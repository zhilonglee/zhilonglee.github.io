# DCF现金流折现：最严谨的估值方法入门

"一个公司的内在价值，等于它未来所有自由现金流的折现值。"这是约翰·伯尔·威廉姆斯在1938年提出的估值核心思想，至今仍是华尔街机构投资者最常用的估值方法。本文基于《股市真规则》一书，从基本原理出发，讲解自由现金流（FCF）的计算、简化版DCF五步计算法、关键假设的确定方法，以及DCF的优缺点和实战应用。

## 一、什么是DCF

### 1.1 DCF的基本原理

DCF（Discounted Cash Flow，现金流折现）是一种通过估算公司未来所有自由现金流，并将其折现到今天来计算公司内在价值的方法。

核心思想是：今天的一块钱大于明天的一块钱，因为今天的钱可以投资获得收益。所以未来的100元不等于今天的100元，未来的100元折现到今天可能只有70元。公司的价值等于未来所有能赚到的钱（折现到今天）的总和。

公式为：公司价值 = FCF₁/(1+r)¹ + FCF₂/(1+r)² + ... + FCFₙ/(1+r)ⁿ + TV/(1+r)ⁿ，其中FCF为每年的自由现金流，r为折现率（通常用WACC），n为预测年数，TV为终值（Terminal Value）。

---

## 二、自由现金流详解

### 2.1 什么是自由现金流

自由现金流（Free Cash Flow, FCF）是公司在维持正常经营后可以自由支配的现金。

计算公式：FCF = 经营性现金流 - 资本支出。更详细的计算是：净利润 + 折旧与摊销（非现金支出加回）- 营运资本增加 - 资本支出（购买设备、建厂房等）。

例如某公司净利润50亿、折旧摊销10亿、营运资本增加5亿、资本支出20亿，则FCF = 50 + 10 - 5 - 20 = 35亿。

### 2.2 为什么用FCF而不是净利润

| 维度 | 净利润 | 自由现金流 |
|------|--------|-----------|
| 可操纵性 | 可以通过会计手段调节 | 很难造假 |
| 真实性 | 可能包含非现金项目 | 真金白银 |
| 可分配性 | 不一定能分给股东 | 可以自由分配 |
| 估值适用性 | PE估值 | DCF估值 |

> "利润只是意见，现金才是事实。" —— 华尔街谚语

## 三、简化版DCF五步法

### 步骤1：确定当前FCF

从财报中找到经营活动现金流净额，减去资本支出，得到自由现金流。假设某公司当前FCF = 100亿。

### 步骤2：预测未来10年的FCF

假设增长率：第1-5年为15%（高速增长期），第6-10年为8%（稳定增长期）。

计算每年FCF：第1年115亿、第2年132亿、第3年152亿、第4年175亿、第5年201亿、第6年217亿、第7年235亿、第8年253亿、第9年274亿、第10年296亿。

### 步骤3：计算终值（Terminal Value）

终值 = 第10年FCF ×（1 + 永续增长率）/（折现率 - 永续增长率）。假设永续增长率 = 3%（不超过GDP增速），折现率 = 10%，则终值 = 296 × 1.03 / 0.07 = 4355亿。

### 步骤4：折现到今天

10年FCF折现之和约1450亿，终值折现到今天约1678亿。公司内在价值 = 1450 + 1678 = 3128亿。

### 步骤5：计算每股价值

假设总股本100亿股，每股内在价值 = 3128/100 = 31.28元。如果当前股价22元，安全边际为29.6%，可以考虑买入。

## 四、关键假设的确定

### 4.1 增长率（g）

参考因素包括过去3-5年的实际增速、行业发展空间、公司竞争优势、管理层指引。建议高增长期（前5年）用历史增速或略低，稳定期（后5年）逐步降低到GDP增速附近，宁可保守不要过于乐观。

### 4.2 折现率（r）

通常用WACC（加权平均资本成本）：WACC = 股权成本 × 股权占比 + 债务成本 ×（1-税率）× 债务占比。简化方法是一般用10%作为折现率，保守投资者可以用12%，低利率环境可以用8%-9%。折现率越高估值越低越保守。

### 4.3 永续增长率

通常取2%-3%，不超过长期GDP增速。原因是如果一家公司永远增长快于GDP，最终它会比整个经济体还大，这不可能。保守选择：发达市场2%，新兴市场3%，中国市场2.5%-3%。

## 五、DCF实战案例

### 5.1 贵州茅台估值（简化示例）

假设当前FCF = 600亿，总股本12.56亿股。增长率假设前5年12%（品牌提价+销量增长），后5年8%（增速放缓），永续增长率3%，折现率9%（确定性强用较低折现率）。

计算结果：前5年FCF折现之和约2900亿，后5年FCF折现之和约2200亿，终值折现约9500亿。内在价值 = 2900 + 2200 + 9500 = 14600亿，每股价值 = 14600/12.56 = 1162元。如果当前股价1500元则高估约29%。

## 六、DCF的优缺点

### 6.1 优点

理论上最严谨的估值方法；关注现金流不容易被会计手段欺骗；可以考虑不同阶段的增长；结果可以量化便于比较；是机构投资者最常用的估值方法。

### 6.2 缺点

对假设极其敏感——增长率变1%估值可能变20%以上，折现率变1%估值可能变15%以上。预测未来很难，谁能准确预测10年后的利润？黑天鹅事件无法预测。

不适合以下公司：亏损公司（没有FCF）、周期股（FCF波动太大）、金融公司（FCF定义模糊）、初创公司（未来不确定）。

容易产生"精确的错误"——算到小数点后两位不代表准确，关键是方向和大致范围。

## 七、DCF与其他估值方法的配合

### 7.1 交叉验证

最佳实践是用多种方法估值取交集。例如DCF估值30-35元、PE估值28-32元、PEG估值25-30元，交集区间28-32元。如果当前股价22元，三种方法都显示低估，安全边际充足可以买入。

### 7.2 不同方法的适用场景

| 方法 | 最适合 | 不适合 |
|------|--------|--------|
| DCF | 现金流稳定的成熟公司 | 亏损、周期、初创 |
| PE | 盈利稳定的公司 | 亏损公司 |
| PB | 重资产行业 | 轻资产公司 |
| PEG | 成长型公司 | 缓慢增长型 |
| PS | 高增长但未盈利 | 传统行业 |

---

## 八、总结

**核心要点回顾：**

1. DCF原理：公司价值=未来所有FCF的折现值
2. 自由现金流：经营现金流-资本支出，比净利润更真实
3. 五步法：确定FCF→预测增长→计算终值→折现→每股价值
4. 关键假设：增长率、折现率、永续增长率，宁可保守
5. 交叉验证：DCF+PE+PEG多种方法配合使用

**实践建议：**

1. DCF是思维工具：不需要精确到小数点，关键是方向和大致范围
2. 保守假设：增长率打8折，折现率加1%
3. 交叉验证：不要只用一种方法
4. 关注FCF质量：持续为正、不断增长的公司最有价值
5. 安全边际：DCF估值后还要留出安全边际
