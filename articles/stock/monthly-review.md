## 一、为什么需要月度复盘

### 1.1 复盘的价值

不复盘的问题是同样的错误反复犯、不知道自己是赚是亏、没有进步方向、可能长期亏损而不自知。

复盘的价值在于发现自己的行为模式、识别盈利和亏损来源、优化交易系统、保持持续进步。

### 1.2 复盘频率

| 频率 | 内容 | 时间 |
|------|------|------|
| 每日 | 简要记录当日操作 | 5分钟 |
| 每周 | 周度小结 | 30分钟 |
| 每月 | 深度复盘 | 2-3小时 |
| 每季 | 战略复盘 | 半天 |
| 每年 | 全面总结 | 1天 |

## 二、月度复盘流程

### 2.1 复盘时间安排

月度复盘建议安排在每月第一个周末：

准备工作（30分钟）：整理当月交易记录、下载交易流水、准备复盘表格。

数据分析（60分钟）：统计交易数据、计算各项指标、对比历史数据。

策略评估（30分钟）：评估各策略表现、分析成功和失败案例。

心理复盘（30分钟）：回顾情绪状态、识别情绪化操作。

制定计划（30分钟）：下月目标、改进措施。

## 三、交易数据分析

### 3.1 核心指标统计

| 指标 | 计算方法 | 目标值 |
|------|---------|--------|
| 总收益率 | (月末净值 - 月初净值) / 月初净值 | > 0 |
| 胜率 | 盈利笔数 / 总笔数 | > 40% |
| 盈亏比 | 平均盈利 / 平均亏损 | > 2:1 |
| 最大单笔盈利 | 最大单笔利润 | 记录 |
| 最大单笔亏损 | 最大单笔亏损 | < 总资金2% |
| 最大回撤 | 最高点到低点的最大跌幅 | < 10% |
| 交易频率 | 月交易笔数 | 合理范围 |

### 3.2 分析维度

多维度分析：

1. **按策略分类**：趋势策略和短线策略的胜率和盈亏比，哪种策略贡献最大？
2. **按行业分类**：哪个行业赚最多？哪个行业亏最多？是否应该调整行业配置？
3. **按持仓时间分类**：短线（<5天）、中线（5-20天）、长线（>20天）的盈亏
4. **按盈亏排序**：前3大盈利交易的共性，前3大亏损交易的共性

### 3.3 净值曲线分析

绘制月度净值曲线，关注以下要点：

1. 曲线是否整体向上？
2. 最大回撤出现在什么时候？
3. 回撤后恢复用了多久？
4. 与大盘对比表现如何？

对比指标：你的收益vs沪深300、你的回撤vs沪深300、你的夏普比率vs基金平均。

## 四、策略有效性评估

### 4.1 策略评估清单

每个策略回答以下问题：

1. 这个策略本月执行了多少次？
2. 胜率和盈亏比是多少？
3. 期望值是正的吗？
4. 有严格执行吗？
5. 需要调整参数吗？
6. 下个月继续使用吗？

评估结果：正期望+严格执行=保持；正期望+未严格执行=加强纪律；负期望+严格执行=调整参数；负期望+未严格执行=暂停，重新评估。

### 4.2 案例分析

每月选2-3个典型案例深入分析：

最佳交易案例：买入理由是什么？持仓过程如何？卖出时机是否最优？可以复制吗？

最差交易案例：错误在哪里？是策略问题还是执行问题？如何避免重复？需要修改什么规则？

## 五、心理状态复盘

### 5.1 情绪日志回顾

回顾当月的情绪状态：

1. **最焦虑的时刻**：什么时候？为什么焦虑？做了什么决定？决定是理性的吗？
2. **最兴奋的时刻**：什么时候？有没有过度自信？有没有冲动操作？
3. **最恐惧的时刻**：什么时候？有没有恐慌性卖出？事后看是正确的吗？
4. **情绪化操作次数**：本月有几笔？占比多少？如何减少？

### 5.2 纪律执行评分

| 项目 | 评分(1-10) | 说明 |
|------|-----------|------|
| 按计划操作 | ? | 是否按交易计划执行 |
| 止损执行 | ? | 是否严格止损 |
| 仓位控制 | ? | 是否控制在合理范围 |
| 不追涨 | ? | 是否避免了追涨 |
| 情绪管理 | ? | 是否保持冷静 |

## 六、制定改进计划

### 6.1 SMART目标

下月目标设定（SMART原则）：

具体（Specific）："提高止损执行率"而不是"做好交易"。

可衡量（Measurable）："止损执行率从70%提高到90%"。

可达成（Achievable）：不要设太高的目标。

相关（Relevant）：针对复盘发现的问题。

有时限（Time-bound）："下个月底前达到"。

### 6.2 改进措施

改进计划模板：

问题1：止损执行不够严格——措施：用条件单自动止损，衡量：止损执行率>95%。

问题2：交易过于频繁——措施：每周最多做3笔交易，衡量：月交易<12笔。

问题3：仓位控制不好——措施：单只不超过15%，衡量：无单只>15%的持仓。

## 七、总结

### 核心要点回顾

1. 月度复盘是必修课：不复盘等于不进步
2. 数据说话：用指标而非感觉评估表现
3. 案例深入分析：最好的和最差的交易都要复盘
4. 心理状态很重要：情绪化操作是最大的敌人
5. 制定改进计划：每月至少一个具体改进目标
