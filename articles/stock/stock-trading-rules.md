# 交易规则硬性要求

> 📋 A股交易有严格的规则，必须熟练掌握才能避免不必要的损失。本文详解所有交易硬性规定。

## 一、交易时间详解

### 1.1 正常交易时间

```
周一至周五（法定节假日除外）

上午时段：
├─ 集合竞价：9:15 - 9:25
│   ├─ 9:15-9:20：可挂单、可撤单
│   └─ 9:20-9:25：可挂单、不可撤单
└─ 连续竞价：9:30 - 11:30

下午时段：
└─ 连续竞价：13:00 - 14:57
└─ 收盘集合竞价：14:57 - 15:00（不可撤单）
```

**关键时间点：**
- **9:15**：开始接受申报
- **9:20**：不可撤单，此时的委托更真实
- **9:25**：产生开盘价
- **9:30**：正式开盘，连续竞价开始
- **11:30**：上午收盘
- **13:00**：下午开盘
- **14:57**：进入收盘集合竞价
- **15:00**：正式收盘

### 1.2 集合竞价规则

**什么是集合竞价？**
- 在规定时间内接受买卖申报
- 一次性集中撮合，产生开盘价或收盘价
- 原则：最大成交量原则

**开盘集合竞价（9:15-9:25）：**
1. 系统接收所有买单和卖单
2. 找出能实现最大成交量的价格
3. 该价格即为开盘价
4. 所有高于开盘价的买单和低于开盘价的卖单全部成交

**收盘集合竞价（14:57-15:00）：**
- 深市、创业板、科创板实行收盘集合竞价
- 沪市主板仍采用连续竞价至15:00
- 目的：防止尾盘操纵股价

**实战技巧：**
- 9:20前的挂单可能是虚假的（主力试盘）
- 9:20后的挂单更可靠
- 强势股常在集合竞价阶段就涨停

### 1.3 特殊交易时间

**节假日安排：**
- 周末休市
- 法定节假日休市（春节、国庆等）
- 调休工作日如果恰逢周末，通常也休市

**临时停牌：**
- 个股重大事项披露时可能临时停牌
- 新股上市首日可能多次临时停牌
- 停牌期间无法交易

## 二、交易制度核心规则

### 2.1 T+1 交易制度

**定义：**
- **T日买入的股票，T+1日才能卖出**
- T日卖出的股票，资金T日可用（买其他股票），T+1日可取（转出到银行卡）

**举例说明：**
```
周一（T日）：
├─ 买入A股票1000股 → 当天不能卖出
└─ 卖出B股票500股 → 资金可立即买C股票，但不能提现

周二（T+1日）：
├─ 可以卖出周一买的A股票
└─ 周一卖出B股票的资金可以提现到银行卡
```

**为什么实行T+1？**
- 抑制过度投机
- 保护中小投资者
- 给投资者冷静期

**对比T+0：**
- 港股、美股实行T+0（当天可多次买卖）
- A股只有部分品种支持T+0：可转债、ETF、期货

**应对策略：**
- 买入前深思熟虑，避免冲动交易
- 利用底仓做T：持有股票基础上，当天低买高卖
- 选择ETF可实现变相T+0

### 2.2 涨跌停限制

#### （1）主板涨跌幅：±10%

**计算方式：**
```
涨停价 = 前一交易日收盘价 × 1.1（四舍五入到分）
跌停价 = 前一交易日收盘价 × 0.9（四舍五入到分）

例如：
昨日收盘价10.00元
涨停价 = 10.00 × 1.1 = 11.00元
跌停价 = 10.00 × 0.9 = 9.00元
```

**特殊情况：**
- 新股上市首日：不设涨跌幅限制（科创板、创业板）
- 之后5个交易日：±20%（科创板、创业板）
- 第6个交易日起：恢复±10%（主板）或±20%（科创板、创业板）

#### （2）创业板、科创板涨跌幅：±20%

**改革时间：** 2020年8月（创业板）、2019年7月（科创板）

**影响：**
- 波动更大，单日可能赚/亏20%
- 打板难度增加（需要更多资金封板）
- 风险显著提高

#### （3）ST股涨跌幅：±5%

**什么是ST股？**
- ST：Special Treatment，特别处理
- 原因：连续亏损、财务异常、违规等
- *ST：退市风险警示

**特点：**
- 涨跌幅限制更严（±5%）
- 投资风险极高
- 可能退市

**投资建议：**
- ❌ 新手绝对不要碰ST股
- ⚠️ 即使老手也要谨慎
- 退市后可能血本无归

### 2.3 涨跌停板实战意义

**涨停板含义：**
- 买盘极强，供不应求
- 可能有重大利好
- 次日可能继续高开或涨停

**跌停板含义：**
- 卖盘极强，恐慌抛售
- 可能有重大利空
- 次日可能继续低开或跌停

**注意事项：**
- 涨停不等于一定能买到（排队）
- 跌停不等于一定能卖出（排队）
- 极端情况下可能连续涨停/跌停

## 三、交易费用详解

### 3.1 费用构成

A股交易费用主要包括三部分：

```
总费用 = 佣金 + 印花税 + 过户费
```

### 3.2 佣金（Commission）

**收取方：** 证券公司  
**费率：** 通常在万分之2.5左右（0.025%），可协商  
**最低收费：** 5元（不足5元按5元收）  
**双向收取：** 买入和卖出都要收

**计算公式：**
```
佣金 = 成交金额 × 佣金率
如果结果 < 5元，则按5元收取

例如：
买入10000元股票，佣金率万分之2.5
佣金 = 10000 × 0.00025 = 2.5元 → 实际收5元（最低收费）

买入100000元股票
佣金 = 100000 × 0.00025 = 25元 → 实际收25元
```

**省钱技巧：**
- 资金量大可与券商协商降低佣金（可谈到万分之1）
- 避免小额频繁交易（每次都收最低5元不划算）
- 选择互联网券商通常佣金更低

### 3.3 印花税（Stamp Duty）

**收取方：** 国家税务局  
**费率：** 卖出时收取成交金额的0.05%（2023年8月减半征收）  
**单向收取：** 只在卖出时收取，买入不收

**计算公式：**
```
印花税 = 卖出成交金额 × 0.05%

例如：
卖出10000元股票
印花税 = 10000 × 0.0005 = 5元
```

**政策变化：**
- 2008年前：双边征收
- 2008-2023年：单边征收0.1%
- 2023年8月起：减半至0.05%（刺激股市）

### 3.4 过户费（Transfer Fee）

**收取方：** 中国证券登记结算公司  
**费率：** 成交金额的0.001%（十万分之一）  
**双向收取：** 买入和卖出都收

**计算公式：**
```
过户费 = 成交金额 × 0.001%

例如：
买入10000元股票
过户费 = 10000 × 0.00001 = 0.1元
```

**注意：**
- 费用很低，几乎可以忽略
- 上海、深圳市场都收取

### 3.5 完整交易成本计算实例

**场景：** 买入10000元股票，涨10%后卖出

**买入时费用：**
```
成交金额：10000元
佣金：5元（最低收费）
印花税：0元（买入不收）
过户费：0.1元
─────────────────
买入总费用：5.1元
```

**卖出时费用：**
```
成交金额：11000元（涨10%）
佣金：5元（最低收费）
印花税：5.5元（11000 × 0.05%）
过户费：0.11元
─────────────────
卖出总费用：10.61元
```

**总成本和净利润：**
```
总费用 = 5.1 + 10.61 = 15.71元
毛利润 = 11000 - 10000 = 1000元
净利润 = 1000 - 15.71 = 984.29元
实际收益率 = 984.29 / 10000 = 9.84%（不是10%）
```

**结论：**
- 短线交易成本高，需要更高胜率
- 长期持有可以摊薄交易成本
- 至少涨0.2%以上才可能保本（覆盖手续费）

### 3.6 费用对比表

| 费用类型 | 费率 | 收取方向 | 最低收费 | 备注 |
|---------|------|---------|---------|------|
| 佣金 | 约0.025% | 双向 | 5元 | 可协商 |
| 印花税 | 0.05% | 仅卖出 | 无 | 国家政策 |
| 过户费 | 0.001% | 双向 | 无 | 固定费率 |

## 四、挂单规则详解

### 4.1 限价委托（Limit Order）

**定义：** 指定价格买入或卖出

**特点：**
- 保证成交价格不劣于指定价格
- 不保证一定成交（可能排队）
- 最常用的委托方式

**举例：**
```
当前价10.00元
你挂买单9.90元 → 只有股价跌到9.90或以下才成交
你挂卖单10.10元 → 只有股价涨到10.10或以上才成交
```

**优势：**
- 控制成本，不会买贵或卖便宜
- 适合震荡市、低吸高抛

**劣势：**
- 可能错过行情（价格没到就飞了）
- 强势股很难用限价买到

### 4.2 市价委托（Market Order）

**定义：** 不指定价格，按当前市场价立即成交

**特点：**
- 保证成交速度
- 不保证成交价格（可能滑点）
- 适合紧急买卖

**深交所市价委托类型：**
1. **对手方最优价格**：按对方第一档价格成交
2. **本方最优价格**：按己方第一档价格挂单
3. **即时成交剩余撤销**：部分成交，剩余撤单
4. **全额成交或撤销**：要么全成，要么全撤

**上交所市价委托类型：**
1. **最优五档即时成交剩余撤销**
2. **最优五档即时成交剩余转限价**

**使用场景：**
- 追涨停板
- 止损离场
- 突发利好/利空需要快速反应

**风险提示：**
- 流动性差的股票可能出现大幅滑点
- 极端行情下成交价可能远离预期

### 4.3 撤单规则

**可撤单时间：**
- 9:15-9:20：可撤单
- 9:20-9:25：不可撤单（集合竞价锁定）
- 9:30-11:30：可撤单（未成交部分）
- 13:00-14:57：可撤单（未成交部分）
- 14:57-15:00：不可撤单（收盘集合竞价）

**撤单操作：**
- 在交易软件中找到"撤单"功能
- 选择要撤销的委托
- 确认撤单

**注意事项：**
- 已成交的部分不能撤
- 撤单后立即释放资金或股票
- 频繁撤单可能被监管关注

### 4.4 预埋单（Pre-order）

**定义：** 在非交易时间提前挂单，开盘后自动生效

**使用时间：**
- 前一交易日清算后（通常晚上9点后）
- 当日早上9:15之前

**用途：**
- 抢涨停/跌停
- 提前布局看好的股票
- 避免早上忘记操作

**优先级：**
- 价格优先：高价买单、低价卖单优先
- 时间优先：同价格下，先挂单的优先

**实战技巧：**
- 看好某股涨停，可提前夜市委托
- 但也不一定成交（要看排队位置）

## 五、停牌与复牌规则

### 5.1 停牌（Suspension）

**定义：** 股票暂停交易

**常见原因：**
1. **重大事项**：并购重组、股权转让
2. **信息披露**：发布重要公告
3. **股价异常**：连续涨停/跌停，需要核查
4. **违规调查**：涉嫌违法违规被调查
5. **财报披露**：定期报告发布前后
6. **股东大会**：召开期间可能短暂停牌

**停牌时长：**
- 短则几分钟（临时公告）
- 长则数月甚至数年（重大重组）

**影响：**
- 资金被占用，无法交易
- 复牌后可能补涨或补跌
- 不确定性高

### 5.2 复牌（Resumption）

**定义：** 股票恢复交易

**复牌表现：**
- **利好消息**：可能连续涨停
- **利空消息**：可能连续跌停
- **中性消息**：跟随大盘走势

**注意事项：**
- 复牌首日不设涨跌幅限制的情况很少
- 大部分情况仍受涨跌停限制
- 提前分析消息性质，做好心理准备

### 5.3 长期停牌风险

**历史案例：**
- 某些股票停牌数年，复牌后暴跌
- 期间大盘上涨，该股补跌
- 资金长期占用，机会成本高

**规避方法：**
- 避免参与有停牌风险的股票
- 分散投资，不全仓一只股
- 关注公司公告，提前预警

## 六、龙虎榜交易规则

### 6.1 什么是龙虎榜？

**定义：** 每日公布异动股票的买卖前五名营业部席位

**上榜条件（满足其一即可）：**
1. 日涨幅偏离值达7%
2. 日跌幅偏离值达7%
3. 日振幅达15%
4. 换手率达20%
5. 连续三个交易日内涨幅偏离值累计达20%

**公布内容：**
- 买入前五名营业部名称及金额
- 卖出前五名营业部名称及金额
- 净买入/净卖出金额

### 6.2 如何看龙虎榜？

**关键信息：**
1. **机构席位**：基金、保险、社保等
   - 机构大买：通常是利好
   - 机构大卖：警惕风险

2. **知名游资席位**：
   - 华泰证券深圳益田路荣超商务中心
   - 国泰君安上海江苏路
   - 中信证券杭州延安路
   - 游资接力：可能继续炒作
   - 游资出货：准备撤退

3. **买卖力量对比**：
   - 买方总额 > 卖方总额：多头占优
   - 买方总额 < 卖方总额：空头占优

4. **营业部集中度**：
   - 集中在少数席位：主力控盘
   - 分散在多个席位：散户居多

### 6.3 龙虎榜实战应用

**利好信号：**
- ✅ 机构大额净买入
- ✅ 知名游资接力买入
- ✅ 买五总额远大于卖五总额
- ✅ 低位首板出现龙虎榜

**利空信号：**
- ❌ 机构大额净卖出
- ❌ 前期大涨后游资集体出货
- ❌ 卖五总额远大于买五总额
- ❌ 高位放量上榜

**注意事项：**
- 龙虎榜是事后数据，有滞后性
- 有些主力会分仓操作，隐藏踪迹
- 不能单纯依赖龙虎榜决策
- 结合技术面、基本面综合判断

## 七、交易规则速查表

### 7.1 核心规则汇总

| 项目 | 规则 | 备注 |
|------|------|------|
| 交易时间 | 9:30-11:30, 13:00-15:00 | 集合竞价另计 |
| 交易制度 | T+1 | 当日买次日才能卖 |
| 主板涨跌幅 | ±10% | 普通股 |
| 创业板涨跌幅 | ±20% | 300开头 |
| 科创板涨跌幅 | ±20% | 688开头 |
| ST股涨跌幅 | ±5% | 高风险 |
| 佣金 | 约0.025% | 最低5元 |
| 印花税 | 0.05% | 仅卖出收取 |
| 过户费 | 0.001% | 双向收取 |
| 最小买入单位 | 100股（1手） | 卖出可以是零股 |
| 价格最小变动 | 0.01元 | 1分钱 |

### 7.2 禁止行为清单

❌ **严禁以下行为：**
1. 内幕交易：利用未公开信息交易
2. 操纵市场：对倒、拉抬、打压股价
3. 虚假申报：频繁挂单撤单误导他人
4. 老鼠仓：基金经理先用个人账户买入
5. 配资炒股：非法杠杆交易
6. 借用账户：使用他人账户交易

**后果：**
- 罚款、没收违法所得
- 市场禁入
- 刑事责任（严重者）

## 八、学习总结

### 核心要点回顾

✅ **交易时间**：9:30-11:30、13:00-15:00，集合竞价特殊规则  
✅ **T+1制度**：当日买入次日才能卖出  
✅ **涨跌幅限制**：主板±10%、创业板科创板±20%、ST±5%  
✅ **交易费用**：佣金+印花税+过户费，短线成本高  
✅ **挂单类型**：限价委托、市价委托、撤单规则  
✅ **停牌复牌**：重大事项导致，复牌可能补涨补跌  
✅ **龙虎榜**：异动股票席位曝光，辅助判断主力动向
