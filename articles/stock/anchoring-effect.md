## 一、锚定效应的原理

### 1.1 什么是锚定效应？

锚定效应（Anchoring Effect）是指人们在做数值估计时，会过度依赖最先获得的信息（锚点），后续的判断和决策都围绕这个锚点进行调整。

经典实验表明，问A组"甘地去世时年龄是否大于114岁"，平均猜67岁；问B组"是否大于35岁"，平均猜50岁。同一个问题，不同的"锚点"导致不同的答案。甘地实际去世年龄为78岁。

### 1.2 为什么会产生锚定？

| 原因 | 说明 |
|------|------|
| 认知惰性 | 从锚点出发调整比从零开始更省力 |
| 调整不足 | 即使知道锚点不对，调整幅度也不够 |
| 信息依赖 | 把锚点当成有价值的参考信息 |
| 心理舒适 | 有个"参照物"让人感觉更有把握 |

## 二、投资中的锚定表现

### 2.1 买入价锚定

最常见的锚定是"我10元买的，现在8元，等回到10元就卖"，这就是锚定在买入价10元。但股票不知道你的买入价，8元可能还会跌到5元。

正确思维是忘记买入价，问自己：如果我现在没有这只股票，我会在8元买入吗？如果不会，就应该卖出。

### 2.2 历史高点锚定

"这只股票曾经涨到过50元，现在才20元，很便宜"——这是锚定在历史高点50元。但高点可能永远不会再来，20元可能还是贵的。

例如某互联网公司2015年高点200元，2020年跌到50元时很多人觉得"好便宜"，结果继续跌到10元。

### 2.3 整数关口锚定

"股价突破100元了好贵""股价才5元好便宜"——这是错误的整数关口锚定。实际上100元的股票可能比5元的更"便宜"（PE更低），股价绝对值没有意义，要看估值（PE、PB、PEG）。

### 2.4 目标价锚定

"分析师说目标价30元，现在25元，还有空间"——这是锚定在分析师目标价。但目标价经常不准，而且会不断调整。

正确做法是把目标价当参考而非锚点，用自己的估值体系做判断。

## 三、锚定效应的实验证据

### 3.1 投资实验

| 实验场景 | 有锚点组 | 无锚点组 |
|---------|---------|---------|
| 估计股票年回报率 | 锚定在历史回报率 | 更理性 |
| 判断股价是否便宜 | 锚定在历史价格 | 看基本面 |
| 设定止损位 | 锚定在买入价 | 看技术位 |
| 估值判断 | 锚定在IPO价格 | 看现金流 |

### 3.2 锚定强度

锚定越强烈，当满足以下条件：

1. **锚点是精确数字**，"目标价32.5元"比"大概30元"更有锚定力
2. **锚点是自己设定的**，"我分析认为会涨到40"
3. **锚点是最近的**，昨天的价格比去年的更有锚定力
4. **锚点带有情感**，"我在30元亏了很多钱"

## 四、常见错误锚点

### 4.1 需要警惕的锚点

| 锚点 | 为什么错 | 应该看什么 |
|------|---------|-----------|
| 买入价 | 市场不知道你的成本 | 当前估值 |
| 历史最高价 | 可能永远回不来 | 当前基本面 |
| 别人的买入价 | 别人可能有不同逻辑 | 自己的分析 |
| 分析师目标价 | 经常不准 | 自己的估值 |
| 整数关口 | 没有基本面意义 | 内在价值 |
| IPO价格 | 可能是泡沫价 | 当前盈利 |

### 4.2 合理的锚点

| 锚点 | 为什么合理 | 使用方法 |
|------|-----------|---------|
| 内在价值 | 基于基本面 | DCF估值 |
| 估值中枢 | PE/PB历史中枢 | 偏离均值 |
| 技术支撑位 | 市场行为形成 | 均线、前低 |
| 成本线 | 行业边际成本 | 周期股底部 |

## 五、摆脱锚定效应的方法

### 5.1 思维重置

摆脱锚定的思维练习：

**问题1**："如果我现在空仓，会在这个价格买入吗？"——会就持有，不会就卖出。

**问题2**："这只股票如果还没有持有，值得研究吗？"——值得就重新分析，不值得就想清楚为什么还持有。

**问题3**："如果我的买入价是X（当前价），我觉得贵吗？"——贵就卖出，不贵就持有。

### 5.2 估值锚定法

用估值替代价格锚定：

1. **不看绝对价格，看PE**，PE 10x的公司比PE 50x的"便宜"，不管股价是10元还是100元
2. **不看历史高点，看估值中枢**，对比当前PE与历史PE中枢，看偏离中枢多远
3. **不看买入价，看内在价值**，当前价格与内在价值的对比，有安全边际就持有

### 5.3 操作建议

1. 定期清理持仓：如果重新选择，还会买这些吗？
2. 设置提醒：在交易软件旁贴"忘记买入价"
3. 写交易日记：记录是否被锚定影响
4. 用条件单止损：自动执行，减少思考

## 六、总结

### 核心要点回顾

1. 锚定效应无处不在：买入价、历史高点、整数关口都是锚
2. 买入价是最大的错误锚点：市场不知道你的成本
3. 忘记成本做决策：用"如果现在空仓"的思维
4. 用估值替代价格：PE、PB比股价更有意义
5. 定期审视持仓：重新评估每一只持有的理由
