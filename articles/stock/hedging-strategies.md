## 一、对冲的基本概念

### 1.1 什么是对冲？

对冲（Hedging）是指通过建立与现有持仓相反的头寸，来降低价格波动风险的交易策略。

对冲的通俗理解：你持有股票（做多）但担心大盘下跌，同时做空指数，如果大盘跌了做空头寸赚钱，从而对冲掉部分或全部下跌风险。

类比来说，买保险就是对冲风险，支付保费就是对冲成本，出险获得赔偿就是对冲收益。

### 1.2 对冲 vs 减仓

| 方式 | 操作 | 优缺点 |
|------|------|--------|
| 减仓 | 卖出部分股票 | 简单，但可能错过反弹 |
| 对冲 | 做空指数 | 保留持仓，但有成本 |
| 止损 | 跌破价位卖出 | 被动，可能有滑点 |

## 二、股指期货对冲

### 2.1 基本原理

股指期货对冲原理：持有50万股票组合，同时做空50万股指期货。

结果是大盘跌10%时股票亏5万但期货赚5万，不亏。大盘涨10%时股票赚5万但期货亏5万，不赚。完全对冲等于锁定了当前价值。

实际操作中通常只部分对冲（如30-50%），保留一部分上涨空间，同时降低一部分下跌风险。

### 2.2 门槛与限制

| 项目 | 说明 |
|------|------|
| 开户门槛 | 50万资金+知识测试 |
| 合约乘数 | IF:300元/点，IC:200元/点 |
| 保证金 | 10-15% |
| 最小交易 | 1手（约10-15万面值） |
| 适合人群 | 资金量较大的投资者 |

### 2.3 对冲比例

对冲比例选择：

0%（不对冲）：完全暴露于市场风险，适合确信牛市的情况。

30%对冲：降低30%的系统性风险，适合偏强市场。

50%对冲：降低一半系统性风险，适合震荡市场。

100%对冲：完全锁定，适合看空但不想卖出的情况。

## 三、ETF对冲策略

### 3.1 反向ETF（境外市场）

在港股/美股市场有反向ETF（如恒生反向ETF），大盘跌1%反向ETF涨1%，买入反向ETF等于对冲下跌风险。优点是操作简单像买股票一样，缺点是有管理费和追踪误差。

### 3.2 利用行业ETF对冲

行业对冲策略：持有科技股组合但担心科技板块回调，可以做空科技ETF（如果有融券）或买入科技板块的看跌期权。持有消费股且看好但不确定，可以同时持有消费ETF（更分散）以降低个股风险。

### 3.3 利用债券ETF对冲

股债平衡策略：60%股票 + 40%债券ETF。

原理是股票和债券通常负相关，股票跌时债券涨，降低组合波动。

调整方式是股票涨多了就卖股买债（再平衡），股票跌多了就卖债买股（再平衡），每季度或每半年调整一次。

## 四、跨市场和跨品种对冲

### 4.1 跨市场对冲

| 策略 | 说明 |
|------|------|
| A股+港股 | 持有A股，做空对应港股 |
| A股+美股 | 持有A股，做空相关行业美股 |
| 黄金对冲 | 持有股票，配置黄金（避险） |

### 4.2 黄金对冲

黄金对冲策略：配置10-15%的黄金，因为黄金与股市通常负相关，黑天鹅时黄金上涨，可以降低组合整体波动。

方式包括黄金ETF（518880）、黄金期货（门槛高）、纸黄金。

### 4.3 货币对冲

持有外币资产对冲人民币贬值：可以通过QDII基金（投资海外市场）、港股通（投资港股）、美元存款等方式。当人民币贬值时外币资产升值，从而对冲汇率风险。

## 五、对冲的成本与收益

### 5.1 对冲成本

| 成本类型 | 说明 |
|---------|------|
| 直接成本 | 期货手续费、ETF管理费 |
| 机会成本 | 对冲掉上涨收益 |
| 基差风险 | 期货和现货的价差变化 |
| 操作复杂度 | 需要额外知识和时间 |

### 5.2 何时对冲？

建议对冲的时机：市场估值过高担心回调、重大事件前不确定性大、持仓浮盈大需保护利润、无法卖出（限售或停牌前）、黑天鹅信号系统性风险增加。

不建议对冲的时机：市场已经大跌可能反弹、持仓不多风险可控、长期投资者短期波动不重要。

---

## 六、总结

### 核心要点回顾

1. 对冲是买保险：降低风险但有成本
2. 股指期货是主要工具：但门槛较高（50万）
3. 股债平衡最简单：60/40组合适合大多数人
4. 黄金是好帮手：10-15%黄金配置降低波动
5. 不要过度对冲：对冲太多等于放弃收益
