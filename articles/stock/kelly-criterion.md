## 一、凯利公式的基本原理

### 1.1 什么是凯利公式？

凯利公式（Kelly Criterion）是由约翰·凯利提出的，用于计算在重复博弈中每次应投入多少比例资金才能使长期增长率最大化的数学公式。

```
凯利公式：
f* = (bp - q) / b

其中：
f* = 最优投注比例（占总资金的百分比）
b  = 赔率（赢的时候赚多少 / 输的时候亏多少）
p  = 胜率（赢的概率）
q  = 败率（输的概率 = 1 - p）
```

### 1.2 核心思想

凯利公式的核心思想：

1. 仓位太小，增长太慢（错失机会）
2. 仓位太大，波动太大（可能破产）
3. 最优仓位，长期复合增长率最大

关键洞察：即使你有60%的胜率，每次全仓也是错误的，因为一次失败就可能致命。

## 二、凯利公式推导与计算

### 2.1 简单示例

```
假设：
胜率 p = 60%
赔率 b = 1（赢1赔1）

f* = (1 × 0.6 - 0.4) / 1 = 0.2 = 20%

结论：每次投入总资金的20%是最优比例
```

### 2.2 不同场景计算

| 胜率(p) | 赔率(b) | 凯利比例(f*) | 说明 |
|---------|---------|-------------|------|
| 50% | 2:1 | 25% | 赔率好，可以大仓位 |
| 60% | 1:1 | 20% | 胜率高，适度仓位 |
| 40% | 3:1 | 10% | 低胜率高赔率 |
| 70% | 1:1 | 40% | 高胜率，可以重仓 |
| 55% | 1.5:1 | 22% | 中等水平 |
| 30% | 5:1 | 6% | 低胜率需小仓位 |

### 2.3 凯利公式的边界

```
何时 f* = 0（不应下注）？
当 bp - q ≤ 0 时
即：b × p ≤ q
即：期望收益为负

例：胜率40%，赔率1:1
f* = (1 × 0.4 - 0.6) / 1 = -0.2
-> 不应下注（期望收益为负）
```

## 三、凯利公式在投资中的应用

### 3.1 确定单笔交易仓位

应用凯利公式的步骤：

**第一步：估计胜率**。基于历史交易记录和当前市场条件，保守估计（宁可低估）。

**第二步：估计赔率（盈亏比）**。目标盈利除以止损幅度。例如目标赚15%，止损5%，赔率3:1。

**第三步：代入公式**。f* = (3 × 0.5 - 0.5) / 3 = 33%。

**第四步：取半凯利（安全起见）**。实际仓位 = f* / 2 = 16.5%。

### 3.2 不同交易类型的仓位

| 交易类型 | 胜率估计 | 盈亏比 | 凯利比例 | 建议仓位 |
|---------|---------|--------|---------|---------|
| 趋势跟踪 | 40% | 3:1 | 13% | 10% |
| 突破交易 | 45% | 2:1 | 22% | 15% |
| 价值投资 | 60% | 2:1 | 40% | 20% |
| 短线交易 | 55% | 1.5:1 | 22% | 15% |

## 四、凯利公式的局限与修正

### 4.1 局限性

| 局限 | 说明 | 应对 |
|------|------|------|
| 胜率难估计 | 未来胜率不确定 | 保守估计 |
| 赔率难确定 | 实际盈亏比波动大 | 用历史平均 |
| 不考虑相关性 | 多个持仓之间的相关性 | 分散投资 |
| 波动太大 | 全凯利波动极大 | 用半凯利或1/3凯利 |
| 假设无限次博弈 | 实际交易次数有限 | 调整比例 |

### 4.2 半凯利法则

实战中推荐使用“半凯利”：实际仓位 = f* / 2。

原因：

1. 胜率和赔率的估计有误差
2. 全凯利的波动太大（心理难以承受）
3. 半凯利的长期收益只比全凯利低25%
4. 但波动降低了50%

半凯利是“收益”和“安全”的最佳平衡。

## 五、实战仓位管理

### 5.1 综合仓位管理框架

综合仓位 = min(凯利仓位, 风险限额, 最大单只仓位)。

1. **凯利仓位**：由公式计算
2. **风险限额**：单笔亏损不超过总资金2%，仓位 = 2% / 止损幅度。如止损5%，则仓位不超过40%
3. **最大单只**：不超过总资金的20%

三者取最小值。

### 5.2 多只股票的仓位分配

假设总资金100万，持有3只股票：

- 股票A：胜率60%，赔率2:1，凯利40%，半凯利20%
- 股票B：胜率50%，赔率2:1，凯利25%，半凯利12%
- 股票C：胜率45%，赔率3:1，凯利22%，半凯利11%

总仓位 = 20% + 12% + 11% = 43%，保留现金57%。

注意：总仓位不超过80%，相关性高的股票降低总仓位。

### 5.3 动态调整

| 市场状态 | 仓位调整 |
|---------|---------|
| 牛市（胜率高） | 提高总仓位到60-80% |
| 震荡（胜率中） | 维持30-50% |
| 熊市（胜率低） | 降低到10-30% |
| 恐慌（不确定） | 降到0-10% |

## 六、总结

### 核心要点回顾

1. 凯利公式给出最优仓位：数学上使长期增长率最大
2. 实战用半凯利：收益损失25%，但风险降低50%
3. 胜率和赔率是关键：保守估计，不要乐观
4. 单笔风险不超过2%：这是底线
5. 动态调整：根据市场环境调整总仓位
