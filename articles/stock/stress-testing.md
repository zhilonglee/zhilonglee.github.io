## 一、压力测试的概念

### 1.1 什么是压力测试？

压力测试（Stress Testing）是指模拟极端市场条件下，评估投资组合可能遭受的最大损失。

压力测试与常规风险评估的区别在于：常规风险评估假设市场正常波动，用历史波动率预测，可能低估极端风险；而压力测试假设极端事件发生，模拟黑天鹅场景，评估最坏情况下的损失。

目的不是预测，而是"如果发生了，我能承受吗？"

### 1.2 为什么要做压力测试？

| 原因 | 说明 |
|------|------|
| 发现隐藏风险 | 正常市况下看不到的风险 |
| 评估承受力 | 最坏情况下能否存活 |
| 制定应急预案 | 提前想好应对方案 |
| 优化仓位 | 降低不可承受的风险 |
| 心理准备 | 知道最坏结果，心态更稳 |

## 二、历史情景压力测试

### 2.1 A股历史极端事件

| 事件 | 时间 | 大盘跌幅 | 持续时间 |
|------|------|---------|---------|
| 2015年股灾 | 6-7月 | -45% | 1个月 |
| 2018年贸易战 | 全年 | -25% | 全年 |
| 2020年疫情 | 2-3月 | -15% | 1个月 |
| 2022年俄乌 | 3月 | -10% | 2周 |

### 2.2 测试方法

历史情景压力测试步骤：

第一步，选择历史极端事件，如2015年股灾（最极端）、2018年熊市（持续阴跌）、2020年疫情（快速V型反转）。

第二步，假设当前持仓经历同样的事件，你的持仓在那个时期跌了多少？你的总资产会损失多少？

第三步，评估承受力：最大亏损金额是多少？你能承受吗？需要多久恢复？

### 2.3 示例

假设当前持仓：科技股A 30万、消费股B 20万、新能源C 20万、现金30万。

模拟2015年股灾（大盘-45%）：科技股A跌幅60%亏损18万，消费股B跌幅35%亏损7万，新能源C跌幅50%亏损10万，总亏损35万（占总资产35%）。

评估：从100万变成65万，需要涨54%才能回本。能承受吗？如果不能，就需要减仓。

## 三、假设情景压力测试

### 3.1 常见假设情景

| 情景 | 描述 | 测试目的 |
|------|------|---------|
| 大盘暴跌30% | 系统性风险 | 总体风险暴露 |
| 单只股票跌停 | 个股风险 | 集中度风险 |
| 连续3个跌停 | 流动性风险 | 能否止损 |
| 行业黑天鹅 | 某行业暴跌50% | 行业集中风险 |
| 利率上升2% | 宏观变化 | 利率敏感股 |

### 3.2 多维度测试

综合压力测试矩阵：

| | 轻度(-10%) | 中度(-25%) | 重度(-40%) |
|---|---|---|---|
| 大盘 | 亏10万 | 亏25万 | 亏40万 |
| 科技板块 | 亏12万 | 亏25万 | 亏36万 |
| 持仓集中 | 亏8万 | 亏20万 | 亏32万 |

问自己：哪种情景我无法承受？无法承受的情景，我的仓位是否太大？

## 四、压力测试结果分析

### 4.1 风险评级

| 最大亏损 | 评级 | 建议 |
|---------|------|------|
| < 10% | 低风险 | 正常操作 |
| 10-20% | 中风险 | 可接受，但需关注 |
| 20-30% | 高风险 | 需要减仓或分散 |
| 30-50% | 极高风险 | 必须立即调整 |
| > 50% | 不可承受 | 严重问题 |

### 4.2 关键指标

压力测试关键指标：

1. **最大可能亏损（Max Loss）**，最坏情况下亏多少
2. **恢复时间**，需要多久才能回到原净值，亏30%需要涨43%才能回本，亏50%需要涨100%才能回本
3. **流动性风险**，如果连续跌停能否止损？小盘股流动性差，风险更大
4. **相关性风险**，所有持仓是否同涨同跌？相关性高则分散无效

---

## 五、风险应对预案

### 5.1 分级应对

压力测试后的应对预案：

一级预案（亏损<10%）：正常止损，按计划操作，不需要特殊处理。

二级预案（亏损10-20%）：减仓至50%，停止新开仓，评估是否需要换股。

三级预案（亏损>20%）：立即减仓至30%，暂停交易1周，全面复盘策略。

四级预案（亏损>30%）：清仓，暂停交易1个月，重新审视整个投资体系。

### 5.2 预防措施

| 措施 | 说明 |
|------|------|
| 分散持仓 | 单只 < 20%，行业 < 30% |
| 保留现金 | 至少10-20%现金 |
| 对冲工具 | 股指期货、期权对冲 |
| 止损纪律 | 单笔不超过总资金2% |
| 定期测试 | 每月做一次压力测试 |

---

## 六、总结

### 核心要点回顾

1. 压力测试是必要的：发现正常市况下看不到的风险
2. 模拟极端事件：如果股灾再来一次，你能承受吗？
3. 评估承受力：最大亏损不超过30%为底线
4. 制定应急预案：不同亏损等级有不同应对方案
5. 分散是最好防护：相关性低的持仓组合最安全
