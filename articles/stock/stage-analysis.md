# 温斯坦阶段分析法：用周线图选大牛股

温斯坦说：“我只在第二阶段买入股票。”这句话价值千万。他将股票的价格运动分为四个阶段——蓄势、上涨、见顶、下跌，核心工具是30周均线和周线图。本文基于《史丹·温斯坦称傲牛熊市的秘密》一书，系统讲解如何用周线图判断股票处于哪个阶段、每个阶段的操作策略，以及阶段转换的关键信号。

> "只在第二阶段买入，其他阶段观望。"

## 一、四阶段理论概述

### 1.1 什么是阶段分析？

**定义：** 温斯坦阶段分析法将股票的价格运动分为四个阶段，每个阶段有不同的特征和操作策略。

**四阶段模型：**
```
价格
 ↑
 │        ╱╲╱╲
 │      ╱╱    ╲╲      第三阶段（顶部）
 │    ╱╱        ╲╲    ╱╲╱╲
 │  ╱╱ 第二阶段  ╲╲  ╱    ╲
 │ ╱╱  （上涨）   ╲╲╱      ╲  第四阶段（下跌）
 │╱╱              ╲╲╲╲╲╲╲╲╲╲╲╲
 │╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱╱
 │ 第一阶段（蓄势）
 └──────────────────────────→ 时间
```

### 1.2 四阶段概览

| 阶段 | 特征 | 均线状态 | 操作策略 |
|------|------|---------|---------|
| 第一阶段 | 横盘整理 | 均线走平 | 观望等待 |
| 第二阶段 | 上涨趋势 | 均线向上 | 买入持有 |
| 第三阶段 | 顶部震荡 | 均线走平 | 分批卖出 |
| 第四阶段 | 下跌趋势 | 均线向下 | 空仓观望 |

**核心原则：**
```
✅ 只在第二阶段买入
✅ 第一、三、四阶段不持有
✅ 用30周均线判断阶段
✅ 周线图为主，日线图为辅
```

## 二、第一阶段：蓄势区

### 2.1 特征描述

```
价格表现：
→ 在一个区间内横盘震荡
→ 波动幅度逐渐收窄
→ 没有明显方向

均线表现：
→ 30周均线走平
→ 股价围绕均线上下波动
→ 均线从下降转为走平

成交量：
→ 量能萎缩
→ 偶尔放量但很快恢复平静
```

### 2.2 图形示意

```
         ──────────────
        ╱╲  ╱╲    ╱╲
  ────╱──╲╱──╲──╱──╲──── 30周均线（走平）
      ╲  ╱╲  ╲╱
       ╲╱  ╲╱
```

### 2.3 操作策略

```
第一阶段的操作：
→ 观望！不买入
→ 放入观察池
→ 等待突破信号

关注信号：
→ 成交量突然放大
→ 股价突破区间上沿
→ 均线开始拐头向上
```

---

## 三、第二阶段：上涨区

### 3.1 特征描述

```
价格表现：
→ 突破第一阶段区间上沿
→ 创出新高
→ 回调不跌破前低

均线表现：
→ 30周均线拐头向上
→ 股价在均线上方运行
→ 均线形成支撑

成交量：
→ 上涨时放量
→ 回调时缩量
→ 量价配合良好
```

### 3.2 图形示意

```
              ╱
            ╱    ← 不断创新高
          ╱
        ╱
      ╱  ← 回调不破前低
    ╱
  ╱
╱  ← 突破第一阶段
─────────────────── 30周均线（向上）
```

### 3.3 操作策略

```
买入条件（全部满足）：
✅ 股价突破第一阶段区间上沿
✅ 30周均线拐头向上
✅ 突破时放量
✅ 股价在30周均线上方

买入时机：
→ 突破时买入（激进）
→ 回踩30周均线不破时买入（稳健）

持有条件：
→ 股价在30周均线上方
→ 30周均线持续向上
→ 没有见顶信号

卖出条件：
→ 股价跌破30周均线
→ 30周均线拐头向下
→ 进入第三阶段
```

---

## 四、第三阶段：顶部区

### 4.1 特征描述

```
价格表现：
→ 停止创新高
→ 在一个区间内大幅震荡
→ 高点不再升高，低点不再降低

均线表现：
→ 30周均线走平
→ 股价频繁穿越均线
→ 均线失去支撑作用

成交量：
→ 量能不稳定
→ 上涨缩量、下跌放量
```

### 4.2 操作策略

```
第三阶段的操作：
→ 分批卖出
→ 不追加买入
→ 设好止损

卖出信号：
→ 股价跌破区间下沿
→ 30周均线拐头向下
→ 放量跌破重要支撑
```

---

## 五、第四阶段：下跌区

### 5.1 特征描述

```
价格表现：
→ 跌破第三阶段区间下沿
→ 持续创新低
→ 反弹不过前高

均线表现：
→ 30周均线向下
→ 股价在均线下方运行
→ 均线形成压力

成交量：
→ 下跌放量
→ 反弹缩量
```

### 5.2 操作策略

```
第四阶段的操作：
→ 空仓观望！
→ 不要抄底！
→ 等待跌势结束的信号

何时可以关注：
→ 下跌速度放缓
→ 成交量极度萎缩
→ 可能在酝酿新的第一阶段
```

## 六、30周均线的妙用

### 6.1 为什么是30周均线？

```
30周均线 ≈ 150日均线 ≈ 半年线

温斯坦选择30周均线的原因：
→ 过滤短期噪音
→ 反映中期趋势
→ 比日线均线更稳定
→ 周线图减少情绪干扰
```

### 6.2 30周均线的用法

| 均线方向 | 股价位置 | 阶段判断 | 操作 |
|---------|---------|---------|------|
| 走平 | 上下穿越 | 第一阶段 | 观望 |
| 向上 | 在上方 | 第二阶段 | 买入持有 |
| 走平 | 上下穿越 | 第三阶段 | 卖出 |
| 向下 | 在下方 | 第四阶段 | 空仓 |

## 七、阶段转换信号

### 7.1 一→二阶段转换

```
关键信号：
✅ 股价放量突破区间上沿
✅ 30周均线拐头向上
✅ 成交量明显放大
✅ 突破后回踩不破

这是最重要的信号！
→ 意味着长期蓄势结束
→ 上涨行情即将开始
```

### 7.2 二→三阶段转换

```
关键信号：
⚠️ 上涨速度放缓
⚠️ 30周均线走平
⚠️ 股价频繁穿越均线
⚠️ 成交量不规则

→ 上涨动能在衰减
→ 需要提高警惕
```

### 7.3 三→四阶段转换

```
关键信号：
❌ 股价跌破区间下沿
❌ 30周均线拐头向下
❌ 放量下跌
❌ 反弹无力

→ 下跌趋势开始
→ 必须离场
```

## 八、实战应用

### 8.1 选股流程

```
第一步：周线筛选
→ 30周均线走平或向上
→ 股价在30周均线上方
→ 处于第一或第二阶段

第二步：确认阶段
→ 第一阶段：放入观察池
→ 第二阶段：深入研究

第三步：日线确认买点
→ 等待回调到支撑位
→ 确认量价配合
→ 设定止损位

第四步：持有管理
→ 每周检查30周均线
→ 均线向上就持有
→ 均线拐头就警惕
```

### 8.2 不同阶段的仓位

| 阶段 | 仓位 | 操作频率 |
|------|------|---------|
| 第一阶段 | 0% | 每周看一次 |
| 第二阶段 | 50-100% | 每周检查 |
| 第三阶段 | 0-30% | 逐步减仓 |
| 第四阶段 | 0% | 不看或放入观察池 |

## 九、总结

### 核心要点回顾

✅ **四阶段**：蓄势→上涨→顶部→下跌，循环往复  
✅ **核心原则**：只在第二阶段买入  
✅ **30周均线**：判断阶段的核心工具  
✅ **阶段转换**：关注均线和量价配合  
✅ **操作纪律**：不同阶段用不同策略  

### 实践建议

1. **用周线图为主**：减少噪音，看清大势
2. **只做第二阶段**：不抄底、不逃顶
3. **30周均线是生命线**：线上持有，线下离场
4. **耐心等待**：第一阶段可能很长，但值得等
5. **严格执行**：阶段转换时必须行动
