## 一、反转形态概述

### 1.1 什么是反转形态？

**定义：** 反转形态是指股价在趋势末端出现的特定K线组合形态，预示着当前趋势即将反转。

**分类：**
```
反转形态
├── 顶部反转（上涨→下跌）
│   ├── 头肩顶
│   ├── 双顶（M顶）
│   ├── 三重顶
│   ├── 圆弧顶
│   └── V型反转（顶部）
│
└── 底部反转（下跌→上涨）
    ├── 头肩底
    ├── 双底（W底）
    ├── 三重底
    ├── 圆弧底
    └── V型反转（底部）
```

### 1.2 反转形态的确认条件

```
反转形态成立的四个条件：
✅ 之前必须有明确的趋势（上涨或下跌）
✅ 形态必须完成（不能半途判断）
✅ 关键位置必须被突破（颈线/趋势线）
✅ 成交量配合（突破时放量更可靠）

⚠️ 重要提醒：
→ 形态未完成前，不能提前判断
→ "看起来像"不等于"就是"
→ 必须等待确认信号
```

## 二、头肩顶与头肩底

### 2.1 头肩顶（Head and Shoulders Top）

**形态结构：**
```
                    头
                   ╱  ╲
          左肩   ╱    ╲   右肩
         ╱  ╲  ╱      ╲  ╱  ╲
        ╱    ╲╱        ╲╱    ╲
       ╱    颈线──────────────╲  ← 跌破颈线确认
      ╱                        
```

**特征：**
```
1. 三个峰：左肩、头（最高）、右肩
2. 左肩和右肩高度大致相当
3. 头部高于左右两肩
4. 连接两肩之间的低点形成颈线
5. 跌破颈线 = 形态确认
```

**成交量特征：**
```
左肩：放量上涨
头部：量能较左肩减少
右肩：量能明显萎缩
跌破颈线：放量下跌

量能递减是头肩顶的重要特征！
```

**操作策略：**
```
买点1：跌破颈线时（激进）
买点2：跌破后回抽颈线不过时（稳健）

止损位：右肩高点上方
目标位：颈线到头的距离，向下投射
```

---

### 2.2 头肩底（Inverse Head and Shoulders）

**形态结构：**
```
      ╲                        
       ╲    颈线──────────────╱  ← 突破颈线确认
        ╲    ╱╲        ╱╲    ╱
         ╲  ╱  ╲      ╱  ╲  ╱
          ╲╱    头部  ╲    ╲╱
                  左肩   右肩
```

**特征：**
```
1. 三个谷：左肩、头（最低）、右肩
2. 左肩和右肩深度大致相当
3. 头部低于左右两肩
4. 突破颈线 = 形态确认
5. 突破时必须放量！
```

**与头肩顶的区别：**
```
头肩顶：
→ 不需要放量确认跌破
→ 无量下跌也可以确认

头肩底：
→ 必须放量确认突破
→ 无量突破不可信！
```

## 三、双顶与双底

### 3.1 双顶（M顶）

**形态结构：**
```
    顶1      顶2
    ╱╲      ╱╲
   ╱  ╲    ╱  ╲
  ╱    ╲  ╱    ╲
 ╱      ╲╱      ╲
╱       颈线──────╲  ← 跌破确认
```

**特征：**
```
1. 两个高度接近的峰
2. 两峰之间有明显回调
3. 回调低点形成颈线
4. 跌破颈线 = 确认
5. 第二个顶的量能通常小于第一个
```

**与头肩顶的对比：**

| 维度 | 头肩顶 | 双顶 |
|------|--------|------|
| 可靠性 | 更高 | 略低 |
| 出现频率 | 较少 | 更常见 |
| 形成时间 | 更长 | 较短 |
| 确认难度 | 更明确 | 有时模糊 |

---

### 3.2 双底（W底）

**形态结构：**
```
╲       颈线──────╱  ← 突破确认
 ╲      ╱╲      ╱
  ╲    ╱  ╲    ╱
   ╲  ╱    ╲  ╱
    ╲╱      ╲╱
    底1      底2
```

**特征：**
```
1. 两个深度接近的谷
2. 两谷之间有明显反弹
3. 反弹高点形成颈线
4. 突破颈线 = 确认
5. 第二个底的量能通常小于第一个
```

**操作策略：**
```
买点1：突破颈线时（激进）
买点2：突破后回踩颈线支撑时（稳健）

止损位：第二个底的下方
目标位：颈线到底部的距离，向上投射
```

## 四、三重顶与三重底

### 4.1 三重顶

```
  顶1    顶2    顶3
  ╱╲    ╱╲    ╱╲
 ╱  ╲  ╱  ╲  ╱  ╲
╱    ╲╱    ╲╱    ╲
      颈线──────────╲  ← 跌破确认
```

**特征：**
```
1. 三个高度接近的峰
2. 比双顶更可靠（三次冲击未果）
3. 形成时间更长
4. 突破后力度更大
5. 相对少见
```

### 4.2 三重底

```
      颈线──────────╱  ← 突破确认
╲    ╱╲    ╱╲    ╱
 ╲  ╱  ╲  ╱  ╲  ╱
  ╲╱    ╲╱    ╲╱
  底1    底2    底3
```

**特征：**
```
1. 三个深度接近的谷
2. 三次探底不破 = 强支撑
3. 突破颈线后上涨力度大
4. 比双底更可靠
```

```
V型反转（底部）：
    ╲          ╱
      ╲      ╱

倒V型（顶部）：

        ╱  ╲

```

**特征：**
```
1. 没有明显的筑底/筑顶过程
2. 反转极其迅速
3. 通常由突发消息引发
4. 事先无法预测
5. 操作难度极大

应对方法：
→ 事先设好止损
→ 不追V型反转的第一波
→ 等回调确认后再参与
```

## 七、目标位计算

### 7.1 测量方法

**通用规则：**
```
目标位 = 突破点 ± 形态高度

形态高度 = 形态最高点到颈线的距离
```

**各形态目标位计算：**

| 形态 | 高度测量 | 目标位 |
|------|---------|--------|
| 头肩顶/底 | 头部到颈线 | 颈线 ± 高度 |
| 双顶/底 | 顶部/底部到颈线 | 颈线 ± 高度 |
| 三重顶/底 | 顶部/底部到颈线 | 颈线 ± 高度 |

**计算实例：**
```
某股票形成双底（W底）：
底部价格：10元
颈线价格：15元
形态高度：15 - 10 = 5元

突破颈线后目标位：
15 + 5 = 20元
```

## 八、真假突破识别

### 8.1 真突破的特征

```
✅ 突破时成交量明显放大
✅ 突破幅度超过3%（过滤噪音）
✅ 连续2-3天站稳突破位
✅ 突破后回踩不破（支撑/阻力转换）
✅ 突破方向与大势一致
```

### 8.2 假突破的特征

```
❌ 突破时量能不足
❌ 突破幅度很小（< 1%）
❌ 当天突破当天回落
❌ 突破后很快回到形态内
❌ 突破方向与大势相反
```

### 8.3 应对假突破

```
方法1：等待确认
→ 不追突破的第一时间
→ 等回踩确认后再进场

方法2：设好止损
→ 突破位下方3-5%设止损
→ 假突破触发止损立即离场

方法3：看成交量
→ 无量突破不追
→ 放量突破更可信
```

## 九、总结

### 核心要点回顾

✅ **头肩形态**：最可靠的反转信号，注意量能递减  
✅ **双顶/双底**：最常见，M顶和W底要等颈线突破确认  
✅ **三重顶/底**：比双顶更可靠，形成时间更长  
✅ **圆弧底**：最可靠的底部形态之一，耐心持有  
✅ **V型反转**：无法预测，靠止损保护  
✅ **目标位**：形态高度投射法  
✅ **真假突破**：看量能、看幅度、看持续性  

### 实践建议

1. **形态未完成不判断**：耐心等待确认信号
2. **成交量是关键**：底部突破必须放量
3. **设好止损**：假突破随时可能出现
4. **结合大势**：顺势形态更可靠
5. **多周期验证**：周线形态比日线更可靠
