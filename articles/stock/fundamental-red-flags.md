# 基本面避雷清单

> ⚠️ 投资第一条：不要亏钱！本文汇总所有基本面雷区，帮你避开90%的陷阱。

## 一、财务造假雷区

### 1.1 收入造假

**❌ 危险信号：**

#### （1）应收账款激增
```
警示：
应收账款增速 >> 营收增速
应收账款/营收 > 30%

含义：
可能通过赊销虚增收入
坏账风险大

案例：
康得新、康美药业都有此特征
```

**检查方法：**
```
计算：应收账款周转天数
正常：<90天
异常：>180天且持续上升
```

---

#### （2）关联交易异常
```
警示：
关联交易占比 > 30%
向关联方销售价格异常

含义：
可能通过关联交易输送利益
虚增收入

检查：
查看财报附注中的关联交易明细
```

---

#### （3）海外收入可疑
```
警示：
海外收入突然大增
但无法验证（审计困难）

含义：
可能虚构海外客户
伪造出口合同

案例：
很多造假公司都有大量"神秘"海外客户
```

---

### 1.2 利润造假

**❌ 危险信号：**

#### （1）毛利率异常高
```
警示：
毛利率远高于同行
且无法合理解释

例子：
同行毛利率20%，该公司50%
却没有技术或品牌优势

含义：
可能少计成本
或虚增收入
```

---

#### （2）费用率异常低
```
警示：
销售费用、管理费用远低于同行
研发费用资本化比例高

含义：
可能将费用资本化
美化利润

检查：
看费用占营收比例
与同行对比
```

---

#### （3）非经常性损益占比高
```
警示：
净利润 >> 扣非净利润
靠出售资产、政府补助盈利

含义：
主业不赚钱
盈利不可持续

检查：
净利润 vs 扣非净利润
差异大就要警惕
```

---

### 1.3 资产造假

**❌ 危险信号：**

#### （1）货币资金与借款矛盾
```
警示：
账上现金很多
但同时有大量借款

例子：
货币资金100亿
短期借款80亿

含义：
现金可能是假的
或被占用

案例：
康美药业：账上300亿现金，却还不起10亿债
→ 现金造假
```

---

#### （2）存货异常
```
警示：
存货大幅增加
但营收下滑
存货周转天数延长

含义：
产品滞销
可能计提大额减值

检查：
存货/营收比例
存货周转率
```

---

#### （3）商誉过高
```
警示：
商誉/净资产 > 30%
频繁高价收购

含义：
收购溢价太高
可能计提商誉减值

风险：
一次性减值可能亏损几十亿

检查：
看商誉构成
评估被收购公司质量
```

---

#### （4）在建工程长期不转固
```
警示：
在建工程金额大
多年不转为固定资产

含义：
可能通过在建工程隐藏费用
或虚构项目

检查：
看在建工程明细
是否合理
```

---

## 二、经营恶化雷区

### 2.1 业绩暴雷

**❌ 危险信号：**

#### （1）连续亏损
```
警示：
连续2年净利润为负
连续3年扣非净利润为负

含义：
主业不赚钱
可能退市

规则：
连续3年亏损 → ST
连续4年亏损 → *ST（退市风险）
```

---

#### （2）业绩大幅下滑
```
警示：
净利润同比下滑 > 50%
营收同比下滑 > 30%

含义：
经营出现严重问题
可能继续恶化

检查：
下滑原因是什么？
是一次性还是趋势？
```

---

#### （3）增收不增利
```
警示：
营收增长
但净利润下滑
毛利率下降

含义：
竞争加剧
成本上升
盈利能力恶化

检查：
看毛利率、净利率变化
```

---

### 2.2 现金流危机

**❌ 危险信号：**

#### （1）经营现金流持续为负
```
警示：
连续2年经营现金流为负
且金额较大

含义：
主业不产生现金
靠融资维持

风险：
资金链可能断裂

检查：
经营现金流/净利润
应该 > 1
```

---

#### （2）短债长投
```
警示：
短期借款多
但现金少
流动比率 < 1

含义：
用短期借款做长期投资
资金错配

风险：
到期还不上
可能违约

检查：
流动比率 = 流动资产/流动负债
应该 > 1.5
```

---

#### （3）频繁融资
```
警示：
频繁增发、发债
筹资活动现金流持续为正

含义：
自身造血能力差
靠外部输血

风险：
融资环境收紧时
可能资金链断裂
```

---

## 三、公司治理雷区

### 3.1 大股东问题

**❌ 危险信号：**

#### （1）股权质押率高
```
警示：
大股东质押比例 > 50%
甚至 > 80%

含义：
大股东缺钱
可能平仓

风险：
股价下跌触发平仓
导致暴跌

检查：
查看股权质押公告
```

---

#### （2）大股东减持
```
警示：
大股东持续减持
高管集体减持

含义：
内部人不看好
可能在套现

风险：
信心打击
股价承压

检查：
查看减持公告
减持比例和价格
```

---

#### （3）大股东占用资金
```
警示：
其他应收款异常大
关联方往来款多

含义：
大股东占用上市公司资金

风险：
资金被掏空
公司受损

案例：
很多ST公司都有此问题
```

---

### 3.2 管理层问题

**❌ 危险信号：**

#### （1）频繁更换高管
```
警示：
CEO、CFO频繁更换
一年内换多次

含义：
内部管理混乱
或有重大问题

风险：
战略不连续
经营不稳定
```

---

#### （2）高管违规
```
警示：
高管被调查
内幕交易
违规担保

含义：
公司治理差
道德风险高

风险：
可能被处罚
影响经营
```

---

#### （3）薪酬异常
```
警示：
业绩下滑但高管薪酬大涨
薪酬与业绩不匹配

含义：
管理层自肥
损害股东利益

检查：
看薪酬与业绩挂钩情况
```

---

## 四、行业政策雷区

### 4.1 政策打压

**❌ 危险信号：**

#### （1）监管趋严
```
警示：
行业被重点监管
出台限制政策

例子：
教培行业（双减政策）
互联网平台（反垄断）
房地产（三道红线）

含义：
行业逻辑改变
估值体系重构

操作：
立即回避
不要抄底
```

---

#### （2）补贴退坡
```
警示：
政府补贴减少或取消
行业依赖补贴

例子：
光伏补贴退坡
新能源车补贴退坡

含义：
盈利能力下降
竞争力考验

操作：
关注成本控制能力强的龙头
```

---

#### （3）环保压力
```
警示：
高污染行业
环保要求提高

例子：
钢铁、煤炭、化工

含义：
成本上升
产能受限

操作：
关注环保达标的龙头
小厂可能倒闭
```

---

### 4.2 技术颠覆

**❌ 危险信号：**

#### （1）新技术替代
```
警示：
出现颠覆性新技术
原有技术被淘汰

例子：
数码相机替代胶卷（柯达倒闭）
智能手机替代功能机（诺基亚衰落）
电动车替代燃油车

含义：
行业面临重构
传统企业危机

操作：
拥抱新技术
回避旧技术
```

---

#### （2）专利到期
```
警示：
核心专利即将到期
仿制药/仿制产品涌入

例子：
创新药专利悬崖

含义：
价格大幅下降
利润缩水

操作：
关注管线储备
是否有新药接力
```

---

## 五、估值泡沫雷区

### 5.1 估值过高

**❌ 危险信号：**

#### （1）PE远超历史
```
警示：
PE处于历史90%分位以上
远高于历史平均

含义：
估值泡沫
透支未来

风险：
均值回归
大幅下跌

操作：
减仓或清仓
不要追高
```

---

#### （2）PE远超同行
```
警示：
PE是同行的2-3倍
但没有明显优势

含义：
估值不合理
可能回调

检查：
是否有特殊理由支撑高估值
否则回避
```

---

#### （3）市值与实力不符
```
警示：
市值巨大
但营收、利润很小

例子：
市值1000亿
营收只有10亿
PS = 100倍

含义：
纯粹炒作
没有基本面支撑

风险：
泡沫破裂
暴跌
```

## 六、避雷 checklist

### 6.1 买入前必查清单

**财务健康：**
- [ ] 营收、利润是否增长？
- [ ] 经营现金流是否为正？

- [ ] 高管是否稳定？
- [ ] 是否有违规记录？
- [ ] 审计意见是否标准？

**行业前景：**
- [ ] 行业是否景气？
- [ ] 政策是否友好？

**估值合理：**
- [ ] PE是否在合理范围？
- [ ] 是否与同行相当？
- [ ] 是否处于历史低位？
- [ ] PEG是否<1.5？
- [ ] 是否有安全边际？

**全部打勾才能买入！**

## 七、经典案例分析

### 7.1 康美药业（财务造假）

**雷区：**
- ❌ 货币资金300亿，却还不起10亿债
- ❌ 应收账款激增
- ❌ 存货异常
- ❌ 关联交易复杂

**结果：**
- 股价从20元跌到2元
- 退市
- 投资者血本无归

**教训：**
- 现金与借款矛盾要警惕
- 财务数据异常要深究

---

### 7.2 乐视网（生态化反）

**雷区：**
- ❌ 持续亏损
- ❌ 经营现金流为负
- ❌ 大股东高比例质押
- ❌ 频繁融资
- ❌ 概念炒作

**结果：**
- 股价从170元跌到0.18元
- 退市
- 投资者损失惨重

**教训：**
- 不赚钱的公司要远离
- 概念炒作不要碰

---

### 7.3 教培行业（政策风险）

**雷区：**
- ❌ 政策突变（双减）
- ❌ 行业逻辑彻底改变
- ❌ 估值崩塌

**结果：**
- 新东方、好未来等暴跌90%+
- 行业几乎消失

**教训：**
- 政策风险要重视
- 不要与国家政策对着干

## 八、核心要点回顾

✅ **财务造假**：应收激增、现金矛盾、商誉过高、关联交易  
✅ **经营恶化**：连续亏损、现金流为负、增收不增利  
✅ **公司治理**：股权质押、大股东减持、高管频繁更换  
✅ **政策风险**：监管趋严、补贴退坡、技术颠覆  
✅ **估值泡沫**：PE过高、远超同行、市值与实力不符  
✅ **避雷原则**：看不懂的不投、有疑点的不投、太贵的不投
