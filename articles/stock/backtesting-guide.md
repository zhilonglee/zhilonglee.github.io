## 一、什么是回测？

### 1.1 定义

```
回测（Backtesting）：
用历史数据模拟交易策略的表现

目的：
-> 验证策略是否有效
-> 了解策略的风险特征
-> 发现策略的优缺点
-> 在投入真金白银前发现问题
```

### 1.2 回测的价值

```
没有回测的问题：
-> 不知道策略的胜率
-> 不知道最大回撤有多大
-> 不知道连续亏损会有几次
-> 无法评估策略是否可行

回测的价值：
-> 用历史数据验证想法
-> 发现策略的薄弱环节
-> 建立对策略的信心
-> 知道什么情况下会亏损
```

## 二、回测的基本步骤

### 2.1 手动回测

```
步骤1：明确交易规则
-> 入场条件是什么？
-> 出场条件是什么？
-> 止损止盈如何设定？

步骤2：选择测试数据
-> 至少5年的历史数据
-> 包含牛市和熊市
-> 数据要完整（OHLC+成交量）

步骤3：模拟交易
-> 按规则逐笔模拟
-> 记录每笔交易
-> 包括买入价、卖出价、盈亏

步骤4：统计分析
-> 计算胜率、盈亏比
-> 计算最大回撤
-> 评估整体表现
```

## 三、关键绩效指标

### 3.1 核心指标

| 指标 | 计算方法 | 优秀标准 |
|------|---------|---------|
| 胜率 | 盈利笔数/总笔数 | > 40% |
| 盈亏比 | 平均盈利/平均亏损 | > 2:1 |
| 最大回撤 | 峰值到谷值的最大跌幅 | < 20% |
| 年化收益 | 平均每年收益率 | > 15% |
| 夏普比率 | (收益-无风险收益)/波动率 | > 1.0 |
| 交易次数 | 总交易笔数 | 越多越可靠 |

### 3.2 指标解读

```
胜率 x 盈亏比 > 1 才能盈利

例如：
胜率40%，盈亏比3:1
期望 = 40% x 3 - 60% x 1 = 1.2 - 0.6 = 0.6 > 0
-> 系统盈利

胜率60%，盈亏比0.8:1
期望 = 60% x 0.8 - 40% x 1 = 0.48 - 0.4 = 0.08 > 0
-> 系统也盈利，但利润很薄

结论：
-> 高胜率 + 低盈亏比 = 可以但不稳定
-> 低胜率 + 高盈亏比 = 更稳健
```

### 3.3 最大回撤

```
最大回撤：从最高点到最低点的最大跌幅

计算方法：
-> 记录每个时点的资金曲线
-> 找出每个高点后的最大跌幅
-> 最大回撤 = 最大的那个跌幅

例如：
资金从10万涨到15万（高点）
然后跌到12万（低点）
回撤 = (15-12)/15 = 20%

最大回撤的意义：
-> 你能承受的最大亏损
-> 如果回撤太大，你会睡不着
-> 回撤 > 30% 大多数人都扛不住
```

## 四、常见回测陷阱

### 4.1 过度拟合

```
问题：
-> 针对历史数据过度优化参数
-> 历史表现完美
-> 实盘表现很差

原因：
-> 历史数据中的"噪音"被当成了"信号"
-> 参数太多，自由度太大

避免方法：
-> 参数越少越好
-> 用样本外数据验证
-> 逻辑简单明了的策略更好
```

### 4.2 幸存者偏差

```
问题：
-> 只测试现在还在的股票
-> 忽略了已经退市的公司
-> 回测结果偏乐观

避免方法：
-> 使用包含退市股票的数据
-> 考虑所有曾经上市的股票
-> 或者用指数成分股回测
```

### 4.3 忽视交易成本

```
问题：
-> 回测时不考虑手续费和滑点
-> 回测结果偏乐观
-> 实盘时成本吃掉利润

避免方法：
-> 加上佣金（万2.5）
-> 加上印花税（千1）
-> 加上滑点（每笔0.5%）
-> 考虑冲击成本
```

### 4.4 忽视市场条件

```
问题：
-> 只在牛市数据上回测
-> 忽略了熊市和震荡市
-> 策略在特定市场有效

避免方法：
-> 测试区间包含牛熊市
-> 至少5年以上数据
-> 在不同市场条件下分别测试
```

## 五、从回测到实盘

### 5.1 过渡步骤

```
步骤1：历史回测
-> 验证策略逻辑
-> 确认绩效指标
-> 5年以上数据

步骤2：模拟盘测试
-> 用实时数据模拟
-> 至少3个月
-> 确认策略可执行

步骤3：小资金实盘
-> 用总资金的10%
-> 至少运行6个月
-> 对比回测结果

步骤4：逐步加仓
-> 确认实盘结果符合预期
-> 逐步增加资金
-> 不要一次all in
```

### 5.2 回测 vs 实盘的差异

```
常见差异：
-> 实盘胜率通常比回测低5-10%
-> 实盘滑点可能更大
-> 实盘情绪会影响执行
-> 实盘可能有意外情况

应对方法：
-> 回测结果打8折预期
-> 预留缓冲空间
-> 严格执行纪律
-> 持续记录和改进
```

## 六、总结

### 核心要点回顾

(1) **回测价值**：用历史数据验证策略，减少试错成本  
(2) **核心指标**：胜率、盈亏比、最大回撤  
(3) **盈利条件**：胜率 x 盈亏比 > 1  
(4) **常见陷阱**：过度拟合、幸存者偏差、忽视成本  
(5) **过渡步骤**：回测->模拟盘->小资金->逐步加仓  

### 实践建议

1. **先回测再实盘**：不要跳过这一步
2. **简单策略更好**：参数少、逻辑清晰
3. **考虑所有成本**：佣金、印花税、滑点
4. **多市场测试**：牛熊市都要测
5. **打8折预期**：实盘结果通常比回测差
