## 一、制造业投资框架

### 1.1 制造业分类与投资特征

| 细分领域 | 代表公司 | 驱动因素 | 周期特征 |
|---------|---------|---------|---------|
| 高端装备 | 中密控股、汇川技术 | 技术升级 | 弱周期 |
| 军工 | 中航沈飞、航发动力 | 国防预算 | 弱周期 |
| 船舶 | 中国船舶、中船防务 | 全球航运周期 | 强周期 |
| 工程机械 | 三一重工、中联重科 | 基建+地产 | 强周期 |
| 自动化 | 汇川技术、埃斯顿 | 智能制造 | 中周期 |

### 1.2 制造业投资的核心逻辑

制造业投资有三重逻辑：

1. **周期逻辑**：需求周期决定短期业绩
2. **成长逻辑**：国产替代+技术升级带来长期增长
3. **格局逻辑**：龙头集中度提升

投资优先级：成长大于格局大于周期（在成长赛道中找好格局，择时看周期）。

## 三、军工行业投资

### 3.1 军工产业链

军工产业链分为上中下游：

**上游（元器件+材料）**
- 军用芯片：紫光国微
- 连接器：中航光电、航天电器
- 碳纤维：光威复材、中简科技
- 特种钢：抚顺特钢

**中游（分系统+总装）**
- 航空发动机：航发动力
- 飞机总装：中航沈飞、中航西飞
- 导弹：航天彩虹
- 船舶：中国船舶
- 卫星：中国卫星

**下游（维修服务）**
- 航发维修：航发控制
- 飞机维修：中航电子

### 3.2 军工投资逻辑

军工行业有四个特殊性：

1. **需求确定**：国防预算持续增长（年均7至8%）
2. **信息不透明**：订单和收入难以跟踪
3. **估值偏高**：但确定性也高
4. **事件驱动**：地缘政治催化

核心跟踪指标：国防预算增速、装备费占比（从40%提升到60%以上）、主机厂交付节奏、预收账款/合同负债。

### 3.3 军工选股

| 选股维度 | 建议 |
|---------|------|
| 赛道选择 | 航空发动机、导弹、电子信息化 |
| 公司选择 | 主机厂、核心配套 |
| 估值方法 | PE 40-60x为合理 |
| 买入时机 | 估值回落到40x以下 |

## 四、船舶与海工

### 4.1 船舶周期

船舶行业是典型的长周期行业，每轮造船周期约20至25年：

需求增长带动订单增加和船价上涨，随后大量下单和产能扩张，交付高峰导致供给过剩和船价下跌，最后产能出清等待下一轮。

当前正处于新一轮上行周期，驱动因素包括：

- 老旧船舶更换需求
- 环保法规推动新船需求
- 产能出清后供给有限

### 4.2 关键指标

1. 新接订单量（CGT）
2. 手持订单量
3. 新造船价格指数
4. 钢材价格（成本端）
5. 全球航运运价（BDI等）

## 五、工程机械与基建链

### 5.1 工程机械周期

| 阶段 | 特征 | 操作 |
|------|------|------|
| 上行期 | 基建地产投资增加，更新需求 | 持有 |
| 顶部 | 销量创新高，但增速放缓 | 警惕 |
| 下行期 | 投资减少，库存高 | 回避 |
| 底部 | 销量见底，更新周期启动 | 逐步建仓 |

### 5.2 投资要点

工程机械的投资逻辑已从“国内周期”转变为“全球成长”：

**旧逻辑**：国内基建地产驱动，强周期特征。

**新逻辑**：出海+电动化+智能化，弱周期+成长性。关键变化包括：三一重工海外收入占比超过50%，电动化降低使用成本，智能化提升竞争力。

## 六、制造业升级趋势

### 6.1 六大升级方向

| 方向 | 说明 | 受益领域 |
|------|------|---------|
| 智能化 | AI+工业 | 工业机器人、视觉检测 |
| 电动化 | 新能源替代 | 电动工程机械、电驱 |
| 数字化 | 工业互联网 | 工业软件、传感器 |
| 绿色化 | 碳中和 | 节能设备、环保装备 |
| 服务化 | 从卖产品到卖服务 | 设备运维、远程诊断 |
| 国产替代 | 自主可控 | 高端装备、核心零部件 |

### 6.2 选股方法论

制造业选股可以从五个维度入手：

1. **选赛道**：国产替代空间大、技术壁垒高
2. **选龙头**：技术领先、客户粘性强
3. **看研发**：研发费用率持续提升
4. **看客户**：是否进入大客户供应链
5. **看出海**：海外收入占比提升

## 七、总结

### 核心要点回顾

1. 制造业投资看三条线：周期、成长、格局
2. 高端装备最有价值：国产替代+技术升级是长期主线
3. 军工看确定性：国防预算增长提供长期保障
4. 船舶是长周期：当前处于上行周期
5. 工程机械看全球：出海打开了新空间
