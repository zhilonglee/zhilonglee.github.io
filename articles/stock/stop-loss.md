# 铁律止损体系详解

> 🛡️ 止损是交易的生命线，不会止损就别做交易。本文详解如何建立铁一般的止损纪律，保住本金。

## 一、止损基础知识

### 1.1 为什么止损如此重要？

**名言：**
> "截断亏损，让利润奔跑。"  
> —— 华尔街格言

> "第一笔损失是最小的损失。"  
> —— 杰西·利弗莫尔

**止损的重要性：**
1. **保护本金**：避免小亏变大亏
2. **控制风险**：单笔损失可控
3. **保持主动**：随时可以重新入场
4. **心态稳定**：知道最坏情况是什么

**实例对比：**

**案例1：不止损**
```
买入价：10元
跌到9元：不舍得卖
跌到8元：幻想反弹
跌到5元：彻底套牢
结果：亏损50%，需要涨100%才能回本
```

**案例2：严格止损**
```
买入价：10元
止损位：9.5元（-5%）
触发止损：卖出
亏损：5%

下次再找机会
很快就能赚回来
```

**数学真相：**
```
亏损10% → 需要涨11%回本
亏损20% → 需要涨25%回本
亏损50% → 需要涨100%回本
亏损90% → 需要涨900%回本

结论：
越早止损，代价越小
```

---

### 1.2 止损的核心原则

#### （1）预设止损原则
```
买入前就设定止损位
不要等到亏了再想
提前计划，严格执行
```

#### （2）无条件执行原则
```
触发止损立即执行
不要犹豫
不要幻想
纪律胜于一切
```

#### （3）接受亏损原则
```
亏损是交易的一部分
没有人能100%正确
接受小亏，才能避免大亏
```

## 二、止损方法详解

### 2.1 固定比例止损 ⭐⭐⭐⭐

**定义：** 按照固定的亏损比例设置止损

**常用标准：**

| 交易类型 | 止损比例 | 说明 |
|---------|---------|------|
| 超短线 | 3%-5% | 快进快出 |
| 短线 | 5%-8% | 波段操作 |
| 中线 | 8%-15% | 趋势跟踪 |
| 长线 | 15%-20% | 价值投资 |

**操作方法：**
```
买入价：10元
止损比例：5%
止损价：9.5元

跌破9.5元：
→ 立即卖出
→ 不要犹豫
```

**优势：**
```
✅ 简单明了
✅ 容易计算
✅ 便于执行
```

**劣势：**
```
❌ 可能被洗出
❌ 不考虑技术位
❌ 过于机械
```

**适用场景：**
- 新手投资者
- 短线交易
- 不确定性高的交易

---

### 2.2 技术位止损 ⭐⭐⭐⭐⭐

**定义：** 根据关键技术位置设置止损

#### （1）支撑位止损

**方法：**
```
在重要支撑位下方设止损

支撑位包括：
- 前期低点
- 箱体下沿
- 密集成交区
- 整数关口
```

**实例：**
```
股票在10-12元箱体震荡
买入价：10.5元
支撑位：10元
止损位：9.8元（支撑位下方2%）

跌破9.8元：
→ 说明支撑失效
→ 立即止损
```

---

#### （2）均线止损

**方法：**
```
以重要均线为止损位

常用均线：
- 5日线：超短线
- 10日线：短线
- 20日线：中线
- 60日线：长线
```

**实例：**
```
沿20日线上涨的股票
买入价：10元
20日线：9.5元
止损位：9.3元（20日线下方）

跌破9.3元：
→ 趋势可能反转
→ 止损离场
```

---

#### （3）形态止损

**方法：**
```
出现破位形态立即止损

破位形态：
- 跌破上升趋势线
- 跌破颈线
- M顶确认
- 头肩顶确认
```

---

### 2.3 时间止损 ⭐⭐⭐

**定义：** 买入后一段时间不涨，无论盈亏都卖出

**常用标准：**
```
超短线：1-2天不涨 → 卖出
短线：3-5天不涨 → 卖出
中线：1-2周不涨 → 卖出
```

**操作方法：**
```
买入后第3天：
- 盈利 → 持有
- 亏损 → 止损
- 横盘 → 也卖出

原因：
资金有时间成本
不涨说明判断可能错误
释放资金寻找更好机会
```

**适用场景：**
- 题材炒作
- 事件驱动
- 追高买入

---

### 2.4 逻辑止损 ⭐⭐⭐⭐⭐

**定义：** 买入的逻辑不再成立时止损

**止损信号：**

#### （1）基本面恶化
```
业绩大幅下滑
行业政策变化
竞争格局恶化
→ 逻辑破坏
→ 立即止损
```

---

#### （2）题材退潮
```
龙头断板
板块集体下跌
亏钱效应大
→ 题材结束
→ 立即止损
```

---

#### （3）消息证伪
```
预期的利好没有发生
或消息被证伪
→ 逻辑不存在
→ 立即止损
```

**优势：**
```
✅ 从根本上止损
✅ 避免长期套牢
✅ 理性决策
```

---

### 2.5 移动止损法 ⭐⭐⭐⭐⭐

**定义：** 随着股价上涨，不断提高止损位

**操作方法：**

**方法1：固定比例移动**
```
股价每上涨10%
止损位提高5%

例如：
买入价：10元
初始止损：9.5元

涨到11元：
止损提高到10元（保本）

涨到12元：
止损提高到11元

以此类推...
```

---

**方法2：均线移动**
```
以20日线为止损位
股价上涨，20日线也上移
止损位跟着上移

跌破20日线：
→ 止损离场
```

---

**方法3：最高点回撤**
```
从最高点回撤一定比例止损

例如：
最高价：20元
回撤10%止损
止损价：18元

如果继续涨到25元
新的止损价：22.5元
```

**优势：**
```
✅ 保护利润
✅ 让利润奔跑
✅ 自动止盈
```

## 三、不同交易的止损策略

### 3.1 短线交易止损

**特点：**
- 持仓时间短
- 波动大
- 需要快速反应

**止损策略：**
```
止损比例：3%-5%
止损方式：固定比例 + 技术位
时间止损：2-3天不涨即卖

示例：
买入价：10元
止损价：9.5元（-5%）
或跌破5日线

触发任一条件：
→ 立即止损
```

---

### 3.2 中线交易止损

**特点：**
- 持仓时间中等
- 跟随趋势
- 容忍一定波动

**止损策略：**
```
止损比例：8%-15%
止损方式：趋势线 + 均线
时间止损：1-2周不涨即卖

示例：
买入价：10元
止损价：8.5元（-15%）
或跌破20日线

触发任一条件：
→ 止损离场
```

---

### 3.3 长线交易止损

**特点：**
- 持仓时间长
- 基于基本面
- 容忍较大波动

**止损策略：**
```
止损比例：15%-20%
止损方式：逻辑止损 + 估值止损
时间止损：不适用

示例：
买入逻辑：公司优质，低估
止损条件：
1. 基本面恶化
2. PE超过合理值
3. 亏损超过20%

触发任一条件：
→ 重新评估，考虑止损
```

## 四、止损心理管理

### 4.1 常见心理问题

#### （1）不舍得

**表现：**
```
已经亏损
但就是舍不得卖
幻想会反弹
结果越套越深
```

**对策：**
```
记住：第一笔损失最小
越早止损，代价越小
接受亏损是交易的一部分
```

---

#### （2）侥幸

**表现：**
```
触发止损信号
还幻想只是假突破
再等等看
结果大亏
```

**对策：**
```
宁可错杀，不可放过
错了就认，不要幻想
纪律胜于一切
```

---

#### （3）报复

**表现：**
```
刚止损就反弹
心里不平衡
立即追高买回
结果再次被套
```

**对策：**
```
接受现实
不要情绪化交易
冷静后再找机会
```

---

#### （4）恐惧

**表现：**
```
止损后害怕再次亏损
不敢再入场
错过好机会
```

**对策：**
```
止损是为了更好地进场
不要因为一次失败就放弃
相信自己的系统
```

---

### 4.2 心态修炼方法

**1. 接受亏损**
```
亏损是交易的成本
就像开店的租金
没有亏损就没有盈利
```

**2. 小亏即赢**
```
及时止损就是胜利
保住本金就有机会
活着比赚钱重要
```

**3. 记录总结**
```
记录每次止损决策
分析是否正确
持续改进
```

**4. 保持纪律**
```
制定规则就要执行
不因情绪改变
长期坚持形成习惯
```

## 五、止损 checklist

### 5.1 买入前检查

**止损规划：**
- [ ] 止损位设在哪里？
- [ ] 止损比例是多少？
- [ ] 最大可接受亏损是多少？
- [ ] 是否有明确的止损条件？

**心理准备：**
- [ ] 是否准备好接受亏损？
- [ ] 是否能严格执行止损？
- [ ] 是否有侥幸心理？

**全部打勾才能买入！**

---

### 5.2 持仓中监控

**每日检查：**
- [ ] 是否接近止损位？
- [ ] 止损逻辑是否还在？
- [ ] 是否需要调整止损位？

**触发止损：**
- [ ] 是否立即执行？
- [ ] 是否犹豫不决？
- [ ] 是否抱有幻想？

**该止损就止损，不要犹豫！**

---

### 5.3 止损后总结

**记录内容：**
- [ ] 这笔交易亏损多少？
- [ ] 止损是否及时？
- [ ] 有什么经验教训？
- [ ] 下次如何改进？

**心态调整：**
- [ ] 是否接受这次亏损？
- [ ] 是否影响下次交易？
- [ ] 是否需要休息调整？

## 六、常见误区与注意事项

### 6.1 常见误区

**❌ 误区1：不设止损**
```
正确做法：
买入前必须设止损
没有止损就不买
```

**❌ 误区2：止损太宽**
```
正确做法：
止损要合理
太宽失去意义
太窄容易被洗
```

**❌ 误区3：频繁调整止损**
```
正确做法：
止损一旦设定
不要轻易调整
除非有充分理由
```

**❌ 误区4：止损后立刻买回**
```
正确做法：
止损后冷静观察
不要情绪化交易
等待更好的机会
```

---

### 6.2 注意事项

**1. 止损要前置**
```
买入前就想好止损
写下来
不要临时决定
```

**2. 止损要坚决**
```
触发止损立即执行
不要犹豫
不要幻想
```

**3. 止损要合理**
```
根据交易类型设定
不要太宽也不要太窄
符合自己的风格
```

**4. 止损后要反思**
```
分析止损原因
是判断错误还是正常波动
持续改进系统
```
