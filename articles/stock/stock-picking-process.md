## 一、选股漏斗模型

### 1.1 五步漏斗

```
A股4000+只股票
     |
     v [第一步：广泛发现]
  观察池（100-200只）
     |
     v [第二步：快速筛选]
  候选池（20-50只）
     |
     v [第三步：深度研究]
  精选池（5-10只）
     |
     v [第四步：估值确认]
  目标池（3-5只）
     |
     v [第五步：买入决策]
  持仓（5-10只）
```

### 1.2 时间分配

| 步骤 | 时间投入 | 频率 |
|------|---------|------|
| 广泛发现 | 每天15分钟 | 每日 |
| 快速筛选 | 每次30分钟 | 每周 |
| 深度研究 | 每只2-3小时 | 按需 |
| 估值确认 | 每只1小时 | 按需 |
| 买入决策 | 15分钟 | 机会出现时 |

## 二、第一步：广泛发现

### 2.1 发现渠道

```
渠道1：行业研究
-> 关注景气度高的行业
-> 阅读行业研报
-> 关注政策方向

渠道2：生活观察
-> 你每天在用什么产品？
-> 哪些店铺总是排队？
-> 哪些品牌在扩张？

渠道3：财务数据筛选
-> 高ROE（>15%）
-> 高增速（>20%）
-> 低估值（PEG<1）

渠道4：市场热点
-> 哪些板块在领涨？
-> 资金在流向哪里？
-> 龙头是谁？

渠道5：机构持仓
-> 社保/保险/QFII买了什么？
-> 北向资金在加仓什么？
-> 公募基金重仓什么？
```

### 2.2 每日发现流程

```
每天15分钟：
1. 看涨幅榜前20（5分钟）
   -> 有没有新面孔？
   -> 有没有熟悉的行业？

2. 看资金流向（5分钟）
   -> 哪些板块资金流入多？
   -> 北向资金在买什么？

3. 看新闻/公告（5分钟）
   -> 有没有重大政策变化？
   -> 有没有重要公告？

发现感兴趣的股票 -> 放入观察池
```

## 三、第二步：快速筛选

### 3.1 财务快筛（5分钟/只）

```
快速筛选清单：

[ ] 1. ROE > 15%（过去3年）
[ ] 2. 净利润增速 > 15%（过去3年）
[ ] 3. 资产负债率 < 60%
[ ] 4. 经营现金流为正
[ ] 5. 毛利率 > 30%

全部满足 -> 进入候选池
不满足 -> 暂时搁置
```

### 3.2 估值快筛

```
估值快速判断：

[ ] PE是否低于行业平均？
[ ] PEG是否 < 1？
[ ] PE百分位是否低于70%？

满足2条以上 -> 估值合理，继续研究
都不满足 -> 估值偏高，暂时搁置
```

### 3.3 避雷快筛

```
快速排除：

-> 存贷双高？排除
-> 商誉占净资产 > 30%？排除
-> 审计意见非标准无保留？排除
-> 连续亏损或ST？排除
-> 大股东大量质押？警惕

有任何红旗 -> 排除
```

## 四、第三步：深度研究

### 4.1 公司分析（2-3小时/只）

```
深度研究清单：

业务分析：
[ ] 主营业务是什么？（一句话说清楚）
[ ] 收入构成？各业务占比？
[ ] 公司在行业中的地位？（第几名？）
[ ] 行业空间有多大？增速如何？

竞争优势：
[ ] 公司有什么护城河？（品牌/成本/网络/转换成本）
[ ] 护城河在加宽还是变窄？
[ ] 竞争对手是谁？差距大吗？

财务分析：
[ ] 读最近3年的年报
[ ] 分析收入增长驱动力
[ ] 分析毛利率变化趋势
[ ] 分析ROE杜邦分解
[ ] 检查现金流质量

管理层：
[ ] 创始人/CEO的背景
[ ] 管理层的持股情况
[ ] 有没有增持/减持记录
[ ] 管理层的战略眼光
```

### 4.2 行业分析

```
行业分析框架：

[ ] 行业处于什么阶段？（成长/成熟/衰退）
[ ] 行业增速如何？
[ ] 竞争格局如何？（集中度CR5）
[ ] 行业有没有政策风险？
[ ] 行业有没有技术替代风险？
[ ] 公司在行业中的优势？
```

## 五、第四步：估值确认

### 5.1 多种估值交叉验证

```
用3种以上方法估值：

方法1：PE估值
-> 合理PE x EPS = 合理价格

方法2：PEG估值
-> PEG < 1 = 低估

方法3：DCF估值
-> 未来现金流折现

方法4：同行对比
-> 对比同行业公司的估值

交叉验证：
-> 3种方法都显示低估 -> 强烈买入
-> 2种显示低估 -> 可以买入
-> 只有1种显示低估 -> 谨慎
-> 都显示高估 -> 不买入
```

### 5.2 安全边际确认

```
安全边际 = (内在价值 - 当前价格) / 内在价值

标准：
-> 安全边际 > 30% -> 很好，积极买入
-> 安全边际 20-30% -> 较好，正常买入
-> 安全边际 10-20% -> 一般，可以少量买
-> 安全边际 < 10% -> 太小，不建议买
```

## 六、第五步：买入决策

### 6.1 最终确认清单

```
买入前最终确认：

基本面：
[ ] 公司有明确的护城河？
[ ] 过去3年ROE > 15%？
[ ] 净利润增速 > 15%？
[ ] 现金流健康？

估值：
[ ] PEG < 1？
[ ] 安全边际 > 20%？
[ ] 多种方法交叉确认低估？

技术面：
[ ] 大趋势（周线）向上？
[ ] 处于支撑位附近？
[ ] 量价配合良好？

风险管理：
[ ] 止损位已设好？
[ ] 仓位合理（< 20%）？
[ ] 能承受最大亏损？

全部满足 -> 执行买入
```

## 七、买入后的预案

### 7.1 持仓管理计划

```
买入后立即制定：

上涨预案：
-> 涨到第一目标 -> 卖出1/3
-> 涨到第二目标 -> 再卖1/3
-> 剩余用移动止损保护

下跌预案：
-> 跌到止损位 -> 立即止损
-> 出现基本面恶化 -> 立即止损
-> 大盘系统性风险 -> 减仓

横盘预案：
-> 1个月内没有上涨 -> 评估是否持有
-> 3个月内没有上涨 -> 考虑换股
```

### 7.2 持续跟踪

```
跟踪频率：

每日：
-> 看一眼价格（不操作）
-> 有没有重大新闻？

每周：
-> 检查技术面（趋势是否还在）
-> 有没有资金异动？

每季度：
-> 读财报
-> 检查基本面是否变化
-> 评估投资逻辑是否还成立
```

## 八、总结

### 核心要点回顾

(1) **选股漏斗**：4000 -> 200 -> 50 -> 10 -> 5 -> 持仓  
(2) **广泛发现**：行业研究+生活观察+数据筛选  
(3) **快速筛选**：5分钟判断基本面+估值+避雷  
(4) **深度研究**：2-3小时分析公司+行业+财务  
(5) **估值确认**：多种方法交叉验证+安全边际  
(6) **买入决策**：全部条件满足才执行  

### 实践建议

1. **建立你的观察池**：从今天开始收集感兴趣的股票
2. **每周筛选一次**：用快速筛选清单过滤
3. **深度研究不超过10只**：精力有限，精选精研
4. **写下买卖理由**：买入和卖出时都写下来
5. **定期复盘**：检查你的选股成功率
