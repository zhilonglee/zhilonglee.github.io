# 筹码分布图分析

> 📊 筹码分布是揭示主力持仓成本的核心工具，看懂筹码就能洞察主力意图。本文详解筹码峰的实战应用。

## 一、筹码分布基础知识

### 1.1 什么是筹码分布？

**定义：** 筹码分布（Chip Distribution）也叫成本分布，显示在不同价格位置上投资者的持仓数量分布情况。

**核心思想：**
- 每一笔成交都形成筹码
- 筹码会在不同价格间转移
- 通过筹码分布可以看出主力的成本和意图

**通俗理解：**
```
想象一个战场：
- 每个价格是一个阵地
- 筹码是在这个阵地上的士兵
- 筹码多 = 士兵多 = 支撑/压力大
- 筹码少 = 士兵少 = 容易突破
```

---

### 1.2 筹码分布图的组成

**图形示意：**
```
价格  筹码量
      │
  20  │        ████
      │       ██████
  18  │      ████████    ← 筹码峰
      │     ██████████
  16  │    ████████████
      │   ██████████████
  14  │  ████████████████
      │ ██████████████████
  12  │████████████████████
      └───────────────────
```

**关键要素：**
- **横轴**：筹码数量（长度）
- **纵轴**：价格位置（高度）
- **筹码峰**：筹码集中的价格区域
- **筹码谷**：筹码稀少的价格区域

---

### 1.3 筹码的颜色含义

**常见颜色设置：**

#### （1）获利盘（红色）
```
当前股价上方的筹码
持有者处于盈利状态
抛压相对较小
```

#### （2）套牢盘（绿色/蓝色）
```
当前股价下方的筹码
持有者处于亏损状态
可能有割肉压力
```

#### （3）平均成本线（黄色）
```
所有筹码的平均成本
重要的参考价位
```

## 二、筹码峰形态详解

### 2.1 单峰密集 - 主力控盘 ⭐⭐⭐⭐⭐

**特征：**
- 筹码集中在一个狭窄的价格区间
- 形成一个明显的峰值
- 其他位置筹码很少

**图形：**
```
        ████
       ██████
      ████████  ← 单峰密集
       ██████
        ████
```

**含义：**
- 主力高度控盘
- 筹码集中度高
- 即将选择方向

**两种情况：**

#### （1）低位单峰密集
```
位置：股价经过长期下跌后
含义：主力吸筹完毕
操作：可逢低买入
预期：可能大幅拉升
```

**实例：**
```
某股票从30元跌到10元
在10-12元区间横盘3个月
筹码逐渐集中形成单峰

随后股价从10元涨到30元
```

---

#### （2）高位单峰密集
```
位置：股价经过大幅上涨后
含义：主力出货完毕
操作：应该离场
预期：可能大幅下跌
```

**实例：**
```
某股票从10元涨到50元
在48-52元区间横盘2个月
筹码从低位转移到高位形成单峰

随后股价从50元跌到20元
```

---

### 2.2 双峰形态 - 震荡整理

**特征：**
- 筹码分布在两个价格区间
- 形成两个峰值
- 中间有筹码谷

**图形：**
```
   ████        ████
  ██████      ██████
 ████████    ████████
  ██████      ██████
   ████        ████
   ↑            ↑
  下峰        上峰
```

**含义：**
- 多空分歧大
- 上下都有压力/支撑
- 震荡行情

**操作策略：**
```
股价在下峰附近 → 买入
股价在上峰附近 → 卖出
突破上峰 → 跟进
跌破下峰 → 离场
```

---

### 2.3 多峰分散 - 筹码松动

**特征：**
- 筹码分布在多个价格区间
- 没有明显的峰值
- 筹码分散

**图形：**
```
  ██    ██    ██
 ███  ███  ███
███████████████
 ███  ███  ███
  ██    ██    ██
```

**含义：**
- 筹码分散
- 主力控盘度低
- 方向不明

**操作：**
```
⚖️ 观望为主
⚖️ 等待筹码集中
⚖️ 不要急于操作
```

---

### 2.4 发散形态 - 趋势行情

**特征：**
- 筹码沿价格方向发散
- 没有明显峰值
- 呈斜线分布

**图形：**
```
            █
          ███
        █████
      ███████
    █████████
  ███████████
```

**含义：**
- 趋势明确
- 筹码跟随价格上涨/下跌
- 顺势而为

**操作：**
```
向上发散 → 持股待涨
向下发散 → 空仓观望
```

## 三、筹码转移过程

### 3.1 主力建仓期

**特征：**
- 股价低位横盘
- 筹码从高位向低位转移
- 逐渐形成低位单峰

**过程：**
```
初期：筹码分散在各个价位
中期：高位筹码逐渐减少
后期：低位筹码逐渐增多
末期：形成低位单峰密集
```

**识别方法：**
- 观察筹码是否从高位消失
- 观察低位筹码是否增加
- 观察是否形成单峰

**操作：**
```
✅ 可在低位单峰形成后买入
✅ 设置止损（单峰下方）
✅ 耐心等待拉升
```

---

### 3.2 主力拉升期

**特征：**
- 股价快速上涨
- 低位筹码锁定良好
- 筹码峰随股价上移但底部仍有筹码

**过程：**
```
启动：突破低位单峰
拉升：股价远离成本区
途中：部分筹码获利了结
继续：主力锁仓拉升
```

**识别方法：**
- 观察低位筹码是否还在
- 观察是否有新的筹码峰形成
- 观察筹码是否稳定

**操作：**
```
✅ 持股待涨
✅ 直到高位形成新单峰
❌ 不要轻易下车
```

---

### 3.3 主力出货期

**特征：**
- 股价高位横盘或震荡
- 筹码从低位向高位转移
- 逐渐形成高位单峰

**过程：**
```
初期：低位筹码开始减少
中期：高位筹码逐渐增多
后期：筹码完全转移到高位
末期：形成高位单峰密集
```

**识别方法：**
- 观察低位筹码是否消失
- 观察高位筹码是否增加
- 观察是否形成高位单峰

**操作：**
```
❌ 坚决清仓
❌ 不要抱幻想
❌ 立即离场
```

---

### 3.4 主力洗盘期

**特征：**
- 股价短暂下跌
- 筹码基本不动
- 主力锁仓

**过程：**
```
打压：股价快速下跌
洗盘：散户恐慌卖出
承接：主力悄悄接货
恢复：股价快速拉回
```

**识别方法：**
- 观察筹码是否大幅转移
- 如果筹码基本不变 = 洗盘
- 如果筹码大量转移 = 出货

**操作：**
```
✅ 坚定持有
✅ 不要被洗出
✅ 可逢低加仓
```

## 四、筹码分布实战技巧

### 4.1 筹码集中度

**定义：** 筹码在某个价格区间的集中程度

**计算公式：**
```
筹码集中度 = (高价 - 低价) / 当前价 × 100%
```

**判断标准：**

| 集中度 | 含义 | 操作 |
|--------|------|------|
| < 10% | 高度集中 | 主力控盘，关注 |
| 10%-20% | 比较集中 | 可以参与 |
| 20%-30% | 一般集中 | 观望 |
| > 30% | 分散 | 回避 |

**应用：**
```
低位 + 高集中度 → 主力建仓完毕，买入
高位 + 高集中度 → 主力出货完毕，卖出
```

---

### 4.2 筹码穿透率

**定义：** 当前价格穿透的筹码比例

**含义：**
- 穿透率高 → 上方套牢盘少，阻力小
- 穿透率低 → 上方套牢盘多，阻力大

**应用：**
```
穿透率 > 80% → 上方压力小，可做多
穿透率 < 20% → 上方压力大，谨慎
```

---

### 4.3 获利比例

**定义：** 当前价格以上的筹码占总筹码的比例

**含义：**
- 获利比例高 → 多数人盈利，抛压小
- 获利比例低 → 多数人亏损，可能割肉

**判断标准：**

| 获利比例 | 市场状态 | 操作 |
|---------|---------|------|
| > 90% | 极度乐观 | 警惕见顶 |
| 70%-90% | 乐观 | 持股 |
| 50%-70% | 正常 | 观望 |
| 30%-50% | 悲观 | 关注 |
| < 30% | 极度悲观 | 准备抄底 |

## 六、筹码分布注意事项

### 6.1 筹码分析的局限性

**1. 滞后性**
- 筹码数据基于历史成交
- 无法预测未来
- 需要结合其他指标

**2. 估算误差**
- 软件计算的筹码是估算值
- 不是真实数据
- 可能有偏差

**3. 主力对倒**
- 主力可以通过对倒制造假象
- 需要综合判断
- 不要单一依赖

---

### 6.2 新手常见错误

**❌ 错误1：只看筹码不看价格**
```
正确做法：筹码和价格结合分析
```

**❌ 错误2：忽视时间因素**
```
正确做法：观察筹码变化的过程
```

**❌ 错误3：过度解读**
```
正确做法：筹码只是参考之一
```

**❌ 错误4：频繁操作**
```
正确做法：等待明确的信号
```

- [ ] 成交量是否配合？
- [ ] MACD是否支持？

- [ ] 是否形成高位单峰？
