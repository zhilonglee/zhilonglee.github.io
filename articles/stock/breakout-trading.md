## 一、突破交易的核心逻辑

### 1.1 什么是突破？

突破是指股价突破前期重要的阻力位（如前高、趋势线、形态上沿等），标志着多空力量发生根本性转变，趋势可能启动。

突破的本质是：阻力位是大量卖单集中的位置，突破意味着买盘力量超过卖盘力量，多方占据绝对优势，趋势可能启动。

### 1.2 突破 vs 低吸

| 维度 | 突破交易 | 低吸交易 |
|------|---------|---------|
| 买入位置 | 阻力位上方 | 支撑位附近 |
| 确定性 | 方向已确认 | 需要等待确认 |
| 成本 | 较高 | 较低 |
| 止损 | 突破位下方 | 支撑位下方 |
| 适用场景 | 趋势启动时 | 趋势回调时 |

## 二、突破类型分类

### 2.1 按突破对象分类

| 突破类型 | 说明 | 可靠度 |
|---------|------|--------|
| 前高突破 | 突破前期高点 | 高 |
| 趋势线突破 | 突破下降趋势线 | 中高 |
| 形态突破 | 突破整理形态上沿 | 高 |
| 均线突破 | 突破长期均线压制 | 中 |
| 整数关口突破 | 突破心理关口 | 中 |
| 成交密集区突破 | 突破筹码密集区 | 高 |

### 2.2 按突破方式分类

突破方式可分为四类：

1. **放量突破（最可靠）**：成交量放大到前期2倍以上，说明多方资金积极进攻
2. **缩量突破（需警惕）**：成交量不大就突破了，可能卖盘少，假突破概率较高
3. **跳空突破（最强）**：以缺口方式突破，买盘极其强劲
4. **反复突破（最可靠）**：多次测试后终于突破，说明突破有效

## 三、真假突破辨别

### 3.1 真突破特征

| 特征 | 说明 |
|------|------|
| 放量 | 突破当日成交量 > 2倍均量 |
| 收盘站稳 | 收盘价在阻力位上方3%以上 |
| 次日确认 | 次日不跌破突破位 |
| 均线多头 | 均线呈多头排列 |
| 板块配合 | 同板块多只股票突破 |

### 3.2 假突破特征

| 特征 | 说明 |
|------|------|
| 缩量 | 突破但量能不足 |
| 冲高回落 | 盘中突破但收盘回来 |
| 长上影线 | 上方抛压重 |
| 次日低开 | 突破次日即回落 |
| 孤军奋战 | 个股独立突破，板块不配合 |

### 3.3 辨别方法

突破确认可分三步：

**第一步：看当日**。收盘价是否站稳（突破位上方3%）？成交量是否放大（超过2倍均量）？K线形态是否强势（大阳线、无长上影）？

**第二步：看次日**。是否回踩突破位不破？成交量是否维持？

**第三步：看三天**。三天内是否不回破突破位？如果三天都站稳，则确认突破有效。

## 四、突破买入策略

### 4.1 三种买入方式

突破买入有三种方式：

**方式1：突破当日买入**。优点是不错过行情，缺点是可能假突破，适用于放量突破、跳空突破。

**方式2：回踩确认后买入（推荐）**。优点是确认突破有效，缺点是可能不回踩，适用于大多数突破场景。

**方式3：分批买入**。突破当日买入30%，回踩确认后加仓40%，放量上涨加仓30%。

### 4.2 止损设置

| 买入方式 | 止损位 | 说明 |
|---------|--------|------|
| 突破当日买入 | 突破位下方3-5% | 假突破止损 |
| 回踩买入 | 回踩低点下方3% | 跌破说明突破失败 |
| 分批买入 | 突破位下方5% | 统一止损 |

## 五、突破后的持仓与卖出

### 5.1 目标位测算

目标位测算有三种方法：

**方法1：形态测量法**。突破位到形态底部的距离等于目标涨幅。例：底部10元，突破位12元，则目标14元。

**方法2：前高法**。下一个目标位是前期更高的阻力位。

**方法3：倍数法**。整理时间越长，突破后涨幅越大。整理3个月，目标涨幅30至50%。

### 5.2 持仓策略

突破后的持仓原则：

1. 突破后不回破则持有
2. 回踩突破位不破则继续持有
3. 回踩后再次上涨可加仓
4. 跌破突破位则止损卖出

止盈方法：到达目标位减仓三分之一，涨幅30%以上减仓至50%，出现滞涨信号逐步清仓。

## 六、经典突破形态

### 6.1 平台突破

平台突破是最常见最可靠的突破形态：

特征：股价在某一区间横盘整理1至3个月，形成一个“平台”，某日放量突破平台上沿。

操作：突破当日或回踩确认后买入，止损设在平台中轴线。

### 6.2 三角形突破

上升三角形、对称三角形、下降三角形的突破，参考经典形态分析。

### 6.3 杯柄形态突破

杯柄形态（威廉·欧奈尔）是最经典的突破买入形态之一：

股价形成“杯子”形状（U型底），杯口右侧形成小回调（“柄”），突破杯口上沿即为买入信号。

## 七、总结

### 核心要点回顾

1. 突破是趋势起点：在阻力位被突破时参与
2. 放量突破最可靠：量能是判断真假突破的关键
3. 等确认再买入：回踩确认比突破当日买入更安全
4. 止损设突破位下方：跌破突破位必须止损
5. 整理越久突破越大：横盘时间决定突破后的涨幅空间
