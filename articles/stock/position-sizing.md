## 一、动态仓位的核心理念

### 1.1 为什么需要动态仓位？

固定仓位的问题：

满仓不动，牛市赚了但波动大，熊市亏惨了，长期收益不稳定。空仓不动，牛市踏空，熊市没亏，但长期跑输通胀。

动态仓位的优势是牛市高仓位多赚、熊市低仓位少亏，长期收益稳定，回撤小。

### 1.2 动态仓位的目标

| 目标 | 说明 |
|------|------|
| 控制回撤 | 最大回撤 < 15% |
| 平滑收益 | 年化波动率可控 |
| 提高夏普比率 | 单位风险收益更高 |
| 保持参与 | 不完全空仓，保持市场感觉 |

## 二、基于市场状态的仓位

### 2.1 市场状态分类

| 状态 | 特征 | 建议仓位 |
|------|------|---------|
| 强势 | 均线多头，量价配合 | 60-80% |
| 偏强 | 震荡偏强，趋势向上 | 40-60% |
| 震荡 | 方向不明，热点轮动快 | 20-40% |
| 偏弱 | 震荡偏弱，赚钱效应差 | 10-20% |
| 弱势 | 均线空头，普跌 | 0-10% |

### 2.2 判断市场状态

市场状态评估表（每周更新）：

1. **大盘趋势（25分）**：指数在20日均线上方（+10）、20日均线向上（+10）、60日均线向上（+5）
2. **赚钱效应（25分）**：涨停家数>30（+10）、上涨家数>下跌家数（+10）、连板股>5只（+5）
3. **成交量（25分）**：两市成交>1万亿（+10）、成交量5日均线向上（+10）、北向资金净流入（+5）
4. **板块活跃度（25分）**：有明确主线（+15）、板块轮动有序（+10）

总分对应仓位：80-100分强势（60-80%仓位），60-80分偏强（40-60%），40-60分震荡（20-40%），20-40分偏弱（10-20%），0-20分弱势（0-10%）。

## 三、基于波动率的仓位

### 3.1 波动率与仓位反比

核心原则是波动率越高管位越低，因为高波动等于高风险，需要降低仓位来控制总风险。公式为：仓位 = 目标风险 / 个股波动率。

示例：目标风险为总资金的2%，个股日波动率3%时仓位为67%，日波动率5%时仓位为40%。

### 3.2 ATR仓位法

ATR（Average True Range）仓位法步骤：

1. 计算个股20日ATR
2. 设定止损距离 = 2 × ATR
3. 计算仓位：仓位金额 = 可承受亏损金额 / (2 × ATR)，股数 = 仓位金额 / 股价

示例：总资金100万，单笔风险2%（2万），某股ATR=2元，股价40元，止损距离=4元，仓位金额=2万/4=5000股，仓位=5000×40=20万（20%仓位）。

## 四、基于账户表现的仓位

### 4.1 赢利加仓法

核心原则是赚钱了可以加仓，亏钱了必须减仓：

1. **连续盈利**每次加仓10%，但总仓位不超过80%
2. **连续亏损**每次减仓20%，直到总仓位降到20%以下
3. **单日大亏（>5%）**减仓50%，冷静1-3天后再加仓

目的是让利润奔跑（赚钱时仓位大），截断亏损（亏钱时仓位小）。

### 4.2 净值曲线管理

账户净值管理：设定净值曲线的"均线"（20日净值均线）。

净值在均线上方说明市场适合你，保持正常仓位。净值跌破均线说明市场不适合你，需要减仓。净值跌破均线10%则大幅减仓至20%。

这相当于给账户做了"趋势跟踪"。

## 五、综合仓位管理模型

### 5.1 三维仓位模型

最终仓位 = min(市场状态仓位, 波动率仓位, 账户表现仓位)

三个维度分别给出仓位上限、单笔仓位和动态调整，三者取最小值，确保风险可控。

### 5.2 仓位调整节奏

| 调整频率 | 调整内容 |
|---------|---------|
| 每日 | 根据盈亏微调 |
| 每周 | 评估市场状态，调整总仓位 |
| 每月 | 全面复盘，调整策略 |
| 重大事件 | 立即调整（如黑天鹅） |

### 5.3 仓位管理纪律

仓位管理铁律：

1. **永远不满仓**，至少保留10%现金
2. **永远不空仓**，至少保留10%仓位（保持感觉）
3. **亏损必减仓**，连续亏损3笔减至30%
4. **盈利可加仓**，但不超过80%
5. **不借钱炒股**，杠杆是最危险的仓位管理错误

---

## 六、总结

### 核心要点回顾

1. 动态仓位优于固定仓位：根据市场灵活调整
2. 市场状态决定仓位上限：强势高仓位，弱势低仓位
3. 波动率决定单笔仓位：高波动低仓位
4. 账户表现决定调整方向：赚钱加仓，亏钱减仓
5. 永远不满仓不空仓：保留灵活性
