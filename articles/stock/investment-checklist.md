## 一、为什么需要检查清单？

### 1.1 清单的价值

```
没有清单的问题：
-> 凭感觉买卖
-> 容易遗漏关键信息
-> 受情绪影响大
-> 决策质量不稳定

有清单的好处：
-> 系统化决策
-> 减少遗漏
-> 降低情绪影响
-> 提高决策质量

数据支持：
-> 使用清单的投资者，决策正确率提高20%+
-> 避免的损失远超清单的时间成本
```

## 二、买入前检查清单

### 2.1 基本面检查（10条）

```
[ ] 1. 公司主营业务是什么？你能用一句话说清楚吗？
[ ] 2. 公司有什么竞争优势（护城河）？
[ ] 3. 过去3年ROE是否 > 15%？
[ ] 4. 过去3年净利润增速是否 > 15%？
[ ] 5. 资产负债率是否 < 60%？
[ ] 6. 经营现金流是否持续为正？
[ ] 7. 毛利率是否稳定或上升？
[ ] 8. 应收账款增速是否合理（不超过收入增速太多）？
[ ] 9. 有没有财务造假红旗信号？（存贷双高等）
[ ] 10. 管理层是否诚信可靠？
```

### 2.2 估值检查（5条）

```
[ ] 11. PE是否在合理范围？（低于历史均值）
[ ] 12. PEG是否 < 1？（成长股）
[ ] 13. 估值是否低于行业平均？
[ ] 14. 安全边际是否 > 20%？
[ ] 15. 当前估值分位是否低于70%？
```

### 2.3 技术面检查（3条）

```
[ ] 16. 大趋势是否向上？（周线/月线）
[ ] 17. 是否处于支撑位附近？
[ ] 18. 量价配合是否良好？
```

### 2.4 风险检查（2条）

```
[ ] 19. 如果跌30%，你能承受吗？
[ ] 20. 这笔投资在你的组合中占比是否合理（< 20%）？
```

### 2.5 决策规则

```
20条检查：
-> 全部满足 -> 可以买入
-> 15条以上满足 -> 可以小仓位买入
-> 15条以下 -> 不建议买入

注意：
-> 第19和20条是必须的
-> 承受不了亏损就不买
-> 仓位不合理就不买
```

## 三、持有中检查清单

### 3.1 月度检查

```
[ ] 1. 公司基本面有没有重大变化？
[ ] 2. 行业环境有没有恶化？
[ ] 3. 管理层有没有负面新闻？
[ ] 4. 大股东有没有大额减持？
[ ] 5. 有没有新的竞争对手威胁？
```

### 3.2 季度检查

```
[ ] 6. 最新财报是否符合预期？
[ ] 7. 营收和利润增速是否稳定？
[ ] 8. 现金流是否健康？
[ ] 9. 毛利率有没有下降？
[ ] 10. 有没有需要更新投资逻辑的地方？
```

### 3.3 持有信号

```
继续持有的信号：
-> 基本面没有恶化
-> 投资逻辑没有被打破
-> 护城河依然宽广
-> 估值依然合理

需要警惕的信号：
-> 连续2个季度增速下降
-> 毛利率持续下降
-> 管理层频繁变动
-> 护城河在变窄
```

## 四、卖出前检查清单

### 4.1 基本面卖出信号

```
[ ] 1. 公司基本面是否恶化？
[ ] 2. 投资逻辑是否被打破？
[ ] 3. 护城河是否在变窄？
[ ] 4. 管理层是否出现问题？
[ ] 5. 行业前景是否转差？

任何一条满足 -> 考虑卖出
```

### 4.2 估值卖出信号

```
[ ] 6. 估值是否严重偏高（PE > 历史90%分位）？
[ ] 7. PEG是否 > 2？
[ ] 8. 安全边际是否已经消失？

任何一条满足 -> 考虑减仓
```

### 4.3 技术面卖出信号

```
[ ] 9. 周线趋势是否转弱？
[ ] 10. 重要支撑位是否被跌破？
[ ] 11. 是否出现量价背离？

任何一条满足 -> 考虑减仓
```

### 4.4 个人因素

```
[ ] 12. 是否发现更好的投资机会？
[ ] 13. 是否需要用钱？
[ ] 14. 这笔投资是否让你焦虑？

任何一条满足 -> 考虑调整仓位
```

## 五、建立你的检查清单

### 5.1 个性化清单

```
清单定制原则：

1. 根据你的投资风格
-> 价值投资 -> 基本面清单为主
-> 趋势交易 -> 技术面清单为主
-> 综合投资 -> 均衡清单

2. 根据你的经验
-> 新手 -> 清单更详细
-> 老手 -> 清单更精简

3. 根据你的错误模式
-> 经常忘记检查什么 -> 加入清单
-> 经常犯什么错误 -> 加入相应检查
```

### 5.2 清单迭代

```
定期更新清单：

每月复盘时：
-> 有没有遗漏的检查项？
-> 有没有不必要的检查项？
-> 有没有新的教训要加入？

每季度：
-> 根据最新经验调整
-> 删除无效的检查项
-> 加入新的检查项
```

## 六、总结

### 核心要点回顾

(1) **清单价值**：系统化决策，减少遗漏和情绪影响  
(2) **买入清单**：20条检查，覆盖基本面+估值+技术面+风险  
(3) **持有清单**：定期检查基本面变化和投资逻辑  
(4) **卖出清单**：基本面+估值+技术面+个人因素  
(5) **持续迭代**：根据经验不断优化清单  

### 实践建议

1. **打印出来**：把清单放在交易桌前
2. **每次过一遍**：买卖前认真检查
3. **记录结果**：哪些检查有效，哪些无效
4. **持续优化**：每月更新一次
5. **严格执行**：清单不过关就不交易
