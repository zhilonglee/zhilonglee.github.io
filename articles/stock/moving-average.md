## 一、均线基础知识

### 1.1 什么是均线？

**定义：** 移动平均线（Moving Average，简称MA）是将某一段时间的收盘价之和除以该周期所得的值连成的一条线。

**通俗理解：**
- 均线 = 过去N天的平均成本
- 反映市场在一段时间内的平均持仓成本
- 具有 smoothing（平滑）作用，过滤短期波动

**计算公式：**
```
5日均线 = (今天收盘价 + 前4天收盘价) / 5
10日均线 = (今天收盘价 + 前9天收盘价) / 10
...以此类推
```

### 1.2 均线的本质

**核心意义：**
1. **成本线**：代表这段时间内买入者的平均成本
2. **趋势线**：显示价格运行的方向
3. **支撑/压力线**：对股价起到支撑或压制作用
4. **心理线**：影响投资者的买卖决策

**举例说明：**
```
某股票20日均线为10元：
→ 过去20天买入的人平均成本是10元
→ 如果现价12元，大部分人盈利，抛压小
→ 如果现价8元，大部分人亏损，可能割肉
```

## 二、常用均线周期详解

### 2.1 短期均线（超短线交易）

#### （1）5日均线 - 攻击线 ⚡

**特点：**
- 最敏感的均线
- 紧贴股价波动
- 反应迅速，但假信号多

**适用场景：**
- 超短线交易（1-3天）
- 强势股追踪
- 快速进出

**实战用法：**
```
✅ 股价站稳5日线 → 短期强势，可持有
❌ 股价跌破5日线 → 短期走弱，考虑减仓
⚠️ 5日线拐头向下 → 警惕回调
```

**注意事项：**
- 震荡市中容易反复穿越，失效
- 需要配合其他指标使用
- 不适合新手单独使用

---

#### （2）10日均线 - 操盘线 🎯

**特点：**
- 短线交易的核心参考
- 比5日线稳定，比20日线灵敏
- 平衡了敏感性和稳定性

**适用场景：**
- 短线波段操作（3-10天）
- 趋势跟踪
- 止损参考

**实战用法：**
```
✅ 股价沿10日线上行 → 短线上升趋势，持股
❌ 股价跌破10日线 → 短线趋势转弱，减仓或离场
⚠️ 10日线走平 → 进入震荡，观望
```

**经典策略：**
- 10日线向上 + 股价在10日线上方 = 做多
- 10日线向下 + 股价在10日线下方 = 做空或空仓

---

### 2.2 中期均线（中线投资）

#### （3）20日均线 - 生命线 ⭐⭐⭐

**重要性：** **最重要的均线之一！**

**特点：**
- 一个月交易日约20天
- 代表月度平均成本
- 稳定性和灵敏度平衡最佳

**适用场景：**
- 中线投资（1-3个月）
- 趋势判断的核心依据
- 重要的支撑/压力位

**实战用法：**
```
✅ 股价站稳20日线 + 20日线向上 → 中线走强，可加仓
❌ 股价跌破20日线 + 20日线向下 → 中线走弱，必须减仓
⚠️ 20日线走平 + 股价围绕震荡 → 方向不明，观望
```

**关键技巧：**
- **第一次跌破20日线**：可能是假突破，观察1-2天
- **第二次跌破20日线**：确认走弱，坚决离场
- **20日线角度**：向上角度越陡，趋势越强

**为什么叫"生命线"？**
- 很多主力资金以20日线为操作基准
- 跌破20日线往往意味着主力撤退
- 守住20日线，就守住了中线趋势

---

#### （4）30日均线 - 辅助线

**特点：**
- 介于20日和60日之间
- 有些投资者偏好使用
- 与20日线功能类似

**使用建议：**
- 可以替代20日线使用
- 或者与20日线配合使用
- 不是必须的，根据个人习惯

---

### 2.3 中长期均线（长线投资）

#### （5）60日均线 - 决策线 ⭐⭐

**特点：**
- 一个季度交易日约60天
- 代表季度平均成本
- 稳定性强，滞后性也强

**适用场景：**
- 中长线投资（3-6个月）
- 牛熊分界的重要参考
- 大趋势判断

**实战用法：**
```
✅ 股价站稳60日线 + 60日线向上 → 中长期走强，可重仓
❌ 股价跌破60日线 + 60日线向下 → 中长期走弱，轻仓或空仓
⚠️ 60日线走平 → 大趋势不明，谨慎操作
```

**重要意义：**
- 60日线向上 = 牛市特征
- 60日线向下 = 熊市特征
- 机构和大资金非常关注60日线

---

#### （6）120日均线 - 半年线

**特点：**
- 半年交易日约120天
- 长期趋势参考
- 非常稳定，但滞后严重

**适用场景：**
- 长线投资（6个月以上）
- 大周期趋势判断
- 价值投资参考

**实战用法：**
- 主要用于确认长期趋势
- 不用于短线买卖点判断
- 适合长线投资者参考

---

#### （7）250日均线 - 年线/牛熊线 ⭐⭐⭐

**重要性：** **长期投资的终极参考！**

**特点：**
- 一年交易日约250天
- 代表年度平均成本
- 最稳定的均线，滞后性最强

**适用场景：**
- 超长线投资（1年以上）
- 牛熊市的最终判断
- 战略配置参考

**实战用法：**
```
✅ 股价站稳年线 + 年线向上 → 牛市，可积极做多
❌ 股价跌破年线 + 年线向下 → 熊市，应该空仓或极轻仓
⚠️ 年线走平 → 牛熊转换期，谨慎观望
```

**为什么叫"牛熊线"？**
- 年线向上 = 牛市格局
- 年线向下 = 熊市格局
- 突破年线 = 牛熊转换的重要信号

**历史验证：**
- A股历次大牛市，都始于股价站上并突破年线
- A股历次大熊市，都始于股价跌破并远离年线

## 三、单根均线的实战应用

### 3.1 均线方向判断趋势

**三种状态：**

#### （1）均线向上 ↗️
```
    /
   /
  /
 /
```
- **含义**：趋势向上，多头主导
- **操作**：持股或逢低买入
- **强度判断**：角度越陡，趋势越强

#### （2）均线走平 ➡️
```
───────
```
- **含义**：趋势不明，多空平衡
- **操作**：观望，等待方向选择
- **注意**：可能是变盘前兆

#### （3）均线向下 ↘️
```
\
 \
  \
   \
```
- **含义**：趋势向下，空头主导
- **操作**：持币或逢高卖出
- **强度判断**：角度越陡，跌势越猛

---

### 3.2 均线作为支撑位

**原理：**
- 均线代表平均成本
- 股价回调到均线时，前期买入者不愿亏钱卖出
- 新买家认为价格合理，愿意买入
- 形成支撑

**实战应用：**
```
上升趋势中：
股价上涨 → 回调到20日线 → 获得支撑 → 再次上涨

操作：
- 在20日线附近买入
- 止损设在20日线下方2-3%
- 成功率较高
```

**支撑强度排序：**
1. 250日线 > 120日线 > 60日线（长期均线支撑更强）
2. 多次测试未破的均线 > 首次测试的均线
3. 向上的均线 > 走平的均线 > 向下的均线

---

### 3.3 均线作为压力位

**原理：**
- 下跌趋势中，均线代表套牢盘成本
- 股价反弹到均线时，套牢者解套卖出
- 形成压力

**实战应用：**
```
下降趋势中：
股价下跌 → 反弹到20日线 → 遭遇压力 → 继续下跌

操作：
- 在20日线附近卖出或减仓
- 不要盲目抄底
- 等待有效突破后再介入
```

**压力强度排序：**
- 同支撑位，长期均线压力更强

## 四、多根均线的组合应用

### 4.1 多头排列 - 最强看涨信号 ⭐⭐⭐⭐⭐

**定义：**
短均线 > 中均线 > 长均线，且全部向上

**图形示意：**
```
5日线  ────────────↗
10日线 ─────────↗
20日线 ──────↗
60日线 ───↗
```

**特征：**
- ✅ 所有均线向上发散
- ✅ 股价在所有均线上方
- ✅ 均线间距逐渐扩大

**含义：**
- 极强多头趋势
- 各周期投资者都盈利
- 抛压最小，上涨阻力最小

**操作策略：**
- ✅ 重仓持有
- ✅ 回调到短期均线可加仓
- ✅ 直到出现空头排列再离场
- ❌ 不要轻易下车

**成功案例：**
- 贵州茅台2017-2020年
- 宁德时代2020-2021年
- 都是典型的多头排列大牛股

---

### 4.2 空头排列 - 最强看跌信号 ⭐⭐⭐⭐⭐

**定义：**
短均线 < 中均线 < 长均线，且全部向下

**图形示意：**
```
5日线  ↘────────────
10日线   ↘─────────
20日线     ↘───────
60日线       ↘─────
```

**特征：**
- ❌ 所有均线向下发散
- ❌ 股价在所有均线下方
- ❌ 均线间距逐渐扩大

**含义：**
- 极强空头趋势
- 各周期投资者都亏损
- 抛压沉重，下跌动能强劲

**操作策略：**
- ❌ 坚决空仓或极轻仓
- ❌ 不要抄底
- ❌ 反弹到均线是卖出机会
- ✅ 直到出现多头排列再考虑入场

**警示案例：**
- 中国石油2007年高点后
- 乐视网2017年崩盘
- 都是典型的空头排列大熊市

---

### 4.3 均线缠绕 - 震荡整理

**定义：**
多根均线纠缠在一起，方向不明

**图形示意：**
```
5日线  ~~~~~~~~
10日线 ~~~~~~~~
20日线 ~~~~~~~~
60日线 ~~~~~~~~
```

**特征：**
- 均线粘合，间距很小
- 方向不明确
- 股价在均线上下穿梭

**含义：**
- 多空力量均衡
- 市场在蓄势
- 即将选择方向

**操作策略：**
- ⚖️ 观望为主
- ⚖️ 降低仓位
- ⚖️ 等待突破信号
- ✅ 向上突破 + 放量 → 跟进
- ✅ 向下突破 + 放量 → 离场

**注意：**
- 均线缠绕时间越长，突破后的行情越大
- "横有多长，竖有多高"

---

### 4.4 金叉与死叉

#### （1）金叉（Golden Cross）- 买入信号

**定义：**
短期均线上穿长期均线

**常见组合：**
- 5日金叉10日
- 10日金叉20日
- 20日金叉60日 ⭐（最重要）
- 60日金叉120日
- 120日金叉250日 ⭐⭐（牛熊转换）

**图形示意：**
```
短期均线  ╱──────
         ╱
        ╱
长期均线 ────────
       ↑
     金叉点
```

**可靠性排序：**
1. 长期均线金叉 > 短期均线金叉
2. 低位金叉 > 高位金叉
3. 放量金叉 > 缩量金叉
4. 均线向上时的金叉 > 均线走平时的金叉

**实战应用：**
```
20日金叉60日 + 成交量放大 + 低位出现
→ 强烈的中线买入信号
→ 可分批建仓
→ 止损设在金叉点下方
```

---

#### （2）死叉（Death Cross）- 卖出信号

**定义：**
短期均线下穿长期均线

**常见组合：**
- 5日死叉10日
- 10日死叉20日
- 20日死叉60日 ⭐（最重要）
- 60日死叉120日
- 120日死叉250日 ⭐⭐（牛熊转换）

**图形示意：**
```
短期均线 ──────╲
               ╲
                ╲
长期均线 ────────╲
                 ↑
               死叉点
```

**可靠性排序：**
- 同金叉，长期均线死叉更可靠

**实战应用：**
```
20日死叉60日 + 成交量放大 + 高位出现
→ 强烈的中线卖出信号
→ 立即减仓或清仓
→ 不要抱有幻想
```

## 五、均线实战技巧

### 5.1 葛兰碧八大法则（Granville's 8 Rules）

**买入信号（4个）：**

1. **均线走平转上，股价突破均线** → 买入
2. **股价跌破均线，但均线仍向上** → 买入（假突破）
3. **股价回调不破均线，再次上涨** → 买入
4. **股价暴跌远离均线** → 买入（超卖反弹）

**卖出信号（4个）：**

5. **均线走平转下，股价跌破均线** → 卖出
6. **股价突破均线，但均线仍向下** → 卖出（假突破）
7. **股价反弹不破均线，再次下跌** → 卖出
8. **股价暴涨远离均线** → 卖出（超买回调）

**图解：**
```
买入1: 均线转折向上，股价突破
买入2: 股价短暂跌破，但均线向上
买入3: 股价回踩均线获支撑
买入4: 股价远离均线，乖离率过大

卖出5: 均线转折向下，股价跌破
卖出6: 股价短暂突破，但均线向下
卖出7: 股价反弹遇均线压力
卖出8: 股价远离均线，乖离率过大
```

---

### 5.2 乖离率（BIAS）应用

**定义：**
股价与均线的偏离程度

**计算公式：**
```
乖离率 = (收盘价 - 均线值) / 均线值 × 100%
```

**应用原则：**
- **正乖离过大**（股价远高于均线）→ 超买，可能回调
- **负乖离过大**（股价远低于均线）→ 超卖，可能反弹

**参考标准（以20日线为例）：**
- 乖离率 > +10% → 超买，考虑减仓
- 乖离率 < -10% → 超卖，考虑买入
- 乖离率在 ±5% 以内 → 正常范围

**实战应用：**
```
案例1：
股价连续涨停，远离20日线
乖离率达到+20%
→ 严重超买
→ 随时可能大幅回调
→ 应该止盈

案例2：
股价连续跌停，远离20日线
乖离率达到-20%
→ 严重超卖
→ 可能出现报复性反弹
→ 可轻仓博反弹
```

---

### 5.3 均线+成交量配合

**最佳买入组合：**
```
✅ 股价突破均线 + 成交量放大 + 均线向上
→ 真突破，可靠性高

❌ 股价突破均线 + 成交量萎缩 + 均线走平
→ 假突破，容易回落
```

**最佳卖出组合：**
```
❌ 股价跌破均线 + 成交量放大 + 均线向下
→ 真跌破，立即离场

⚠️ 股价跌破均线 + 成交量萎缩 + 均线向上
→ 可能是假跌破，观察1-2天
```

## 六、常见误区与注意事项

### 6.1 均线的局限性

**1. 滞后性**
- 均线基于历史数据计算
- 信号出现时，行情已走出一段
- 无法预测未来

**应对：**
- 结合其他指标（如MACD、KDJ）
- 关注成交量变化
- 提前预判可能的支撑/压力位

**2. 震荡市失效**
- 横盘震荡时，均线频繁交叉
- 产生大量假信号
- 容易来回打脸

**应对：**
- 震荡市减少使用均线
- 改用布林带、KDJ等震荡指标
- 降低交易频率

**3. 单一均线不可靠**
- 单根均线容易产生误判
- 需要多根均线配合
- 需要其他指标验证

**应对：**
- 使用均线组（如5、10、20、60日）
- 结合形态、成交量、基本面
- 综合判断

---

### 6.2 新手常见错误

**❌ 错误1：只看一根均线**
```
正确做法：至少看3根均线（短、中、长）
```

**❌ 错误2：忽视均线方向**
```
正确做法：均线方向比位置更重要
向上均线支撑更强，向下均线压力更大
```

**❌ 错误3：均线一破就慌**
```
正确做法：
- 第一次跌破，观察1-2天
- 第二次跌破，确认离场
- 结合成交量判断真假突破
```

**❌ 错误4：过度依赖均线**
```
正确做法：
- 均线只是工具之一
- 需要结合K线、成交量、基本面
- 形成自己的交易系统
```

## ❓ 常见问题

**Q1: 均线应该看哪几条？太多会不会混乱？**
A: 建议新手先看3条：20日线（生命线）、60日线（决策线）、250日线（牛熊线）。熟练后可增加5日、10日线做短线。不要超过5条，否则会很混乱。

**Q2: 为什么均线金叉后股价反而跌了？**
A: 金叉只是参考信号，不是绝对保证。需要结合：①位置（低位金叉更可靠）；②成交量（放量金叉更可靠）；③整体趋势。单一信号成功率约60%。

**Q3: 震荡市中均线频繁交叉怎么办？**
A: 震荡市均线确实会失效。建议：①改用布林带、KDJ等震荡指标；②降低交易频率；③等待均线重新发散后再操作；④减少仓位。

**Q4: 20日线真的那么重要吗？**
A: 是的！20日线被称为"生命线"，因为：①代表月度成本；②主力资金常用；③稳定性和灵敏度平衡最佳。很多股票跌破20日线后就开启下跌趋势。

**Q5: 均线和MACD哪个更重要？**
A: 两者互补。均线看趋势方向，MACD看动能强弱。建议：①先用均线判断大趋势；②再用MACD找买卖点；③两者共振时信号最可靠。
