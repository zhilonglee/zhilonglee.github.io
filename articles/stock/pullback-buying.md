## 一、回调的本质与类型

### 1.1 回调为什么会发生？

回调有四个常见原因：

1. 获利盘兑现，短期赚钱了想落袋为安
2. 技术性修正，涨太快了需要“消化”
3. 市场恐慌，大盘下跌拖累个股
4. 资金切换，板块轮动导致资金流出

关键判断：正常回调是上涨趋势中的暂时调整（买入机会），趋势反转是上涨趋势结束（危险信号）。

### 1.2 回调 vs 反转

| 特征 | 正常回调 | 趋势反转 |
|------|---------|---------|
| 回调幅度 | < 前一波涨幅的50% | > 61.8% |
| 成交量 | 缩量 | 放量下跌 |
| 均线 | 中长期均线仍多头 | 均线开始走平或死叉 |
| 基本面 | 没有变化 | 出现重大利空 |
| 时间 | 5-20天 | 持续下跌 |

## 二、回调深度分析

### 2.1 黄金分割回调位

| 回调比例 | 强度 | 操作建议 |
|---------|------|---------|
| 23.6% | 极强（强势股） | 快速买入 |
| 38.2% | 较强 | 重点关注，常见买点 |
| 50.0% | 中等 | 重要分水岭 |
| 61.8% | 较弱 | 最后一个买点 |
| > 61.8% | 弱（可能是反转） | 观望 |

### 2.2 均线回调位

不同均线对应不同强度的回调：

- 5日线回调：极强趋势（连涨多日后的正常调整）
- 10日线回调：强趋势（正常的波段回调）
- 20日线回调：中趋势（较深回调，但趋势仍在）
- 60日线回调：弱趋势（深度回调，需重新评估）

## 三、回调买点确认

### 3.1 K线信号确认

| K线形态 | 说明 | 可靠度 |
|---------|------|--------|
| 锤子线 | 下影线长，实体小 | 高 |
| 早晨之星 | 三根K线组合反转 | 高 |
| 吞没形态 | 阳线吞没前一日阴线 | 中高 |
| 十字星 | 多空平衡，可能转折 | 中（需确认） |

### 3.2 买点确认三步法

买点确认可分三步：

**第一步：看回调幅度**。是否到了关键支撑位（均线、前低、黄金分割）？

**第二步：看止跌信号**。是否出现止跌K线（锤子线、十字星）？成交量是否萎缩到位？

**第三步：看确认信号**。是否出现放量阳线？是否突破回调高点？

三步全部满足则确认买入。

### 3.3 不同回调深度的买入策略

不同回调深度的买入策略：

**浅回调（小于38.2%）**：说明趋势很强，在5日或10日均线附近买入，仓位可以稍大。

**中回调（38.2至50%）**：最常见的回调幅度，在20日均线或黄金分割38.2%买入，分批建仓。

**深回调（50至61.8%）**：需要更谨慎，确认不是反转后再买，减小仓位。

## 四、不同时间级别的回调

### 4.1 日线级别回调

日线级别回调是最常见的操作级别：上涨趋势中回调3至10天，回调到10日或20日均线，适合波段交易者，持仓周期1至4周。

周线级别回调是更大的操作级别：上涨趋势中回调2至6周，回调到周线20周均线，适合中线投资者，持仓周期1至6个月。

60分钟级别回调是更精细的操作级别：日内趋势回调，回调到60分钟均线，适合日内交易者，持仓周期数小时到1至2天。

## 五、回调买入实战技巧

### 5.1 选股标准

适合回调买入的股票：

1. 处于明确上升趋势
2. 均线多头排列（5日大于10日大于20日大于60日）
3. 基本面良好（有业绩支撑）
4. 近期有明确的上涨逻辑
5. 回调时缩量

不适合回调买入的：下跌趋势中的“回调”（那是继续跌）、基本面恶化的股票、高位放量下跌的股票。

### 5.2 操作清单

| 步骤 | 内容 | 确认标准 |
|------|------|---------|
| 1. 确认趋势 | 日线均线多头排列 | 5>10>20>60 |
| 2. 等回调 | 回调到支撑位 | 均线/前低/黄金分割 |
| 3. 看量能 | 回调缩量 | 量比 < 1 |
| 4. 看K线 | 止跌信号 | 锤子线/十字星 |
| 5. 确认买入 | 放量阳线 | 阳线收复前阴线 |
| 6. 设止损 | 支撑位下方3-5% | 严格执行 |

## 六、总结

### 核心要点回顾

1. 回调是正常现象：上涨趋势中必有回调，回调是买入机会
2. 区分回调与反转：幅度、量能、均线是判断关键
3. 黄金分割38.2%是最佳买点：最常见的回调深度
4. 等确认再买入：止跌K线+放量阳线双重确认
5. 不同级别不同策略：日线适合波段，周线适合中线
