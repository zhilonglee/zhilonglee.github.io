# 核心估值指标体系

> 💰 估值是价值投资的核心，看懂估值才能判断股票贵还是便宜。本文详解PE、PB、PS、ROE四大核心估值指标。

## 一、估值基础知识

### 1.1 什么是估值？

**定义：** 估值（Valuation）是评估股票内在价值的过程，判断当前价格是高于还是低于真实价值。

**核心思想：**
- 价格围绕价值波动
- 低估时买入，高估时卖出
- 长期来看，价格会回归价值

**两种估值方法：**

#### （1）绝对估值
```
计算公司的内在价值
如：DCF现金流折现模型
优点：理论严谨
缺点：假设多，复杂
```

#### （2）相对估值
```
与同类公司或历史数据比较
如：PE、PB、PS等指标
优点：简单直观
缺点：受市场情绪影响
```

**本文重点：** 相对估值指标（PE、PB、PS、ROE）

---

### 1.2 为什么需要估值？

**估值的作用：**
1. **判断贵贱**：股票是便宜还是贵
2. **安全边际**：留出容错空间
3. **投资决策**：买还是卖的依据
4. **风险控制**：避免高位接盘

**名言：**
> "价格是你付出的，价值是你得到的。"  
> —— 沃伦·巴菲特

---

## 二、PE市盈率（Price-to-Earnings Ratio）

### 2.1 PE的定义

**公式：**
```
PE = 股价 / 每股收益（EPS）
   = 总市值 / 净利润
```

**通俗理解：**
- PE = 10：需要10年收回投资成本
- PE = 20：需要20年收回投资成本
- PE越低，理论上越便宜

**举例：**
```
某股票：
股价 = 20元
每股收益 = 1元
PE = 20 / 1 = 20倍

意味着：按当前盈利水平，20年回本
```

---

### 2.2 PE的三种类型

#### （1）静态PE（LYR）

**定义：** 使用上一年度的净利润

**公式：**
```
静态PE = 当前市值 / 上年度净利润
```

**优点：**
- 数据确定，不会变化
- 便于横向对比

**缺点：**
- 滞后性强
- 不能反映最新情况

**适用场景：**
- 年度财报刚发布时
- 稳定增长的公司

---

#### （2）动态PE（Forward PE）

**定义：** 使用预测的未来一年净利润

**公式：**
```
动态PE = 当前市值 / 预测净利润
```

**优点：**
- 前瞻性强
- 反映未来预期

**缺点：**
- 预测可能不准确
- 不同机构预测差异大

**适用场景：**
- 高成长公司
- 业绩变化快的公司

---

#### （3）滚动PE（TTM）⭐最常用

**定义：** 使用过去四个季度的净利润

**公式：**
```
滚动PE = 当前市值 / 最近4个季度净利润之和
```

**优点：**
- 数据最新
- 消除季节性影响
- 最准确

**缺点：**
- 需要每季度更新

**适用场景：**
- **大多数情况首选TTM**
- 实时估值参考

---

### 2.3 PE的合理范围

**一般标准：**

| PE范围 | 估值状态 | 操作建议 |
|--------|---------|---------|
| PE < 10 | 低估 | 可考虑买入 |
| 10 ≤ PE < 20 | 合理 | 持有观望 |
| 20 ≤ PE < 30 | 偏高 | 谨慎追高 |
| PE ≥ 30 | 高估 | 考虑减仓 |

**注意：** 不同行业PE差异很大！

---

### 2.4 不同行业的PE特点

#### （1）低PE行业（通常<15）

**银行、保险、地产：**
- PE通常在5-10倍
- 原因：增长慢、周期性强
- 策略：低PE不一定便宜，要看成长性

**钢铁、煤炭、水泥：**
- PE通常在5-15倍
- 原因：强周期、盈利波动大
- 策略：周期底部低PE可能是陷阱

---

#### （2）中等PE行业（通常15-30）

**消费、医药、家电：**
- PE通常在20-30倍
- 原因：稳定增长、防御性强
- 策略：合理PE可长期持有

**化工、机械、建材：**
- PE通常在15-25倍
- 原因：周期性+成长性
- 策略：结合周期判断

---

#### （3）高PE行业（通常>30）

**科技、互联网、新能源：**
- PE通常在30-60倍甚至更高
- 原因：高成长、未来预期好
- 策略：高PE不一定贵，要看增速

**生物制药、芯片：**
- PE可能在50-100倍
- 原因：研发投入大、未来潜力大
- 策略：高风险高回报

---

### 2.5 PEG指标（PE与成长性的结合）⭐

**定义：** PEG = PE / 净利润增长率

**公式：**
```
PEG = PE / 净利润同比增长率
```

**判断标准：**

| PEG值 | 含义 | 操作 |
|-------|------|------|
| PEG < 0.5 | 严重低估 | 强烈买入 |
| 0.5 ≤ PEG < 1 | 低估 | 买入 |
| 1 ≤ PEG < 1.5 | 合理 | 持有 |
| 1.5 ≤ PEG < 2 | 偏高 | 谨慎 |
| PEG ≥ 2 | 高估 | 卖出 |

**实例：**
```
公司A：
PE = 30倍
净利润增速 = 30%
PEG = 30 / 30 = 1 ← 合理估值

公司B：
PE = 20倍
净利润增速 = 10%
PEG = 20 / 10 = 2 ← 高估

结论：虽然A的PE更高，但考虑到成长性，A更值得投资
```

**优势：**
- 结合估值和成长
- 更适合成长股估值
- 彼得·林奇推崇的方法

---

### 2.6 PE的局限性

**❌ 问题1：不适用于亏损企业**
```
净利润为负，PE为负数，无意义
解决：改用PS（市销率）
```

**❌ 问题2：一次性收益扭曲**
```
出售资产导致利润暴增，PE虚低
解决：看扣非净利润
```

**❌ 问题3：周期性行业失真**
```
周期顶部利润高，PE低（陷阱）
周期底部利润低，PE高（机会）
解决：结合周期位置判断
```

**❌ 问题4：忽视资产负债表**
```
只看利润，不看负债
解决：结合PB（市净率）
```

## 三、PB市净率（Price-to-Book Ratio）

### 3.1 PB的定义

**公式：**
```
PB = 股价 / 每股净资产
   = 总市值 / 净资产
```

**通俗理解：**
- PB = 1：股价等于净资产
- PB < 1：股价低于净资产（破净）
- PB > 1：股价高于净资产

**举例：**
```
某公司：
总市值 = 100亿
净资产 = 50亿
PB = 100 / 50 = 2倍

意味着：花2块钱买1块钱的净资产
```

---

### 3.2 PB的合理范围

**一般标准：**

| PB范围 | 估值状态 | 操作建议 |
|--------|---------|---------|
| PB < 1 | 破净，低估 | 关注机会 |
| 1 ≤ PB < 2 | 合理偏低 | 可考虑买入 |
| 2 ≤ PB < 4 | 合理 | 持有观望 |
| PB ≥ 4 | 偏高 | 谨慎追高 |

**注意：** 不同行业PB差异很大！

---

### 3.3 适合用PB估值的行业

#### （1）重资产行业 ⭐最适合

**银行：**
- PB通常在0.5-1.5倍
- 原因：资产主要是贷款，容易估值
- 策略：PB<1可能是机会

**保险：**
- PB通常在1-3倍
- 原因：资产主要是投资组合
- 策略：结合内含价值判断

**地产：**
- PB通常在0.5-2倍
- 原因：资产主要是土地和房产
- 策略：PB<1可能是低估

**钢铁、煤炭、水泥：**
- PB通常在0.5-2倍
- 原因：资产主要是厂房设备
- 策略：周期底部PB低是机会

---

#### （2）不适合用PB的行业

**科技、互联网：**
- 资产主要是人才和技术
- 净资产不能反映真实价值
- 应用PE或PS更好

**医药、生物：**
- 资产主要是专利和研发
- 净资产被低估
- 应用PE或PS更好

**消费、服务：**
- 资产主要是品牌和客户
- 无形资产不在账面
- 应用PE更好

---

### 3.4 PB的特殊情况

#### （1）破净股（PB<1）

**含义：**
- 股价低于净资产
- 理论上可以清算获利

**可能原因：**
- ✅ 真的低估（机会）
- ❌ 资产质量差（陷阱）
- ❌ 盈利能力弱（合理）
- ❌ 行业衰退（回避）

**判断方法：**
```
看ROE：
ROE > 10% + PB < 1 → 可能是机会
ROE < 5% + PB < 1 → 可能是陷阱

看资产质量：
现金、房产多 → 质量好
应收账款、存货多 → 质量差
```

---

#### （2）高PB股（PB>5）

**含义：**
- 股价远高于净资产
- 市场给予高溢价

**可能原因：**
- ✅ 高成长性（合理）
- ✅ 轻资产模式（合理）
- ❌ 泡沫炒作（危险）
- ❌ 概念 hype（危险）

**判断方法：**
```
看成长性：
净利润增速 > 30% + 高PB → 可能合理
净利润增速 < 10% + 高PB → 可能泡沫

看行业：
科技、医药高PB常见
银行、地产高PB罕见
```

---

## 四、PS市销率（Price-to-Sales Ratio）

### 4.1 PS的定义

**公式：**
```
PS = 股价 / 每股销售收入
   = 总市值 / 营业收入
```

**通俗理解：**
- PS = 1：市值等于年销售额
- PS = 5：市值是年销售额的5倍
- PS越低，理论上越便宜

**适用场景：**
- **未盈利企业**（PE无法使用）
- **高成长企业**（利润不稳定）
- **早期科技公司**

---

### 4.2 PS的合理范围

**一般标准：**

| PS范围 | 估值状态 | 操作建议 |
|--------|---------|---------|
| PS < 1 | 低估 | 关注机会 |
| 1 ≤ PS < 3 | 合理 | 持有观望 |
| 3 ≤ PS < 10 | 偏高 | 谨慎追高 |
| PS ≥ 10 | 高估 | 考虑减仓 |

**注意：** SaaS、互联网公司PS通常较高

---

### 4.3 适合用PS估值的行业

#### （1）SaaS软件公司

**特点：**
- 前期投入大，亏损
- 收入稳定增长
- 客户粘性强

**典型PS：**
- 成熟SaaS：5-15倍
- 高成长SaaS：10-30倍
- 早期SaaS：20-50倍

**判断方法：**
```
看收入增速：
增速 > 50% + PS 10-20 → 合理
增速 < 20% + PS 10-20 → 高估

看毛利率：
毛利率 > 70% → 质量好
毛利率 < 50% → 质量一般
```

---

#### （2）电商平台

**特点：**
- 规模效应明显
- 前期亏损换市场
- 后期盈利能力强

**典型PS：**
- 成熟电商：1-3倍
- 成长电商：3-8倍
- 早期电商：5-15倍

---

#### （3）生物制药（未盈利）

**特点：**
- 研发投入巨大
- 暂无产品上市
- 未来潜力大

**典型PS：**
- 难以用PS估值
- 更多看管线价值
- 风险极高

---

### 4.4 PS的局限性

**❌ 问题1：忽视盈利能力**
```
收入高但亏损严重
PS低不代表便宜
解决：结合毛利率、净利率
```

**❌ 问题2：忽视成本控制**
```
同样收入，成本不同
利润差异巨大
解决：看利润率趋势
```

**❌ 问题3：不适用于传统行业**
```
传统行业利润稳定
用PE更合适
解决：选择合适的指标
```

---

## 五、ROE净资产收益率（Return on Equity）

### 5.1 ROE的定义

**公式：**
```
ROE = 净利润 / 净资产 × 100%
```

**通俗理解：**
- ROE = 15%：每100元净资产赚15元
- ROE越高，赚钱能力越强
- 巴菲特最看重的指标

**举例：**
```
公司A：
净利润 = 10亿
净资产 = 50亿
ROE = 10 / 50 = 20%

公司B：
净利润 = 5亿
净资产 = 50亿
ROE = 5 / 50 = 10%

结论：A的赚钱能力是B的2倍
```

---

### 5.2 ROE的评判标准

**巴菲特的标准：**
- **ROE > 20%**：优秀公司
- **15% < ROE < 20%**：良好公司
- **10% < ROE < 15%**：一般公司
- **ROE < 10%**：较差公司

**连续多年高ROE才是真优秀！**

---

### 5.3 ROE的杜邦分析

**杜邦公式：**
```
ROE = 净利率 × 总资产周转率 × 权益乘数
```

**三个驱动因素：**

#### （1）净利率（盈利能力）
```
净利率高 → 产品有竞争力
如：茅台净利率50%+
```

#### （2）总资产周转率（运营效率）
```
周转率高 → 资产利用效率高
如：沃尔玛薄利多销
```

#### （3）权益乘数（财务杠杆）
```
杠杆高 → 借钱经营
如：银行、地产高杠杆
风险：负债过高可能爆雷
```

**分析方法：**
```
高ROE的来源：
✅ 高净利率 → 真好（品牌、技术）
✅ 高周转率 → 真好（管理优秀）
❌ 高杠杆 → 警惕（风险大）
```

---

### 5.4 ROE的持续性

**关键：** 看ROE是否持续稳定

**优秀案例：**
```
贵州茅台：
2015-2023年，ROE持续在25%-35%
→ 真正的优质公司

格力电器：
2015-2020年，ROE持续在20%-30%
→ 优秀的制造业公司
```

**警惕案例：**
```
某公司：
2020年ROE突然从10%跳到30%
原因：出售资产一次性收益
→ 不可持续，不要追
```

**判断方法：**
- 至少看5年ROE
- 排除一次性收益
- 看ROE趋势（上升/下降/稳定）

---

### 5.5 ROE与估值的关系

**高ROE + 低PE = 最佳投资机会** ⭐⭐⭐⭐⭐

**四种组合：**

| ROE | PE | 评价 | 操作 |
|-----|----|------|------|
| 高 | 低 | 黄金机会 | 重仓买入 |
| 高 | 高 | 合理估值 | 适度参与 |
| 低 | 低 | 价值陷阱 | 谨慎回避 |
| 低 | 高 | 泡沫严重 | 坚决远离 |

**实例：**
```
公司A：ROE=25%, PE=15 → 黄金机会！
公司B：ROE=25%, PE=50 → 合理，但偏贵
公司C：ROE=8%, PE=10 → 看似便宜，实则陷阱
公司D：ROE=8%, PE=40 → 泡沫，快跑！
```

## 六、四大指标综合运用

### 6.1 估值指标对比表

| 指标 | 适用行业 | 优点 | 缺点 |
|------|---------|------|------|
| **PE** | 盈利稳定的公司 | 直观、常用 | 不适用于亏损企业 |
| **PB** | 重资产行业（银行、地产） | 反映资产价值 | 忽视盈利能力 |
| **PS** | 未盈利的高成长公司 | 适用于亏损企业 | 忽视盈利能力 |
| **ROE** | 所有行业（质量指标） | 反映赚钱能力 | 不是估值指标 |

---

### 6.2 估值流程

**Step 1：选择合适指标**
```
盈利稳定 → PE
重资产 → PB
未盈利高成长 → PS
所有公司 → 看ROE
```

**Step 2：横向对比**
```
与同行业其他公司比较
高于行业平均 → 可能高估
低于行业平均 → 可能低估
```

**Step 3：纵向对比**
```
与公司历史估值比较
处于历史低位 → 可能低估
处于历史高位 → 可能高估
```

**Step 4：综合判断**
```
结合多个指标
结合成长性（PEG）
结合行业前景
得出最终结论
```

---

### 6.3 实战案例

**案例：某消费品公司估值**

**数据：**
```
PE(TTM) = 25倍
PB = 6倍
PS = 4倍
ROE = 25%
净利润增速 = 20%
PEG = 25/20 = 1.25
```

**分析：**
```
1. PE=25：消费行业合理范围（20-30）
2. PB=6：偏高，但消费品轻资产，可接受
3. PS=4：合理
4. ROE=25%：优秀，持续5年以上
5. PEG=1.25：略高，但在合理范围

结论：估值合理，可持有，但不宜大幅加仓
```

## 七、估值注意事项

### 7.1 常见误区

**❌ 误区1：PE低就是便宜**
```
正确做法：结合成长性、行业特点
周期股低PE可能是陷阱
```

**❌ 误区2：ROE高就一定好**
```
正确做法：看ROE来源
高杠杆带来的高ROE有风险
```

**❌ 误区3：忽视行业差异**
```
正确做法：同行业对比
不同行业估值标准不同
```

**❌ 误区4：单一指标决策**
```
正确做法：多指标综合
结合定性分析
```

---

### 7.2 估值 checklist

**买入前检查：**
- [ ] PE是否在合理范围？
- [ ] PEG是否<1.5？
- [ ] ROE是否>15%且持续？
- [ ] 与同行业相比是否低估？
- [ ] 与历史估值相比是否低位？
- [ ] 成长性是否支撑当前估值？

**卖出前检查：**
- [ ] PE是否远高于历史平均？
- [ ] PEG是否>2？
- [ ] ROE是否下降？
- [ ] 是否远高于同行业？
- [ ] 成长性是否放缓？
- [ ] 是否有更好的投资机会？

## 八、核心要点回顾

✅ **PE市盈率**：最常用，适合盈利稳定公司，结合PEG看成长  
✅ **PB市净率**：适合重资产行业，破净可能是机会也可能是陷阱  
✅ **PS市销率**：适合未盈利高成长公司，忽视盈利能力是缺陷  
✅ **ROE净资产收益率**：衡量赚钱能力，巴菲特最看重，看持续性  
✅ **综合运用**：选择合适指标，横向+纵向对比，综合判断  
✅ **避免误区**：不单一依赖指标，结合行业和成长性
