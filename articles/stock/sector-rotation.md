## 一、板块轮动的本质

### 1.1 为什么会有板块轮动？

板块轮动有五个原因：

1. 资金有限，存量博弈，资金从A板块流向B板块
2. 信息传播，利好从核心扩散到相关板块
3. 估值修复，涨多了切换到低估值板块
4. 经济周期，不同阶段受益的行业不同
5. 政策驱动，政策利好从一个方向切换到另一个

### 1.2 A股板块分类

| 分类方式 | 示例 |
|---------|------|
| 行业板块 | 科技、消费、医药、金融 |
| 概念板块 | AI、新能源、信创、中特估 |
| 风格板块 | 大盘价值、小盘成长 |
| 主题板块 | 国企改革、一带一路 |

## 二、板块轮动规律

### 2.1 经济周期与板块轮动

美林时钟的A股版本：

- 经济复苏期：金融、地产、可选消费
- 经济繁荣期：周期品（有色、钢铁、化工）
- 经济过热期：能源、资源品
- 经济衰退期：必选消费、医药、公用事业
- 政策宽松期：券商、地产、基建

### 2.2 A股典型轮动节奏

| 阶段 | 领涨板块 | 特征 |
|------|---------|------|
| 牛市初期 | 券商、金融 | 行情启动器 |
| 牛市中期 | 科技、成长 | 赚钱效应最强 |
| 牛市后期 | 低价股、ST股 | 鸡犬升天，风险加大 |
| 震荡市 | 题材热点快速轮动 | 追涨杀跌易亏 |
| 熊市 | 消费、医药防御 | 抱团取暖 |

### 2.3 日内板块轮动

一天内的板块轮动规律：

- 9:30至10:00：最强板块率先启动
- 10:00至11:00：跟风板块补涨
- 11:00至11:30：轮动减速
- 13:00至14:00：新热点可能出现
- 14:00至15:00：尾盘定方向

## 三、轮动驱动因素

### 3.1 政策驱动

政策驱动轮动的特征：

1. 政策发布后相关板块短期暴涨
2. 持续性看政策力度和落地节奏
3. 利好出尽后板块回落

近年政策驱动案例：碳中和政策带动新能源板块，数字经济带动信创和AI板块，中特估带动央企蓝筹。

### 3.2 业绩驱动

业绩驱动轮动有三个特点：

1. 季报/年报期间，业绩超预期的板块领涨
2. 持续性强，有基本面支撑
3. 每年1月、4月、7月、10月是业绩窗口

跟踪方法：业绩预告（提前1个月）、行业高频数据、分析师一致预期变化。

### 3.3 资金驱动

资金驱动轮动的四类来源：

1. 北向资金加仓，消费、金融受益
2. 融资余额增加，科技、题材受益
3. 公募基金加仓，抱团龙头
4. 游资进入，小盘题材股受益

## 四、板块轮动跟踪方法

### 4.1 每日跟踪指标

| 指标 | 说明 | 数据来源 |
|------|------|---------|
| 板块涨幅排名 | 今日最强/最弱板块 | 同花顺/东财 |
| 板块资金流向 | 资金净流入/流出 | 同花顺/东财 |
| 涨停板分布 | 哪个板块涨停多 | 龙虎榜 |
| 北向资金动向 | 外资买什么 | 沪深港通 |
| 板块换手率 | 活跃度变化 | 行情软件 |

### 4.2 板块强度评分

板块强度可通过五个指标综合打分：

1. 近5日涨幅排名（20分）
2. 近5日资金净流入（20分）
3. 涨停家数（20分）
4. 板块内上涨家数占比（20分）
5. 龙头股表现（20分）

总分大于80为强势板块（关注），总分小于40为弱势板块（回避）。

### 4.3 轮动预警信号

板块即将轮动的信号：

1. **当前强势板块开始滞涨**：龙头股涨不动了，板块内分化加剧
2. **下一个板块开始异动**：龙头股率先上涨，资金开始流入，有政策或业绩催化
3. **成交量变化**：强势板块缩量，新板块放量

## 五、板块轮动交易策略

### 5.1 三种轮动策略

三种轮动策略：

**策略1：提前潜伏（最推荐）**。分析下一个可能轮动的板块，在轮动前买入，等待资金流入。

**策略2：确认后跟进**。板块已经启动，确认不是假突破后买入板块龙头。

**策略3：补涨逻辑**。龙头板块已经涨了很多，找相关的低位补涨板块。例如AI龙头涨完后，AI应用可能补涨。

### 5.2 板块龙头选择

| 选股维度 | 标准 |
|---------|------|
| 涨幅 | 板块内涨幅前3 |
| 辨识度 | 市场公认的龙头 |
| 封板时间 | 最先涨停 |
| 连板 | 有连板能力 |
| 市值 | 适中（50-500亿） |

### 5.3 卖出时机

板块轮动有五个卖出信号：

1. 板块龙头开始滞涨，减仓
2. 板块内大面积下跌，清仓
3. 资金大幅流出，减仓
4. 新的热点出现，切换
5. 板块涨幅过大（超过30%），分批止盈

## 六、实战案例与总结

### 6.1 2023-2024年轮动主线

2023年的轮动主线：AI、中特估、新能源反弹、消费。2024年的轮动主线：高股息、AI应用、低空经济、出海。

规律：每轮行情持续1至3个月，主线之间有交叉但不重叠，主线结束后有1至2周空窗期。

### 6.2 核心要点回顾

1. 板块轮动是A股核心特征：理解轮动比选个股更重要
2. 经济周期决定大方向：不同阶段买不同板块
3. 跟踪资金流向：资金去哪里，机会就在哪里
4. 提前潜伏优于追涨：预判下一个轮动方向
5. 龙头股是核心：每个板块只买龙头
