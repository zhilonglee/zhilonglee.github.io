## 一、新能源行业全景图

### 1.1 产业链概览

新能源产业链可分为上游、中游、下游三个环节：

**上游（资源+材料）**
- 锂矿：天齐锂业、赣锋锂业
- 钴矿：华友钴业、洛阳钼业
- 硅料：通威股份、大全能源
- 正极材料：当升科技、容百科技

**中游（制造）**
- 电池：宁德时代、比亚迪
- 光伏组件：隆基绿能、晶科能源
- 风机：金风科技、明阳智能
- 储能：阳光电源、派能科技

**下游（应用+运营）**
- 新能源车：比亚迪、长安汽车
- 光伏电站：三峡能源、龙源电力
- 充电桩：特锐德、万马股份
- 换电服务：蔚来

### 1.2 新能源行业投资特征

| 特征 | 说明 |
|------|------|
| 政策驱动 | 补贴、碳交易、双碳目标 |
| 技术迭代快 | 电池技术、光伏效率持续提升 |
| 产能周期 | 大规模扩产导致供需波动 |
| 全球竞争 | 中国在全球供应链中占主导 |
| 成本下降 | 度电成本持续下降，平价上网 |

## 二、锂电池产业链

### 2.1 锂电池产业链图谱

| 环节 | 代表公司 | 竞争格局 |
|------|---------|---------|
| 锂矿 | 天齐锂业、赣锋锂业 | 全球寡头 |
| 正极材料 | 当升科技、容百科技 | 技术分化 |
| 负极材料 | 璞泰来、杉杉股份 | 集中度高 |
| 电解液 | 天赐材料、新宙邦 | 龙头集中 |
| 隔膜 | 恩捷股份、星源材质 | 寡头格局 |
| 电芯 | 宁德时代、比亚迪 | 双寡头 |

### 2.2 电池技术路线

电池技术分为当前主流和下一代技术：

**当前主流**：
- 磷酸铁锂（LFP）：成本低、安全，但能量密度低
- 三元（NCM）：能量密度高，但成本高

**下一代技术**：
- 钠离子电池：成本更低，适合储能
- 固态电池：安全性高，能量密度高（预计2027年量产）
- 4680大圆柱：特斯拉主推，成本优化

### 2.3 关键跟踪指标

1. 碳酸锂价格（锂矿景气度）
2. 电池装机量（月度数据）
3. 产能利用率
4. 海外收入占比
5. 技术路线进展

## 三、光伏产业链

### 3.1 光伏产业链

| 环节 | 代表公司 | 说明 |
|------|---------|------|
| 硅料 | 通威股份、大全能源 | 产能集中 |
| 硅片 | 隆基绿能、TCL中环 | 大尺寸趋势 |
| 电池片 | 通威股份、爱旭股份 | TOPCon/HJT |
| 组件 | 隆基、晶科、天合光能 | 品牌+渠道 |
| 逆变器 | 阳光电源、锦浪科技 | 高毛利环节 |
| 电站运营 | 三峡能源 | 稳定现金流 |

### 3.2 光伏技术迭代

光伏技术路线正经历迭代升级：PERC（当前主流）、TOPCon（主流切换中）、HJT（下一代）、钙钛矿（远期）。

每次技术迭代都会带来新的投资机会：
- 新设备公司受益（迈为股份、捷佳伟创）
- 率先量产的公司获得超额利润
- 老产能面临淘汰

### 3.3 光伏投资周期

| 阶段 | 特征 | 操作 |
|------|------|------|
| 扩产期 | 产能快速增加 | 关注设备商 |
| 过剩期 | 供大于求，价格下跌 | 回避制造端 |
| 出清期 | 落后产能退出 | 关注龙头 |
| 复苏期 | 需求回暖，价格企稳 | 买入龙头 |

## 四、风电与储能

### 4.1 风电产业链

| 环节 | 代表公司 | 趋势 |
|------|---------|------|
| 整机 | 金风科技、明阳智能 | 大型化 |
| 叶片 | 中材科技 | 大叶片 |
| 塔筒 | 大金重工 | 海上风电 |
| 海缆 | 东方电缆、中天科技 | 海上风电核心 |

### 4.2 储能：新能源的"刚需"

储能之所以是新能源的“刚需”，原因有三：

- 光伏风电有间歇性（没太阳没风就没电）
- 电网需要调峰调频
- 储能是新能源高渗透的前提

储能技术路线包括四种：

- 电化学储能（锂电）：最主流，成本持续下降
- 抽水蓄能：最成熟，但受地理限制
- 压缩空气：大规模长时储能
- 液流电池：安全性高，适合长时

## 五、新能源汽车产业链

### 5.1 新能源车产业链

| 环节 | 代表公司 | 核心逻辑 |
|------|---------|---------|
| 整车 | 比亚迪、长安汽车 | 销量+智能化 |
| 动力电池 | 宁德时代、比亚迪 | 技术+规模 |
| 热管理 | 三花智控、银轮股份 | 电动化新增量 |
| 智能驾驶 | 德赛西威、经纬恒润 | 智能化趋势 |
| 轻量化 | 拓普集团、旭升集团 | 续航需求 |
| 充电桩 | 特锐德 | 基础设施 |

### 5.2 投资节奏

新能源车投资分为两个阶段：

**电动化阶段（已部分完成）**：电池、电机、电控，渗透率从5%到30%。

**智能化阶段（正在进行）**：智能驾驶、智能座舱，渗透率从10%到50%，这是下一个大机会。

## 六、新能源行业周期特征

### 6.1 产能周期

新能源行业产能周期呈现这样的特征：景气上行时大量扩产，导致产能过剩和价格下跌，落后产能出清后供需重新平衡，需求增长带动景气再次上行。

当前各环节所处阶段不同：
- 锂矿：从过剩走向平衡
- 光伏组件：产能过剩中
- 动力电池：结构性过剩
- 储能：高增长初期

### 6.2 投资节奏建议

1. 在产能出清末期买入龙头
2. 在产能扩张高峰期警惕估值
3. 关注成本曲线，低成本企业有安全边际
4. 技术迭代期关注设备公司

## 七、投资方法论与风险

### 7.1 选股框架

新能源选股有五个要点：

1. **选龙头**：行业集中度持续提升
2. **看成本**：成本最低的公司活得最久
3. **看技术**：技术路线选择决定未来
4. **看海外**：出海能力打开增长空间
5. **看产能利用率**：反映真实需求

### 7.2 主要风险

| 风险类型 | 具体表现 |
|---------|---------|
| 产能过剩 | 价格战，利润大幅下滑 |
| 技术路线 | 押错技术被市场淘汰 |
| 政策变化 | 补贴退坡、贸易壁垒 |
| 原材料 | 锂价等大幅波动 |
| 估值泡沫 | 景气高点估值最高 |

## 八、总结

### 核心要点回顾

1. 新能源是长期趋势：碳中和目标下的确定性方向
2. 产业链很长：上中下游各有机会，需要找准环节
3. 产能周期是核心：供需关系决定价格和利润
4. 技术迭代是机会：每次技术变革都带来新的投资标的
5. 龙头最有价值：行业洗牌后龙头份额持续提升
