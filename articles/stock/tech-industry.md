## 一、科技行业全景图

### 1.1 A股科技板块分类

| 细分领域 | 代表公司 | 核心驱动因素 | 投资难度 |
|---------|---------|-------------|---------|
| 半导体 | 中芯国际、北方华创 | 国产替代+周期 | 高 |
| 消费电子 | 立讯精密、歌尔股份 | 产品周期+创新 | 中 |
| 计算机/软件 | 用友网络、金山办公 | 信创+云化 | 中高 |
| 通信 | 中兴通讯、烽火通信 | 5G/6G建设 | 中 |
| AI产业链 | 科大讯飞、海康威视 | 技术落地+场景 | 高 |
| 信创 | 中国软件、中科曙光 | 政策驱动 | 中 |

### 1.2 科技行业投资特征

科技行业有五个显著特征：

1. **技术迭代快**，今天的龙头可能明天被淘汰
2. **赢者通吃**，龙头公司市占率持续提升
3. **研发投入高**，利润短期可能不反映真实价值
4. **政策敏感**，国产替代、出口管制影响大
5. **估值波动大**，市场情绪对股价影响显著

## 二、半导体：科技产业的基石

### 2.1 半导体产业链

半导体产业链可分为上游、中游、下游三个环节：

**上游（设备+材料）**
- 光刻机：ASML（全球垄断）
- 刻蚀设备：北方华创、中微公司
- 硅片：沪硅产业、立昂微
- 光刻胶：彤程新材

**中游（制造+封测）**
- 晶圆代工：中芯国际、华虹半导体
- 封装测试：长电科技、通富微电
- IDM模式：士兰微、华润微

**下游（设计）**
- 手机芯片：紫光展锐（未上市）
- 存储芯片：兆易创新、北京君正
- 模拟芯片：圣邦股份、思瑞浦
- GPU/AI芯片：海光信息、寒武纪

### 2.2 半导体周期分析

半导体行业有明显的周期性：

| 周期阶段 | 特征 | 投资策略 |
|---------|------|---------|
| 景气上行 | 供不应求，涨价 | 持有，逢低加仓 |
| 景气顶部 | 库存高企，产能过剩信号 | 减仓，止盈 |
| 景气下行 | 去库存，降价 | 观望，等待 |
| 景气底部 | 库存见底，需求回暖 | 逐步建仓 |

### 2.3 投资半导体的关键指标

投资半导体需要跟踪五个核心指标：

1. 全球半导体销售额（SIA月度数据）
2. 北美半导体设备出货额（SEMI数据）
3. DRAM/NAND Flash现货价格
4. 台积电月度营收（行业风向标）
5. 国内晶圆厂产能利用率

## 三、消费电子：周期与创新的交汇

### 3.1 消费电子产业链

| 环节 | 代表公司 | 竞争力 |
|------|---------|--------|
| 品牌商 | 苹果、华为、小米 | 生态+品牌 |
| 代工 | 富士康、比亚迪电子 | 规模+效率 |
| 零组件 | 立讯精密、蓝思科技 | 技术+客户 |
| 面板 | 京东方、TCL科技 | 产能+技术 |
| 光学 | 舜宇光学、欧菲光 | 技术迭代 |

### 3.2 创新周期驱动

消费电子的投资逻辑主要围绕两条主线展开：

**iPhone周期**
- 每年9月新机发布，产业链6至8月备货
- 销量超预期时，产业链股价上涨
- 销量不及预期时，股价回调

**创新周期**
- 折叠屏：铰链、柔性屏受益
- AR/VR：光学、显示受益
- AI手机：端侧芯片、存储受益

### 3.3 投资要点

1. 关注大客户新品发布节奏
2. 跟踪月度出货量数据
3. 创新功能带来的ASP提升
4. 国产替代带来的份额提升

## 四、云计算与SaaS

### 4.1 云计算产业链

云计算产业链分为三层：

**IaaS（基础设施）**：阿里云、腾讯云、华为云。受益标的包括服务器（中科曙光）、IDC（万国数据）

**PaaS（平台）**：数据库、中间件等，受益标的如东方国信、海量数据

**SaaS（应用）**：办公（金山办公、钉钉）、ERP（用友网络、金蝶）、CRM（纷享销客）、安全（深信服、奇安信）

### 4.2 SaaS估值方法

SaaS公司通常用PS（市销率）估值：

| PS倍数 | 评价 | 适用条件 |
|--------|------|---------|
| < 5x | 低估 | 增速 > 30% |
| 5-15x | 合理 | 增速 20-50% |
| 15-30x | 偏高 | 增速 > 50% |
| > 30x | 泡沫 | 需警惕 |

### 4.3 关键指标

评估SaaS公司需要关注四个核心指标：

1. **ARR**（年度经常性收入）及增速
2. **NRR**（净收入留存率），大于100%为优秀
3. **CAC回收周期**（获客成本），小于12个月为佳
4. **Rule of 40**：增速 + 利润率大于40%

## 五、人工智能产业链

### 5.1 AI产业链图谱

| 层级 | 细分 | 代表公司 |
|------|------|---------|
| 基础层 | AI芯片 | 海光信息、寒武纪 |
| 基础层 | 算力基础设施 | 中科曙光、浪潮信息 |
| 技术层 | 大模型 | 百度、科大讯飞 |
| 技术层 | 计算机视觉 | 海康威视、商汤 |
| 技术层 | NLP | 科大讯飞 |
| 应用层 | 智能驾驶 | 德赛西威、经纬恒润 |
| 应用层 | 智能客服 | 科大讯飞 |
| 应用层 | AI办公 | 金山办公 |

### 5.2 AI投资的核心逻辑

AI投资可分为三个阶段，受益环节依次递进：

**第一阶段：算力建设期（最先受益）**。GPU/AI芯片、服务器、光模块等确定性最高。

**第二阶段：模型训练期**。大模型厂商、数据服务商受益，但竞争激烈，选股难度大。

**第三阶段：应用落地期**。垂直行业应用、SaaS集成空间最大，但需要验证商业模式。

### 6.1 信创产业链

| 环节 | 国产化率 | 代表公司 |

2. 从可用到好用：产品竞争力持续提升
3. 量价齐升：渗透率提升 + 客单价提升
4. 关注订单和收入确认节奏

## 七、科技股估值方法

### 7.1 估值方法选择

| 公司类型 | 推荐方法 | 说明 |
|---------|---------|------|
| 成熟盈利型 | PE、PEG | 利润稳定的公司 |
| 高成长亏损型 | PS、EV/Revenue | 有收入无利润 |
| SaaS型 | PS、ARR倍数 | 看经常性收入 |
| 半导体周期型 | PB、EV/EBITDA | 周期底部用PB |
| 早期概念型 | 主题投资 | 看市场情绪和催化 |

### 7.2 科技股估值陷阱

科技股估值有四个常见陷阱需要注意：

1. **低PE陷阱**：周期顶部利润最高，PE最低，但即将下行
2. **高增长幻觉**：一次性收入当成持续性收入，或并购带来的“增长”
3. **技术路线风险**：押错技术路线，公司可能被淘汰
4. **政策风险**：出口管制、反垄断等

## 八、科技行业投资实战

### 8.1 选股框架

科技股选股可遵循五步法：

**第一步：选赛道**。市场空间大（千亿以上），增速快（20%以上），竞争格局好（CR3大于50%）。

**第二步：选龙头**。市占率第一或第二，技术壁垒高，客户粘性强。

**第三步：看财务**。收入增速高于行业增速，研发费用率持续提升，毛利率稳定或提升。

**第四步：看估值**。PEG小于1为合理，对比历史估值中枢。

**第五步：等催化**。新品发布、政策利好、业绩超预期等事件驱动。

### 8.2 科技股交易纪律

1. 不追概念炒作，等业绩验证
2. 分散持仓，单只不超过15%
3. 设好止损，科技股波动大
4. 关注大股东减持和解禁

## 九、总结

### 核心要点回顾

1. 赛道选择：半导体、AI、信创是当前最有确定性的方向
2. 周期判断：科技行业有周期性，要判断所处阶段
3. 龙头溢价：科技行业赢者通吃，选龙头比选赛道更重要
4. 估值方法：不同类型用不同方法，不能一刀切用PE
5. 风险控制：技术路线风险、政策风险、估值风险需要重视
