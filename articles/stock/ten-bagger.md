## 一、彼得·林奇简介与投资哲学

### 1.1 彼得·林奇的成就

**核心数据：**
```
管理基金：麦哲伦基金（Magellan Fund）
管理时间：1977-1990年（13年）
初始规模：2000万美元
最终规模：140亿美元
年化收益率：29.2%
累计收益率：约2700%

对比：
- 同期标普500年化约12%
- 林奇跑赢市场近20年
- 连续13年跑赢 benchmark
```

**投资风格：**
```
✅ 自下而上选股（不预测宏观）
✅ 重视基本面研究
✅ 喜欢"无聊"的公司
✅ 从生活中发现投资机会
✅ 长期持有优质成长股
✅ 适度分散（持有几百只股票）
```

**名言：**
> "如果你在平时生活中能注意到一些好的商业现象，那么在投资中你就已经占据了优势。"  
> —— 彼得·林奇

---

### 1.2 林奇的核心信念

**散户的优势：**
```
散户可以做到：
✅ 灵活投资，不受机构约束
✅ 关注小公司（机构看不上）
✅ 从生活中发现机会（机构做不到）
✅ 长期持有，不用季度考核
✅ 可以空仓等待好机会

```

## 二、六种公司分类法

### 2.1 分类概览

**彼得·林奇将公司分为六类：**

| 类型 | 特征 | 增长率 | 投资策略 | 预期收益 |
|------|------|--------|---------|---------|
| 缓慢增长型 | 大型成熟企业 | 2-4% | 吃股息 | 低 |
| 稳健增长型 | 大型优质企业 | 10-12% | 攻守兼备 | 中 |
| 快速增长型 | 中小型成长企业 | 20-25%+ | 十倍股摇篮 | 高 |
| 周期型 | 随经济波动 | 不固定 | 择时交易 | 中高 |
| 困境反转型 | 面临危机但可能复苏 | 不确定 | 逆向投资 | 很高 |
| 隐蔽资产型 | 资产被低估 | 不确定 | 深度挖掘 | 高 |

---

### 2.2 各类型详解

#### （1）缓慢增长型 ⭐⭐

**特征：**
```
- 通常是大型成熟企业
- 增长率2-4%，与GDP接近
- 盈利稳定，分红丰厚
- 增长空间有限

典型行业：
- 公用事业（电力、水务）
- 传统银行
- 电信运营商

投资策略：
→ 主要为了分红收益
→ 经济衰退时防御性好
→ 不要期望股价大涨
```

#### （2）稳健增长型 ⭐⭐⭐⭐

**特征：**
```
- 大型优质企业
- 增长率10-15%
- 盈利稳定增长
- 有一定定价权

典型行业：
- 消费品龙头（可口可乐、宝洁）
- 医药龙头（强生、辉瑞）
- A股：茅台、海天、伊利

投资策略：
→ 核心持仓品种
→ 合理估值时买入
→ 长期持有享受复利
→ PE不超过30倍时可以考虑
```

#### （3）快速增长型 ⭐⭐⭐⭐⭐

**特征：**
```
- 中小型高成长企业
- 增长率20-25%以上
- 市场空间大
- 十倍股的摇篮！

典型行业：
- 新兴消费品牌
- 创新药企
- 科技公司

投资策略：
→ 重点研究对象
→ 关键看增长速度能否持续
→ PEG < 1 时积极买入
→ 可以集中投资
→ 注意增长放缓的信号
```

**林奇说：**
> "快速增长型公司是我赚钱最多的地方。一个小的、增长快的公司，如果成功的话，可以涨10倍甚至更多。"

#### （4）周期型 ⭐⭐⭐

**特征：**
```
- 业绩随经济周期波动
- 好年份利润可能是差年份的10倍
- 关键看周期位置

典型行业：
- 钢铁、煤炭、化工
- 汽车、航空
- 房地产

投资策略：
→ 关键是判断周期位置
→ 周期底部买入（低PE时）
→ 周期顶部卖出（高PE时）
→ ⚠️ 注意：周期股低PE可能是顶部信号！
```

**与稳健增长型的区别：**
```
稳健增长型：
PE低 → 便宜 → 可以买
PE高 → 贵了 → 谨慎

周期型：
PE低 → 利润在顶部 → 可能快见顶了！
PE高 → 利润在底部 → 可能快见底了！

⚠️ 这是最容易搞混的地方！
```

#### （5）困境反转型 ⭐⭐⭐⭐⭐

**特征：**
```
- 面临严重困难
- 股价大幅下跌
- 但如果能渡过难关
- 股价可能翻数倍

典型情况：
- 行业危机（如2008年银行）
- 一次性事件（如产品召回）
- 管理层更换
- 债务重组

投资策略：
→ 判断是暂时困难还是永久衰退
→ 资产负债表是否健康
→ 有没有足够的现金撑过去
→ 如果判断正确，收益巨大
```

#### （6）隐蔽资产型 ⭐⭐⭐⭐

**特征：**
```
- 市场没有发现其真实价值
- 可能有隐蔽的资产或业务

典型情况：
- 子公司价值被忽略
- 土地资产被低估
- 专利价值未体现
- 新业务还没被市场认知

投资策略：
→ 需要深度研究
→ 找到市场忽略的价值
→ 等待市场重新发现
```

## 三、PEG指标详解

### 3.1 PEG的定义

**公式：**
```
PEG = PE / 净利润增速（%）

例如：
某股票PE = 30倍
净利润增速 = 30%
PEG = 30 / 30 = 1.0
```

**判断标准：**

| PEG | 评价 | 操作 |
|-----|------|------|
| < 0.5 | 极度低估 | 强烈买入 |
| 0.5-1.0 | 低估 | 可以买入 |
| 1.0 | 合理估值 | 持有观望 |
| 1.0-1.5 | 略高估 | 谨慎 |
| 1.5-2.0 | 高估 | 考虑减仓 |
| > 2.0 | 严重高估 | 卖出 |

---

### 3.2 PEG实战计算

**案例1：贵州茅台（假设数据）**
```
当前PE = 35倍
未来3年净利润增速预期 = 20%
PEG = 35 / 20 = 1.75

评价：略高估
→ 对于茅台这样的确定性龙头
→ PEG可以容忍到1.5-2.0
→ 但当前不算便宜
```

**案例2：某成长股**
```
当前PE = 25倍
未来3年净利润增速预期 = 40%
PEG = 25 / 40 = 0.625

评价：低估
→ PEG < 1，有投资价值
→ 但需要确认增速能否持续
```

**案例3：某高估值科技股**
```
当前PE = 80倍
未来3年净利润增速预期 = 30%
PEG = 80 / 30 = 2.67

评价：严重高估
→ 即使增速很快
→ 当前价格也透支了太多未来
→ 不建议追高
```

---

### 3.3 PEG的注意事项

**局限性：**
```
❌ 增长率估计可能不准确
   → 需要用多种方法交叉验证
   → 参考多家机构预测

❌ 不适合亏损公司
   → 没有PE，无法计算PEG
   → 亏损公司需要用其他方法

❌ 不适合周期股
   → 周期顶部的增长率不可持续
   → PEG会给出错误信号

❌ 对缓慢增长型不适用
   → 增长率太低，PEG会很高
   → 这类公司应该看分红率
```

## 四、生活选股法

### 4.1 什么是生活选股法？

**核心理念：**
```
从日常生活中发现投资机会

你每天接触的产品和服务：
→ 哪些让你离不开？
→ 哪些店总是排队？
→ 哪些产品在涨价你还买？
→ 哪些品牌你在推荐给朋友？

这些就是好公司的线索！
```

**林奇说：**
> "如果你在平时去商场的时候，发现某家店总是人满为患，或者某个产品总是供不应求，那么这家公司的股票就值得研究。"

---

### 4.2 生活选股法实战

**发现线索：**

```
场景1：超市购物
→ 哪个品牌的货架总是满满的？
→ 哪些产品经常被买空？
→ 哪些品牌在扩大货架面积？

场景2：餐饮消费
→ 哪家餐厅总是排队？
→ 哪个新品牌开分店很快？
→ 外卖平台上哪个品牌订单最多？

场景3：互联网使用
→ 你手机里打开频率最高的APP？
→ 哪个服务你离不开？
→ 朋友们都在用什么新产品？

场景4：工作场景
→ 你的公司在用什么新软件？
→ 哪个供应商的订单在增加？
→ 行业里哪个公司被讨论最多？
```

**从线索到投资：**
```
第一步：发现线索
→ "某某品牌最近很火"

第二步：初步筛选
→ 这家公司上市了吗？
→ 市值多大？增长多快？
→ 估值合理吗？

第三步：深入研究
→ 读财报、分析竞争格局
→ 判断增长能否持续
→ 计算合理估值

第四步：做出决策
→ 如果低估 → 买入
→ 如果合理 → 放入观察池
→ 如果高估 → 等待回调
```

## 五、13条选股黄金法则

### 5.1 林奇的13条法则

| # | 法则 | 说明 |
|---|------|------|
| 1 | 公司名称很无聊 | 好公司不需要花哨的名字 |
| 2 | 业务简单易懂 | 看不懂就不要买 |
| 3 | 令人厌烦的业务 | 竞争少，利润反而好 |
| 4 | 从母公司分拆出来 | 新公司更有动力 |
| 5 | 机构不持有 | 还没被发现 = 机会 |
| 6 | 传言四起 | 负面传言可能是机会 |
| 7 | 管理层在买自家股票 | 最了解公司的人在加仓 |
| 8 | 公司在回购股票 | 管理层认为被低估 |
| 9 | 有增长空间 | 还能开新店、进新市场 |
| 10 | 利基市场 | 小市场里的大公司 |
| 11 | 人们需要持续购买 | 消耗品 > 耐用品 |
| 12 | 技术的使用者而非发明者 | 用技术降成本，不靠技术吃饭 |
| 13 | 内部人在增持 | 用真金白银投票 |

## 六、何时卖出十倍股

### 6.1 卖出的五个信号

```
信号1：故事已经讲完了
→ 当初买入的逻辑已经实现
→ 增长预期已经被充分定价
→ PEG > 2

信号2：增长开始放缓
→ 连续2个季度增速下降
→ 新开店速度减慢
→ 市场份额停止增长

信号3：估值严重偏高
→ PE远超历史均值
→ PEG > 2
→ 市场给出了过于乐观的预期

信号4：基本面恶化
→ 毛利率持续下降
→ 竞争加剧
→ 护城河在变窄

信号5：发现更好的机会
→ 有更具性价比的标的
→ 需要调仓换股
```

**林奇说：**
> "卖出的理由应该是基本面发生了变化，而不是股价涨了多少。"

## 七、A股十倍股案例

### 7.1 经典十倍股

**贵州茅台（2003-2021）：**
```
2003年股价约25元（前复权）
2021年股价约2600元
涨幅约100倍

核心驱动力：
→ 品牌护城河极宽
→ 消费升级大趋势
→ 净利润从3亿增长到500亿+
→ 属于"稳健增长型"的极致表现
```

**恒立液压（2012-2021）：**
```
2012年上市，股价约10元
2021年最高约120元
涨幅约12倍

核心驱动力：
→ 国产替代进口
→ 挖掘机液压件龙头
→ 净利润从1亿增长到25亿+
→ 属于"快速增长型"
```

## 八、总结

### 核心要点回顾

✅ **六种分类**：不同类型用不同策略，快速增长型是十倍股摇篮  
✅ **PEG指标**：PEG < 1 低估，PEG > 2 高估  
✅ **生活选股**：从日常消费中发现投资机会  
✅ **13条法则**：关注"无聊"的公司、内部人增持  
✅ **卖出信号**：基本面变化才是卖出理由，不是涨了多少  

### 实践建议

1. **先分类再选股**：确定目标公司属于哪一类
2. **用PEG估值**：寻找PEG < 1的成长股
3. **从生活中发现**：关注你身边的消费趋势
4. **耐心持有**：十倍股需要时间成长
5. **警惕增长放缓**：增速下降是卖出的重要信号
