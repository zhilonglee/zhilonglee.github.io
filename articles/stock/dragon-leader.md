# 龙头战法基础教程

> 👑 龙头是题材的灵魂，抓住龙头就能抓住主升浪。本文详解龙头识别、买入和卖出技巧。

## 一、龙头基础知识

### 1.1 什么是龙头？

**定义：** 龙头股是指在某个题材或板块中，最先启动、涨幅最大、影响力最强的股票。

**龙头的特征：**
- ✅ 最先涨停（时间优先）
- ✅ 连板最高（空间优先）
- ✅ 带动板块（影响力）
- ✅ 抗跌性强（逆势上涨）
- ✅ 人气最高（关注度）

**名言：**
> "做短线，只做龙头。"  
> "龙头多条命，跟风死得快。"

---

### 1.2 龙头的类型

#### （1）市场总龙头 ⭐⭐⭐⭐⭐

**定义：** 整个市场最强的股票，不受板块限制

**特征：**
- 连板高度最高（通常7板以上）
- 带动多个板块
- 市场焦点
- 人气王

**例子：**
```
2023年捷荣技术：14连板
2022年中通客车：13连板
2021年九安医疗：10连板
```

**操作策略：**
```
✅ 第一时间跟进
✅ 坚定持有
✅ 直到见顶
✅ 可重仓
```

---

#### （2）板块龙头 ⭐⭐⭐⭐

**定义：** 某个题材板块内最强的股票

**特征：**
- 板块内最先涨停
- 板块内连板最高
- 带动板块上涨
- 板块标杆

**例子：**
```
人工智能题材：
- 龙头：科大讯飞
- 跟风：其他AI概念股

新能源题材：
- 龙头：宁德时代
- 跟风：其他锂电股
```

**操作策略：**
```
✅ 积极参与
✅ 持有到板块退潮
✅ 可做波段
```

---

#### （3）补涨龙头 ⭐⭐⭐

**定义：** 老龙头见顶后，新出现的龙头

**特征：**
- 老龙头断板后出现
- 低位首板或二板
- 承接老龙头资金
- 可能有第二波

**操作策略：**
```
⚠️ 谨慎参与
⚠️ 快进快出
⚠️ 不要期望太高
```

---

### 1.3 龙头 vs 跟风

**对比表：**

| 特性 | 龙头 | 跟风 |
|------|------|------|
| 启动时间 | 最早 | 较晚 |
| 连板高度 | 最高 | 较低 |
| 涨停强度 | 封板坚决 | 容易炸板 |
| 抗跌性 | 强 | 弱 |
| 反弹速度 | 快 | 慢 |
| 安全性 | 相对安全 | 风险大 |
| 收益 | 高 | 低 |

**核心原则：**
```
✅ 只做龙头，不做跟风
✅ 龙头断板前一直持有
✅ 跟风股及时止盈
```

## 二、龙头识别方法

### 2.1 时间维度识别

#### （1）谁先涨停？

**判断方法：**
```
同一题材多只股票涨停：
- 9:30涨停 → 最强
- 9:35涨停 → 较强
- 10:00后涨停 → 较弱
- 下午涨停 → 最弱

优先选择最早涨停的
```

---

#### （2）谁先上板？

**盘中观察：**
```
快速拉升涨停 → 强势
缓慢磨蹭涨停 → 弱势

一字板 > T字板 > 实体板
```

---

### 2.2 空间维度识别

#### （1）连板高度

**判断标准：**
```
连板数最高的 = 龙头

例如：
股票A：5连板
股票B：3连板
股票C：2连板

→ A是龙头
```

---

#### （2）累计涨幅

**判断标准：**
```
短期涨幅最大的 = 龙头

例如：
5天内：
股票A：涨60%
股票B：涨40%
股票C：涨20%

→ A是龙头
```

---

### 2.3 影响力维度识别

#### （1）是否带动板块？

**观察方法：**
```
龙头涨停后：
- 板块内多只跟风涨停 → 是真龙头
- 板块无反应 → 可能是独立行情

龙头大跌时：
- 板块集体下跌 → 是真龙头
- 板块无反应 → 影响力弱
```

---

#### （2）是否逆势走强？

**观察方法：**
```
大盘下跌时：
- 龙头继续涨停 → 极强
- 龙头横盘 → 较强
- 龙头下跌 → 一般

大盘上涨时：
- 龙头涨停更快 → 强
- 龙头跟涨 → 一般
```

---

### 2.4 人气维度识别

#### （1）成交量

**判断标准：**
```
龙头特征：
- 成交量适中（不是天量）
- 换手充分
- 量价配合好

警惕：
- 缩量加速（可能一字板）
- 天量滞涨（可能见顶）
```

---

#### （2）讨论热度

**观察渠道：**
```
- 股吧讨论最多
- 社交媒体热议
- 研报频繁提及
- 龙虎榜知名游资

人气高 = 关注度高 = 流动性好
```

## 三、龙头买入技巧

### 3.1 首板买入法 ⭐⭐⭐⭐⭐

**适用场景：** 题材发酵期，龙头首次涨停

**操作方法：**
```
Step 1：发现题材启动
Step 2：找到最先涨停的股票
Step 3：在涨停价挂单买入
Step 4：成交后持有

成功率：高
风险：低
收益：高
```

**实例：**
```
某政策发布：
9:30 股票A快速涨停
9:32 股票B涨停
9:35 股票C涨停

操作：
立即买入股票A（龙头）
```

---

### 3.2 二板确认法 ⭐⭐⭐⭐

**适用场景：** 首板没买到，次日二板确认

**操作方法：**
```
Step 1：观察首板龙头
Step 2：次日高开或快速拉升
Step 3：涨停时买入
Step 4：确认龙头地位

成功率：较高
风险：中等
收益：高
```

**注意：**
```
必须是强势二板
低开或弱势二板不买
```

---

### 3.3 分歧低吸法 ⭐⭐⭐

**适用场景：** 龙头中途调整，低吸机会

**操作方法：**
```
Step 1：确认是龙头
Step 2：等待分歧调整
Step 3：在5日线或10日线低吸
Step 4：反弹后卖出

成功率：中等
风险：中等
收益：中等
```

**注意：**
```
只适用于真龙头
跟风股不能低吸
严格止损
```

---

### 3.4 打板买入法 ⭐⭐⭐⭐

**适用场景：** 龙头连续涨停，打板跟进

**操作方法：**
```
Step 1：确认龙头地位
Step 2：观察封板强度
Step 3：涨停瞬间买入
Step 4：次日溢价卖出或持有

成功率：较高
风险：中等
收益：高
```

**注意：**
```
只做前排龙头
不做后排跟风
炸板要止损
```

---

## 四、龙头卖出技巧

### 4.1 断板卖出法 ⭐⭐⭐⭐⭐

**原则：** 龙头断板即卖出

**操作方法：**
```
龙头不再涨停 → 立即卖出
不管盈亏，坚决执行

原因：
断板 = 走弱信号
可能开始退潮
```

**实例：**
```
某龙头7连板后：
第8天开盘未涨停
→ 立即卖出
→ 不要幻想反包
```

---

### 4.2 放量滞涨卖出法

**信号：**
```
成交量异常放大
但股价不涨或微涨
→ 主力出货
→ 卖出
```

**判断标准：**
```
成交量是平时的2-3倍
涨幅 < 3%
→ 危险信号
```

---

### 4.3 高位巨阴卖出法

**信号：**
```
高位出现大阴线
跌幅 > 7%
成交量放大
→ 见顶信号
→ 卖出
```

---

### 4.4 板块退潮卖出法

**信号：**
```
板块内多只股票跌停
龙头也开始走弱
→ 板块退潮
→ 卖出所有持仓
```

---

## 五、龙头战法进阶技巧

### 5.1 龙头多条命

**现象：**
```
真龙头断板后
可能反包再涨
甚至创出新高

原因：
人气高
资金记忆
第二波行情
```

**操作策略：**
```
第一次断板：卖出
观察1-2天：
- 若反包涨停 → 可重新买入
- 若继续下跌 → 放弃

注意：
只有真龙头才有第二条命
跟风股没有
```

---

### 5.2 龙头切换

**现象：**
```
老龙头见顶
新龙头崛起
资金从老龙头流向新龙头
```

**识别方法：**
```
老龙头断板当天或次日：
- 低位出现新的首板
- 属于同一题材或新题材
- 快速涨停

→ 可能是新龙头
```

**操作策略：**
```
卖出老龙头
买入新龙头
完成切换
```

---

### 5.3 龙头与指数共振

**现象：**
```
龙头上涨带动指数
指数上涨助推龙头
形成正反馈
```

**操作策略：**
```
指数向好 + 龙头强势 → 重仓
指数走弱 + 龙头独强 → 轻仓
指数大跌 + 龙头也跌 → 空仓
```

## 六、龙头战法风险控制

### 6.1 常见误区

**❌ 误区1：把跟风当龙头**
```
正确做法：
严格按标准识别
只做真正的龙头
```

**❌ 误区2：龙头断板还持有**
```
正确做法：
断板即卖出
不要幻想
```

**❌ 误区3：高位接力**
```
正确做法：
只做首板、二板
不做5板以上的接力
```

**❌ 误区4：忽视大盘环境**
```
正确做法：
大盘差时不做龙头
顺势而为
```

---

### 6.2 止损策略

**止损规则：**
```
打板失败：次日开盘卖出
低吸失败：亏损5%止损
断板未卖：跌破5日线止损
```

**原则：**
```
宁可小亏，不要大套
严格执行止损
```

---

### 6.3 仓位管理

**仓位建议：**
```
首板：6-8成
二板：5-7成
三板及以上：3-5成
高位接力：1-2成或不参与
```

**原则：**
```
越早期仓位越重
越后期仓位越轻
```

## 七、核心要点回顾

✅ **龙头特征**：最先涨停、连板最高、带动板块、人气最高

✅ **识别方法**：时间优先、空间优先、影响力、人气  
✅ **买入技巧**：首板买入、二板确认、分歧低吸、打板跟进  
✅ **卖出技巧**：断板卖出、放量滞涨、高位巨阴、板块退潮  
✅ **风险控制**：严格止损、仓位管理、不做跟风
