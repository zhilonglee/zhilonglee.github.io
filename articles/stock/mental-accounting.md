## 一、心理账户的定义

### 1.1 什么是心理账户？

心理账户（Mental Accounting）是指人们在心中将资金分为不同的"账户"，对不同来源或用途的资金采取不同的态度和决策。

经典例子：

场景1：你花80元买了一张电影票，到了影院发现票丢了。你会再花80元买一张吗？大多数人不会。

场景2：你准备花80元买电影票，到了影院发现丢了80元现金。你还会买电影票吗？大多数人会。

同样是损失80元，但决策不同，因为"娱乐账户"和"现金账户"在心理上是分开的。

### 1.2 心理账户的分类

| 账户类型 | 来源 | 消费/投资态度 |
|---------|------|-------------|
| 工资账户 | 工资收入 | 精打细算 |
| 奖金账户 | 年终奖、红包 | 大手大脚 |
| 投资盈利 | 炒股赚的钱 | 容易冒险 |
| 意外之财 | 彩票、退税 | 挥霍消费 |
| 本金账户 | 存款、积蓄 | 非常谨慎 |

## 二、投资中的心理账户

### 2.1 盈利账户 vs 本金账户

最常见的心理账户是"炒股赚的钱"（盈利账户），觉得是"白来的"，更容易冒险，"反正是赚来的，亏了也不心疼"，结果赚来的钱很快又亏回去。而对"本金"（本金账户）则非常谨慎，不敢冒险，"这是自己的血汗钱"。

真相是：赚来的钱和你自己的钱是一样的钱！

### 2.2 不同股票的心理账户

人们常常为每只股票建"心理账户"：股票A赚了钱就觉得是"好股票，一直拿着"，股票B亏了钱就觉得是"差股票，等回本就卖"，股票C没涨没跌就"没感觉，不管它"。

理性做法是不看历史盈亏，只看未来预期收益，未来好的持有，未来差的卖出。

### 2.3 短线账户 vs 长线账户

"短线账户"的钱可以随便操作，追涨杀跌无压力，"反正只是短线"。"长线账户"的钱不动，即使基本面变坏了也不卖，"这是长线投资"。

风险在于短线变长线（被套了就不动了），长线变死扛（基本面变了也不卖）。

## 三、心理账户的危害

### 3.1 危害清单

| 危害 | 表现 | 后果 |
|------|------|------|
| 盈利冒更大风险 | "赚来的钱亏了不心疼" | 盈利回吐 |
| 沉没成本效应 | "已经投了这么多" | 继续投入烂项目 |
| 来源偏见 | "奖金可以乱花" | 浪费资金 |
| 处置效应 | "赚钱的卖，亏钱的扛" | 盈亏比失衡 |
| 账户隔离 | 各账户独立管理 | 整体风险失控 |

### 3.2 典型案例

案例：小王有10万元，其中8万本金（"要谨慎"）买了银行股，2万盈利（"可以冒险"）买了妖股。结果银行股赚了5%（4000元），妖股亏了50%（10000元），总亏损6000元。

如果统一看10万元，6%的亏损是可以接受的吗？可能就不会买妖股了。

## 四、建立理性资金观

### 4.1 钱就是钱

理性资金观的核心原则：

1. **所有钱都是一样的**，赚来的钱等于本金，奖金等于工资，100元就是100元
2. **统一看待总资产**，不区分"哪个账户赚的"，只看总资产的变化，整体规划
3. **统一风险标准**，不管钱从哪来，同样的风险标准，同样的止损纪律

### 4.2 总资产视角

从"分账户管理"到"总资产管理"：

旧方式是短线账户20万随便炒、长线账户30万不动、理财账户10万保守，总风险不知道。

新方式是总资产60万，统一规划50%稳健+30%成长+20%进攻，统一管理风险，定期再平衡。

## 五、克服心理账户的方法

### 5.1 实用技巧

| 技巧 | 说明 |
|------|------|
| 统一账户 | 用总资产视角看待所有资金 |
| 定期汇总 | 每月计算总资产变化 |
| 忘掉成本 | 不看每只股票的盈亏 |
| 统一规则 | 所有交易用同样的风控标准 |
| 再平衡 | 定期调整各类资产比例 |

### 5.2 投资决策框架

每笔投资决策前问自己：

1. 这笔钱和我的其他钱一样吗？是的就用同样的标准
2. 如果这笔钱是我工资赚的，我还会这么做吗？不会就说明被心理账户影响了
3. 我的总仓位是否合理？不看单个"账户"，看总风险暴露
4. 这笔交易的止损设好了吗？不管"盈利"还是"本金"，统一止损标准

---

## 六、总结

### 核心要点回顾

1. 心理账户普遍存在：人们为不同来源的钱设立不同标准
2. 盈利更容易冒险："赚来的钱"不是"白来的钱"
3. 钱就是钱：所有资金应该统一管理
4. 用总资产视角：不看单个账户，看整体
5. 统一风控标准：所有交易用同样的止损和仓位规则
