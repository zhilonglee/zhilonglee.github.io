## 一、资产配置的核心原理

### 1.1 为什么资产配置重要？

```
研究结论：
-> 投资组合收益的90%来自资产配置
-> 只有10%来自选股和择时
-> 资产配置比选股更重要

马科维茨的发现：
-> 不同资产的收益相关性不同
-> 低相关性资产组合可以降低风险
-> 不减少预期收益的情况下降低波动
```

### 1.2 分散投资的科学

```
完全正相关（+1）：分散无效
不相关（0）：分散有效
负相关（-1）：分散效果最好

A股常见资产的相关性：
-> 股票 vs 股票：高正相关（0.5-0.8）
-> 股票 vs 债券：低相关（0-0.3）
-> 股票 vs 黄金：低相关或负相关
-> A股 vs 美股：中等相关（0.3-0.5）
```

## 二、股票组合构建

### 2.1 个股数量

```
最佳持股数量：

研究结论：
-> 10-15只股票可以分散大部分风险
-> 超过20只，分散效果递减
-> 少于5只，集中风险太大

建议：
-> 新手：10-15只
-> 有经验：5-10只（适度集中）
-> 不要超过20只（管理不过来）
```

### 2.2 行业分散

```
行业分散原则：
-> 持有3-5个不同行业
-> 单一行业不超过30%
-> 避免全部持有相关行业

好的组合示例：
-> 消费（30%）+ 科技（20%）+ 医药（20%）
   + 金融（15%）+ 制造（15%）

差的组合示例：
-> 全部是科技股
-> 全部是周期股
-> 全部是同一产业链
```

### 2.3 个股仓位

```
仓位分配原则：

确定性高的：
-> 龙头股、护城河宽
-> 可以给15-20%仓位

确定性一般的：
-> 成长股、有一定风险
-> 给5-10%仓位

不确定的：
-> 困境反转、高风险
-> 给2-5%仓位

永远不要：
-> 单只股票 > 30%仓位
-> All in一只股票
```

## 三、跨资产配置

### 3.1 主要资产类别

| 资产 | 预期年化 | 波动性 | 特点 |
|------|---------|--------|------|
| A股 | 8-12% | 高 | 长期向上，波动大 |
| 债券 | 3-5% | 低 | 稳定收益，防御性 |
| 黄金 | 5-8% | 中 | 避险，抗通胀 |
| 现金 | 2-3% | 极低 | 流动性，安全垫 |
| 海外股票 | 8-10% | 中高 | 分散地域风险 |

### 3.2 经典配置模型

```
模型1：60/40（经典）
-> 60%股票 + 40%债券
-> 适合中等风险偏好

模型2：年龄法则
-> 股票比例 = 100 - 年龄
-> 30岁：70%股票 + 30%债券
-> 50岁：50%股票 + 50%债券

模型3：全天候（达利欧）
-> 30%股票 + 40%长期债券 + 15%中期债券
   + 7.5%黄金 + 7.5%商品
-> 适合任何市场环境

模型4：永久组合
-> 25%股票 + 25%债券 + 25%黄金 + 25%现金
-> 极度保守，适合退休
```

## 四、再平衡策略

### 4.1 什么是再平衡？

```
定义：
当资产比例偏离目标时，调整回原始比例

示例：
目标：60%股票 + 40%债券
年初：60万股票 + 40万债券
年末：股票涨到72万，债券42万
比例变成：63% + 37%

再平衡：
-> 卖出3万股票
-> 买入3万债券
-> 恢复到60:40
```

### 4.2 再平衡的好处

```
好处1：自动实现"高卖低买"
-> 涨多了的卖一点
-> 跌多了的买一点

好处2：控制风险
-> 不会让股票比例过高
-> 保持风险在可控范围

好处3：提高收益
-> 长期看可以增加0.5-1%年化收益
```

### 4.3 再平衡方法

```
方法1：定期再平衡
-> 每年1次或2次
-> 简单方便
-> 推荐大多数人使用

方法2：阈值再平衡
-> 偏离目标超过5-10%时调整
-> 更灵活
-> 需要经常检查

方法3：现金流再平衡
-> 用新增资金买入比例偏低的资产
-> 不需要卖出
-> 适合定投投资者
```

## 五、不同投资者的组合方案

### 5.1 新手投资者

```
方案：简单三步法
(1) 70%沪深300指数基金
(2) 30%债券基金
(3) 每月定投，每年再平衡一次

优点：简单、分散、省心
预期年化：6-10%
```

### 5.2 进阶投资者

```
方案：核心+卫星
核心（70%）：
-> 沪深300指数（30%）
-> 中证500指数（20%）
-> 优质个股（20%）

卫星（30%）：
-> 行业ETF（15%）
-> 成长股（10%）
-> 现金（5%）

优点：稳健+弹性
预期年化：8-15%
```

### 5.3 有经验投资者

```
方案：多元配置
-> A股个股（40%）
-> 指数基金（20%）
-> 债券基金（15%）
-> 黄金ETF（10%）
-> 海外ETF（10%）
-> 现金（5%）

优点：全面分散，抗风险能力强
预期年化：8-12%
```

## 六、总结

### 核心要点回顾

(1) **资产配置最重要**：决定90%的收益差异  
(2) **分散投资**：10-15只股票，3-5个行业  
(3) **跨资产配置**：股票+债券+黄金+现金  
(4) **再平衡**：定期调整，自动高卖低买  
(5) **因人而异**：根据年龄、风险偏好选择方案  

### 实践建议

1. **先定大框架**：股票、债券、现金的比例
2. **再选具体标的**：指数基金+优质个股
3. **适度分散**：不要太集中也不要太分散
4. **定期再平衡**：每年1-2次
5. **长期坚持**：资产配置需要时间验证
