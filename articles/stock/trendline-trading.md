## 一、趋势线基础

### 1.1 什么是趋势线？

**定义：** 趋势线是连接一系列递增低点（上升趋势线）或递减高点（下降趋势线）的直线，用于判断趋势方向和关键支撑阻力。

**画法原则：**
```
上升趋势线：
-> 连接两个或以上的有效低点
-> 从低点向右上方延伸
-> 越多次触及越有效

下降趋势线：
-> 连接两个或以上的有效高点
-> 从高点向右下方延伸
-> 越多次触及越有效
```

### 1.2 趋势线的有效性

```
有效趋势线的条件：
(1) 至少触及2个有效高低点
(2) 3次触及比2次更可靠
(3) 时间跨度越长越可靠
(4) 角度越平缓越可靠
(5) 未被突破过

无效趋势线：
(1) 只触及1个点
(2) 太陡峭（容易很快被突破）
(3) 已经被反复突破
```

## 二、上升趋势线

### 2.1 画法

```
            /
          /     <-- 趋势线
        /
      / \
    /    \ / \
  /         \ / \
/  /  /  /  /  / \
   连接两个有效低点
```

### 2.2 操作要点

```
上升趋势线的作用：
-> 提供买入机会
-> 每次回踩趋势线都是买点
-> 跌破趋势线是警告信号

买入时机：
-> 股价回调到趋势线附近
-> 出现止跌信号（如锤子线、十字星）
-> 成交量萎缩

止损位：
-> 趋势线下方3-5%
-> 或最近一个低点下方
```

## 三、下降趋势线

### 3.1 画法

```
\  \  \  \  \  \  \
  \ / \
    \ /  \
      \ /   \
        \ /    \
          \ /
           \
            ^ 连接两个有效高点
```

### 3.2 操作要点

```
下降趋势线的作用：
-> 提供卖出信号
-> 每次反弹到趋势线都是卖点
-> 突破趋势线是反转信号

不要做的事：
X 在下降趋势中抄底
X 在趋势线下方买入
X 与趋势作对

正确做法：
-> 等待突破下降趋势线
-> 突破后回踩不破确认
-> 再考虑买入
```

## 四、通道交易

### 4.1 什么是通道？

**定义：** 通道由趋势线和通道线组成。趋势线连接低点（或高点），通道线平行于趋势线连接高点（或低点）。

### 4.2 上升通道

```
           /  <-- 通道线（连接高点）
         /
       /\/\/\
     /       \/\
   /   /\/\       \
 /   /    趋势线    \
/   /   （连接低点）
```

**特征：**
```
1. 高低点都在上升
2. 通道线提供阻力
3. 趋势线提供支撑
4. 在通道内高抛低吸
```

### 4.3 下降通道

```
\
  \/\
    \/\  \
      \/\   \
        \/\    \
          \/\     \
            \/\      \
              \/\
通道线（连接高点）  趋势线（连接低点）
```

**特征：**
```
1. 高低点都在下降
2. 通道线提供支撑
3. 趋势线提供阻力
4. 在通道内高抛低吸（短线）
5. 突破上轨是反转信号
```

## 五、趋势线的突破

### 5.1 有效突破的判断

```
有效突破的条件：
(1) 收盘价突破趋势线（不是盘中假突破）
(2) 突破幅度 > 3%
(3) 突破时放量
(4) 突破后2-3天确认

假突破的特征：
X 盘中突破但收盘回到趋势线内
X 突破幅度很小（< 1%）
X 无量突破
X 突破后很快回到趋势线内
```

### 5.2 突破后的走势

```
上升趋势线被跌破后：
-> 可能回抽趋势线（阻力转换）
-> 回抽不过 = 确认跌破
-> 继续下跌
-> 目标看前一个低点

下降趋势线被突破后：
-> 可能回踩趋势线（支撑转换）
-> 回踩不破 = 确认突破
-> 继续上涨
-> 目标看前一个高点
```

## 六、趋势线交易策略

### 6.1 顺势交易策略

```
上升趋势中：
-> 每次回调到趋势线附近买入
-> 跌破趋势线止损
-> 持有直到趋势线被跌破

下降趋势中：
-> 空仓观望
-> 等待突破下降趋势线
-> 突破后回踩不破时买入
```

### 6.2 通道交易策略

```
上升通道中：
-> 下轨（趋势线）买入
-> 上轨（通道线）卖出
-> 突破上轨加仓
-> 跌破下轨止损

下降通道中：
-> 上轨（趋势线）卖出
-> 下轨（通道线）买入（短线）
-> 突破上轨是反转信号
```

## 七、总结

### 核心要点回顾

(1) **趋势线画法**：连接有效高低点，至少2个点  
(2) **上升趋势线**：连接低点，提供买入机会  
(3) **下降趋势线**：连接高点，提供卖出信号  
(4) **通道**：趋势线+平行通道线，可高抛低吸  
(5) **有效突破**：收盘价+放量+幅度+确认  

### 实践建议

1. **先画大趋势线**：周线/月线级别更可靠
2. **顺势交易**：不要与趋势作对
3. **等待回踩**：突破后回踩确认再进场
4. **严格止损**：趋势线被有效突破就止损
5. **多周期验证**：大小周期趋势线共振更可靠
