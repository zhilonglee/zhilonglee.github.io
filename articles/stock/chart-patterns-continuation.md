## 一、持续形态概述

### 1.1 什么是持续形态？

**定义：** 持续形态是趋势运行中途出现的整理形态，表示市场在短暂休息后将继续原有趋势。

**与反转形态的区别：**

| 维度 | 反转形态 | 持续形态 |
|------|---------|---------|
| 出现位置 | 趋势末端 | 趋势中途 |
| 预示方向 | 趋势反转 | 趋势延续 |
| 形成时间 | 通常较长 | 通常较短 |
| 交易策略 | 反方向操作 | 顺方向操作 |

## 二、三角形整理

### 2.1 对称三角形

**形态结构：**
```
      ╱╲╱╲╱╲
     ╱        ╲      ← 高点逐渐降低
    ╱          ╲
   ╱    收敛区域  ╲
  ╱              ╲
 ╱   ╱╲╱╲╱╲      ╲
╱   ╱              ← 低点逐渐升高
   ╱
```

**特征：**
```
1. 高点逐渐降低（下降趋势线）
2. 低点逐渐升高（上升趋势线）
3. 两条趋势线收敛
4. 通常向原趋势方向突破
5. 形成时间2-4周
```

**成交量：**
```
整理过程中量能逐渐萎缩
突破时放量确认
```

---

### 2.2 上升三角形

**形态结构：**
```
    ────────────────  ← 水平阻力线
   ╱╲╱╲╱╲╱╲
  ╱
 ╱  ← 低点逐渐升高
╱
```

**特征：**
```
1. 上方有水平阻力线
2. 低点逐渐升高
3. 多方力量不断增强
4. 通常向上突破
5. 是看涨形态
```

**操作：**
```
买入点：突破阻力线时
止损位：最近一个低点下方
目标位：三角形最宽处的高度向上投射
```

---

### 2.3 下降三角形

**形态结构：**
```
╲
  ╲  ← 高点逐渐降低
    ╲
     ╲╱╲╱╲╱╲
    ────────────────  ← 水平支撑线
```

**特征：**
```
1. 下方有水平支撑线
2. 高点逐渐降低
3. 空方力量不断增强
4. 通常向下突破
5. 是看跌形态
```

---

### 2.4 三角形形态总结

| 类型 | 特征 | 突破方向 | 性质 |
|------|------|---------|------|
| 对称三角形 | 高低点收敛 | 原趋势方向（60-70%） | 中性 |
| 上升三角形 | 水平阻力+上升支撑 | 向上（75%+） | 看涨 |
| 下降三角形 | 下降阻力+水平支撑 | 向下（75%+） | 看跌 |

## 三、旗形与三角旗

### 3.1 旗形（Flag）

**形态结构：**
```
上涨趋势中的旗形：
              ╱╲╱╲╱╲  ← 旗面（平行四边形，向下倾斜）
             ╱
            ╱
           ╱  ← 旗杆（急速上涨）
          ╱
         ╱
        ╱
```

**特征：**
```
1. 旗杆：急速上涨或下跌（几乎直线）
2. 旗面：与趋势方向相反的平行四边形
3. 持续时间短（1-3周）
4. 突破后涨幅 ≈ 旗杆长度
```

### 3.2 三角旗（Pennant）

**形态结构：**
```
            ╱╲╱╲
           ╱    ╲   ← 小三角旗面
          ╱
         ╱  ← 旗杆
        ╱
       ╱
```

**与旗形的区别：**
```
旗形：旗面是平行四边形
三角旗：旗面是小三角形

共同点：
→ 都有旗杆
→ 都是短期整理
→ 突破后力度大
→ 持续时间短
```

## 四、楔形

### 4.1 上升楔形

**形态结构：**
```
         ╱  ← 高点连线更陡
        ╱
       ╱╲╱╲
      ╱    ╲
     ╱      ╲  ← 低点连线较缓
    ╱
   ╱
```

**特征：**
```
1. 高低点都在上升
2. 上升速度越来越快（收敛）
3. 通常向下突破
4. 出现在下跌趋势的反弹中 = 看跌
5. 出现在上涨趋势末端 = 也可能向下反转
```

### 4.2 下降楔形

**形态结构：**
```
   ╲
    ╲╱╲
     ╲  ╲
      ╲  ╲╱╲
       ╲    ╲
        ╲
```

**特征：**
```
1. 高低点都在下降
2. 下降速度越来越慢（收敛）
3. 通常向上突破
4. 出现在上涨趋势的回调中 = 看涨
5. 是相对少见的看涨形态
```

### 4.3 楔形 vs 三角形

| 维度 | 楔形 | 三角形 |
|------|------|--------|
| 方向 | 整体向上或向下倾斜 | 水平方向 |
| 突破方向 | 通常与楔形方向相反 | 通常与原趋势一致 |
| 持续时间 | 较短 | 较长 |
| 出现频率 | 较少 | 更常见 |

## 五、矩形整理

### 5.1 矩形（Rectangle）

**形态结构：**
```
  ────────────────────  ← 水平阻力
 ╱╲  ╱╲    ╱╲  ╱╲
╱  ╲╱  ╲  ╱  ╲╱  ╲
  ────────────────────  ← 水平支撑
```

**特征：**
```
1. 价格在两条水平线之间波动
2. 阻力线和支撑线平行
3. 持续时间较长（数周到数月）
4. 通常向原趋势方向突破
5. 也叫"箱体整理"
```

**操作：**
```
策略1：突破后买入
→ 突破阻力线时买入
→ 止损设在矩形内

策略2：箱体内高抛低吸
→ 支撑位买入
→ 阻力位卖出
→ ⚠️ 风险：突破后方向反了
```

## 六、持续形态交易策略

### 6.1 通用交易规则

```
1. 等待突破确认
   → 不提前预判方向
   → 收盘价突破才算数

2. 看成交量
   → 突破时必须放量
   → 无量突破不可信

3. 设好止损
   → 止损在形态内最近的高低点
   → 或突破位下方3-5%

4. 计算目标位
   → 形态高度投射
   → 到达目标位分批止盈

5. 回踩确认
   → 突破后回踩不破 = 加仓机会
   → 回踩跌破 = 假突破，止损
```

### 6.2 各形态可靠性排名

| 排名 | 形态 | 可靠性 | 出现频率 |
|------|------|--------|---------|
| 1 | 旗形/三角旗 | ⭐⭐⭐⭐⭐ | 中等 |
| 2 | 上升/下降三角形 | ⭐⭐⭐⭐ | 常见 |
| 3 | 对称三角形 | ⭐⭐⭐ | 很常见 |
| 4 | 矩形 | ⭐⭐⭐ | 常见 |
| 5 | 楔形 | ⭐⭐⭐ | 较少 |

## 七、总结

### 核心要点回顾

✅ **对称三角形**：高低点收敛，通常向原趋势突破  
✅ **上升三角形**：水平阻力+上升支撑，看涨  
✅ **下降三角形**：下降阻力+水平支撑，看跌  
✅ **旗形/三角旗**：旗杆+旗面，突破后涨幅≈旗杆  
✅ **楔形**：通常向楔形方向相反突破  
✅ **矩形**：水平支撑阻力之间整理，向原趋势突破  
✅ **关键确认**：突破+放量+回踩不破  

### 实践建议

1. **顺势交易**：持续形态是顺势加仓的好机会
2. **等待确认**：突破前不猜方向
3. **量能验证**：放量突破才可信
4. **止损保护**：假突破随时可能发生
5. **目标位管理**：用形态高度计算目标位
