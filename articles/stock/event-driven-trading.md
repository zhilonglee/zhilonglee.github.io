## 一、事件驱动交易框架

### 1.1 事件分类

| 事件类型 | 示例 | 影响持续性 | 可操作性 |
|---------|------|-----------|---------|
| 政策事件 | 产业政策、监管变化 | 长期 | 高 |
| 业绩事件 | 业绩预告、财报 | 中期 | 高 |
| 行业催化 | 新品发布、技术突破 | 中期 | 中 |
| 突发事件 | 自然灾害、地缘冲突 | 短期 | 低 |
| 资本运作 | 并购重组、股权激励 | 长期 | 中 |

### 1.2 事件影响评估

事件影响可从三个维度评估：

**1. 超预期程度**。超预期的利好会推动股价大涨，符合预期则可能“利好出尽”，不及预期则股价下跌。

**2. 影响范围**。影响整个市场为系统性，影响行业为板块性，影响个股为个股行情。

**3. 持续性**。一次性事件只有短期影响，趋势性变化有长期影响（更重要）。

## 二、政策事件交易

### 2.1 政策类型

| 政策类型 | 影响方向 | 案例 |
|---------|---------|------|
| 产业政策 | 利好相关板块 | 新能源补贴、AI支持 |
| 货币政策 | 宽松利好股市 | 降准降息 |
| 监管政策 | 短期利空 | 反垄断、教培监管 |
| 财政政策 | 利好基建消费 | 减税降费、专项债 |
| 贸易政策 | 影响进出口 | 关税、制裁 |

### 2.2 政策交易策略

政策交易可分三步：

**第一步：政策解读**。政策力度如何（超预期还是符合预期）？影响哪些板块？是短期还是长期？

**第二步：预期差分析**。市场是否已经消化预期？如果已经涨了很多则“利好出尽是利空”，如果没有预期到则可能大涨。

**第三步：交易执行**。超预期则第一时间买入龙头，符合预期则获利了结，不及预期则观望。

### 2.3 重要政策日历

| 时间 | 事件 | 影响 |
|------|------|------|
| 每年3月 | 两会 | 全年政策方向 |
| 每季度 | 政治局会议 | 经济政策定调 |
| 不定期 | 国务院常务会议 | 具体政策 |
| 不定期 | 部委文件 | 行业政策 |

## 三、业绩事件交易

### 3.1 业绩预告交易

业绩预告类型及市场反应：

- 预增（超过50%）：看是否超预期
- 预减（超过50%）：利空，但看是否已经消化
- 扭亏：利好（特别是超预期）
- 首亏：利空
- 续亏：利空（但利空出尽可能反转）

关键判断：不是“好不好”决定涨跌，而是“比预期好还是差”决定涨跌。

### 3.2 财报季策略

A股财报时间：

- 1月：年报预告（上一年度）
- 4月：年报+一季报
- 7月：半年报预告
- 8月：半年报
- 10月：三季报

财报季策略：

1. 提前埋伏，买入业绩可能超预期的公司
2. 业绩兑现，超预期持有，符合预期卖出
3. 避开业绩雷，提前看预告

### 3.3 业绩超预期选股

| 指标 | 说明 |
|------|------|
| 分析师预期 | 一致预期上调的公司 |
| 行业景气度 | 高频数据向好的行业 |
| 管理层指引 | 管理层乐观的公司 |
| 订单/合同 | 有大额新订单的公司 |

## 四、行业催化事件

### 4.1 常见催化类型

| 催化类型 | 案例 | 影响范围 |
|---------|------|---------|
| 新品发布 | 苹果发布会、华为新品 | 产业链 |
| 技术突破 | AI大模型、固态电池 | 相关行业 |
| 价格变化 | 产品涨价、锂价上涨 | 上下游 |
| 国际会议 | CES、ASCO | 相关概念股 |
| 订单公告 | 大额合同、框架协议 | 个股+板块 |

### 4.2 催化事件交易

催化事件操作要点：

**1. 提前布局**。已知催化时间点（如发布会日期），提前1至2周买入相关标的，催化兑现后根据表现决定。

**2. 催化兑现**。超预期则持有，符合预期则卖出（买预期卖事实），不及预期则止损。

**3. 催化后的扩散**。龙头先涨，二线补涨，三线跟涨，抓住扩散节奏。

## 五、突发事件交易

### 5.1 突发事件类型

常见突发事件：

1. 自然灾害影响供给（如矿难带动煤炭涨价）
2. 地缘冲突影响资源品（如石油、粮食）
3. 黑天鹅导致短期恐慌（如疫情初期）
4. 公司突发（财务造假、高管变动）

突发事件操作原则：不要恐慌性卖出，评估事件的真实影响，很多突发事件是“买入机会”。

### 5.2 黑天鹅操作

黑天鹅事件操作指南：

- 当日：不操作（恐慌情绪最高）
- 次日：评估影响，决定是否减仓
- 一周内：如果基本面没变，可以加仓

巴菲特的名言：“别人恐惧时我贪婪”。

## 六、事件交易的操作纪律

### 6.1 信息获取

事件交易的信息来源分为三类：

**1. 官方渠道**：证监会、交易所公告，部委官网，上市公司公告。

**2. 专业媒体**：财联社、证券时报，行业媒体。

**3. 数据平台**：东方财富、同花顺，Wind、Choice。

注意：不信小道消息，以官方信息为准，多方验证。

### 6.2 交易纪律

事件交易铁律：

1. **不追利好**：已经涨停的不追
2. **不信内幕**：没有内幕消息
3. **设止损**：事件可能被证伪
4. **控制仓位**：单事件不超过30%仓位
5. **及时止盈**：事件热度消退快

## 七、总结

### 核心要点回顾

1. 事件驱动看预期差：不是“好不好”，而是“比预期好还是差”
2. 政策事件影响最深远：要深入理解政策意图
3. 买预期卖事实：催化兑现后要根据表现决定
4. 信息获取要正规：不信小道消息
5. 控制仓位和止损：事件可能不及预期
