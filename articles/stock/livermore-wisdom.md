## 一、利弗莫尔其人

### 1.1 传奇人生

```
杰西·利弗莫尔（1877-1940）
美国传奇交易员

主要成就：
-> 14岁在对赌行赚1000美元
-> 1907年做空美股赚300万美元
-> 1929年大崩盘做空赚1亿美元（约今15亿美元）
-> 被称为"华尔街大空头"

人生轨迹：
-> 多次暴富，多次破产
-> 最终在1940年自杀
-> 留下经典著作《股票作手回忆录》
```

### 1.2 核心投资哲学

```
利弗莫尔的核心信念：
-> 市场有趋势，趋势可以判断
-> 赚大钱靠等待，不靠频繁交易
-> 顺势而为，不逆势操作
-> 用资金管理控制风险
-> 独立思考，不听消息
```

**名言：**
> "赚大钱的诀窍不在于买进卖出，而在于等待。"  
> —— 杰西·利弗莫尔

## 二、最小阻力线

### 2.1 什么是最小阻力线？

```
定义：
价格总是沿着阻力最小的方向运动

上涨趋势：
-> 向上的阻力 < 向下的阻力
-> 价格继续上涨

下跌趋势：
-> 向下的阻力 < 向上的阻力
-> 价格继续下跌

横盘整理：
-> 上下阻力相等
-> 等待突破方向

关键：
-> 判断最小阻力方向
-> 顺势交易
```

### 2.2 实战应用

```
判断最小阻力方向：

看趋势：
-> 高点是否不断升高？-> 向上
-> 低点是否不断降低？-> 向下
-> 高低点都不变？-> 横盘

看量能：
-> 上涨放量，下跌缩量 -> 向上
-> 下跌放量，上涨缩量 -> 向下

看均线：
-> 均线向上 -> 向上
-> 均线向下 -> 向下
```

## 三、关键点交易法

### 3.1 什么是关键点？

```
定义：
价格运动中的关键转折位置

类型：
-> 突破关键点：价格突破重要阻力/支撑
-> 回调关键点：趋势中的回调到位
-> 心理关键点：整数关口（如10元、100元）
```

### 3.2 突破关键点

```
操作规则：
-> 价格突破关键阻力位时买入
-> 必须放量确认
-> 突破后回踩不破再加仓
-> 止损设在突破位下方

实例：
某股票在20元反复震荡3个月
某天放量突破20元
-> 20元就是关键点
-> 突破时买入
-> 目标看22-25元
```

### 3.3 回调关键点

```
操作规则：
-> 上涨趋势中回调到支撑位
-> 出现止跌信号
-> 在支撑位附近买入
-> 止损设在支撑位下方

实例：
某股票从10元涨到20元
回调到15元（前期平台）止跌
-> 15元就是回调关键点
-> 止跌后买入
-> 目标看新高
```

## 四、资金管理

### 4.1 金字塔加仓法

```
利弗莫尔的加仓方法：

第一次买入：试探性建仓（总仓位的20%）
-> 如果方向正确 -> 加仓
-> 如果方向错误 -> 止损

第二次加仓：确认性加仓（再加20%）
-> 价格继续向有利方向运动
-> 加仓量 <= 第一次

第三次加仓：趋势性加仓（再加20%）
-> 趋势确认
-> 加仓量 <= 第二次

原则：
-> 每次加仓量递减
-> 只在盈利时加仓
-> 绝不在亏损时加仓
```

### 4.2 利弗莫尔的仓位管理

```
核心原则：
-> 先用小仓位试探
-> 确认方向后再加仓
-> 永远不要满仓
-> 保留现金应对意外

分配方法：
-> 单只股票不超过总仓位的20%
-> 同时持有不超过5只
-> 至少保留20-30%现金
```

## 六、利弗莫尔的教训

### 6.1 他为什么最终破产？

```
尽管利弗莫尔多次暴富
但他最终破产并自杀

原因分析：
-> 不遵守自己的规则
-> 情绪化交易
-> 生活奢侈，支出失控
-> 听信他人建议
-> 过度自信

教训：
-> 知道规则不等于执行规则
-> 交易系统再好，不执行也没用
-> 纪律是交易者的生命线
```

### 6.2 给投资者的启示

```
从利弗莫尔身上学到：

要学的：
-> 顺势交易的智慧
-> 关键点交易法
-> 金字塔加仓法
-> 资金管理的重要性
-> 独立思考的精神

要避免的：
-> 不遵守纪律
-> 情绪化交易
-> 过度自信
-> 生活支出失控
-> 听信他人
```

## 七、总结

### 核心要点回顾

(1) **最小阻力线**：价格沿阻力最小方向运动  
(2) **关键点**：突破关键位时入场  
(3) **金字塔加仓**：先试探，确认后加仓  
(4) **资金管理**：截断亏损，让利润奔跑  
(5) **纪律**：知道规则更要执行规则  

### 实践建议

1. **顺势交易**：判断最小阻力方向，顺势操作
2. **等待关键点**：不急于入场，等到好位置
3. **严格止损**：亏损不超过10%
4. **金字塔加仓**：只在盈利时加仓
5. **遵守纪律**：制定规则并严格执行
