## 一、PEG指标详解

### 1.1 PEG的定义

**公式：**
```
PEG = PE（市盈率）/ G（净利润增速%）

其中：
PE = 股价 / 每股收益（或 总市值 / 净利润）
G = 未来3-5年的预期净利润年增长率（%）

例如：
某股票PE = 30倍
预期未来3年净利润年增速 = 25%
PEG = 30 / 25 = 1.2
```

### 1.2 PEG的判断标准

| PEG | 评价 | 操作建议 |
|-----|------|---------|
| < 0.5 | 极度低估 | 强烈买入机会 |
| 0.5-0.8 | 低估 | 积极买入 |
| 0.8-1.0 | 略低估 | 可以买入 |
| 1.0 | 合理估值 | 持有观望 |
| 1.0-1.5 | 略高估 | 谨慎，等待回调 |
| 1.5-2.0 | 高估 | 考虑减仓 |
| > 2.0 | 严重高估 | 不建议买入 |

**彼得·林奇的标准：**
```
林奇认为：
→ PEG = 1 是合理价格
→ PEG < 1 是便宜
→ PEG < 0.5 是非常好的机会

但林奇也指出：
→ 对于确定性极高的龙头
→ PEG可以容忍到1.5
→ 因为确定性本身就有价值
```

## 二、PEG的实战应用

### 2.1 计算实例

**案例1：消费成长股**
```
某消费品公司：
当前股价：50元
每股收益（EPS）：2元
PE = 50/2 = 25倍

过去3年净利润增速：
第1年：+20%
第2年：+25%
第3年：+30%
平均增速：25%

预期未来3年增速：22%（保守估计）

PEG = 25 / 22 = 1.14

评价：合理偏高
→ 如果确定性强，可以持有
→ 但当前不算便宜
→ 等回调到PEG < 1时买入更好
```

**案例2：科技成长股**
```
某科技公司：
当前股价：80元
EPS：1.6元
PE = 80/1.6 = 50倍

过去3年净利润增速：
第1年：+40%
第2年：+50%
第3年：+60%
平均增速：50%

预期未来3年增速：35%（增速放缓）

PEG = 50 / 35 = 1.43

评价：略高估
→ 虽然增速很快
→ 但当前价格已经透支
→ 需要增速持续超预期才不贵
```

**案例3：低估值成长股**
```
某制造公司：
当前股价：15元
EPS：1元
PE = 15倍

预期未来3年增速：20%

PEG = 15 / 20 = 0.75

评价：低估
→ PEG < 1，有投资价值
→ 如果基本面确认没问题
→ 可以考虑买入
```

## 三、如何估算增长率

### 3.1 三种估算方法

**方法1：历史增长率法**
```
取过去3-5年的净利润增速平均值

优点：数据客观
缺点：过去不代表未来

建议：
→ 取3年和5年的平均值
→ 如果增速在加速，可以用近2年数据
→ 如果增速在减速，用保守估计
```

**方法2：机构预测法**
```
参考多家券商研报的预测

方法：
→ 查看3-5家机构的预测
→ 取中间值（去掉最高和最低）
→ 在此基础上打8折（保守估计）

优点：有专业分析支撑
缺点：机构预测经常不准
```

**方法3：业务驱动法**
```
从业务角度推算增长率

例如：
→ 预计未来3年每年新开店100家
→ 单店年利润200万
→ 当前总利润10亿

第1年新增利润：100×200万=2亿 → 增速20%
第2年累计：200×200万=4亿 → 增速33%
第3年累计：300×200万=6亿 → 增速37.5%

平均增速约30%
```

### 3.2 增长率估算的注意事项

```
⚠️ 关键原则：宁可保守，不要乐观

常见错误：
❌ 用最高增速年份的数据
❌ 只看好消息，忽略风险
❌ 假设增速能永远维持
❌ 忽略基数效应（利润越大增速越难）

正确做法：
✅ 用3-5年平均增速
✅ 在预测基础上打8折
✅ 考虑行业天花板
✅ 考虑基数效应
```

## 四、PEG vs PE vs PB

### 4.1 三大指标对比

| 指标 | 公式 | 适用场景 | 不适用场景 |
|------|------|---------|-----------|
| PE | 股价/EPS | 盈利稳定的公司 | 亏损公司、周期股 |
| PB | 股价/每股净资产 | 重资产行业（银行、地产） | 轻资产公司（科技） |
| PEG | PE/增速 | 成长型公司 | 亏损公司、缓慢增长型 |

### 4.2 如何选择？

```
盈利稳定的大公司（消费、医药龙头）：
→ 主要看PE
→ 辅助看PEG

高成长公司（科技、新能源）：
→ 主要看PEG
→ 辅助看PS（市销率）

重资产公司（银行、地产、钢铁）：
→ 主要看PB
→ 辅助看PE

周期型公司（煤炭、化工）：
→ 主要看PB
→ PE在周期顶部可能误导
```

### 5.1 行业PEG参考

| 行业 | 合理PEG范围 | 说明 |

| 制造 | 0.8-1.5 | 周期性需考虑 |

## 六、PEG的局限性

### 6.1 主要局限

```
❌ 不适用于亏损公司
   → 没有PE，无法计算PEG
   → 需要用PS等其他方法

❌ 增长率估计困难
   → 预测未来本身就很难
   → 不同人估算差异大

❌ 不适合周期股
   → 周期顶部增长率很高
   → PEG看起来很低，实际是陷阱

❌ 不适合缓慢增长型
   → 增速只有5%，PEG会很高
   → 但这类公司应该看分红率

❌ 忽略了公司质量
   → PEG低不代表公司好
   → 需要结合护城河、ROE等判断
```

## 七、总结

### 核心要点回顾

✅ **PEG公式**：PE / 净利润增速，衡量成长股的性价比  
✅ **判断标准**：PEG < 1低估，PEG = 1合理，PEG > 1高估  
✅ **增长率估算**：用3-5年平均，保守估计打8折  
✅ **指标选择**：成长股看PEG，稳定股看PE，重资产看PB  
✅ **局限性**：不适用于亏损公司、周期股、缓慢增长型  

### 实践建议

1. **PEG是成长股估值的首选工具**
2. **结合PE和PB交叉验证**
3. **保守估算增长率**，宁可错过也不买贵
4. **不同行业用不同PEG标准**
5. **PEG只是工具之一**，需要结合护城河、管理层等综合判断
