# PEG估值法：成长股的合理价格怎么算

PE告诉你市场愿意为公司赚的每一块钱付多少钱，而PEG告诉你这个价格相对于增长速度是否合理。PEG（市盈率相对盈利增长比率）是彼得·林奇最爱的估值指标，它将市盈率与净利润增速结合，帮助投资者判断成长股的估值是否合理。本文基于《彼得·林奇的成功投资》一书，详细讲解PEG公式、实战应用、增长率估算方法、与PE/PB的对比，以及不同行业的PEG标准。

## 一、PEG指标详解

### 1.1 PEG的定义

公式：PEG = PE（市盈率）/ G（净利润增速%），其中PE = 股价/每股收益（或总市值/净利润），G为未来3-5年的预期净利润年增长率。

例如某股票PE = 30倍，预期未来3年净利润年增速 = 25%，则PEG = 30/25 = 1.2。

### 1.2 PEG的判断标准

| PEG | 评价 | 操作建议 |
|-----|------|---------|
| < 0.5 | 极度低估 | 强烈买入机会 |
| 0.5-0.8 | 低估 | 积极买入 |
| 0.8-1.0 | 略低估 | 可以买入 |
| 1.0 | 合理估值 | 持有观望 |
| 1.0-1.5 | 略高估 | 谨慎，等待回调 |
| 1.5-2.0 | 高估 | 考虑减仓 |
| > 2.0 | 严重高估 | 不建议买入 |

林奇认为PEG = 1是合理价格，PEG < 1是便宜，PEG < 0.5是非常好的机会。但对于确定性极高的龙头，PEG可以容忍到1.5，因为确定性本身就有价值。

## 二、PEG的实战应用

### 2.1 计算实例

**案例一：消费成长股。** 当前股价50元，EPS 2元，PE = 25倍。过去3年净利润增速分别为20%、25%、30%，平均增速25%，预期未来3年保守估计22%。PEG = 25/22 = 1.14，合理偏高，如果确定性强可以持有，但当前不算便宜。

**案例二：科技成长股。** 当前股价80元，EPS 1.6元，PE = 50倍。过去3年增速分别为40%、50%、60%，但预期未来增速放缓至35%。PEG = 50/35 = 1.43，略高估，虽然增速快但当前价格已经透支。

**案例三：低估值成长股。** 当前股价15元，EPS 1元，PE = 15倍，预期未来3年增速20%。PEG = 15/20 = 0.75，低估，如果基本面确认没问题可以考虑买入。

## 三、如何估算增长率

### 3.1 三种估算方法

**方法一：历史增长率法。** 取过去3-5年的净利润增速平均值。优点是数据客观，缺点是过去不代表未来。建议取3年和5年的平均值，如果增速在加速可以用近2年数据，如果增速在减速用保守估计。

**方法二：机构预测法。** 参考多家券商研报的预测，查看3-5家机构的预测，取中间值（去掉最高和最低），在此基础上打8折作为保守估计。优点是有专业分析支撑，缺点是机构预测经常不准。

**方法三：业务驱动法。** 从业务角度推算增长率。例如预计未来3年每年新开店100家、单店年利润200万、当前总利润10亿，则第1年新增利润2亿（增速20%），第2年累计4亿（增速33%），第3年累计6亿（增速37.5%），平均增速约30%。

### 3.2 增长率估算的注意事项

关键原则是宁可保守，不要乐观。常见错误包括用最高增速年份的数据、只看好消息忽略风险、假设增速能永远维持、忽略基数效应（利润越大增速越难）。正确做法是用3-5年平均增速、在预测基础上打8折、考虑行业天花板、考虑基数效应。

## 四、PEG vs PE vs PB

### 4.1 三大指标对比

| 指标 | 公式 | 适用场景 | 不适用场景 |
|------|------|---------|-----------|
| PE | 股价/EPS | 盈利稳定的公司 | 亏损公司、周期股 |
| PB | 股价/每股净资产 | 重资产行业（银行、地产） | 轻资产公司（科技） |
| PEG | PE/增速 | 成长型公司 | 亏损公司、缓慢增长型 |

### 4.2 如何选择

盈利稳定的大公司（消费、医药龙头）主要看PE，辅助看PEG。高成长公司（科技、新能源）主要看PEG，辅助看PS（市销率）。重资产公司（银行、地产、钢铁）主要看PB，辅助看PE。周期型公司（煤炭、化工）主要看PB，PE在周期顶部可能误导。

## 五、不同行业的PEG标准

| 行业 | 合理PEG范围 | 说明 |
|------|-----------|------|
| 消费品 | 0.8-1.5 | 确定性高，可容忍较高 |
| 医药 | 0.6-1.2 | 波动大，需要更低PEG |
| 科技 | 0.5-1.0 | 增速快但不确定性高 |
| 金融 | 0.8-1.2 | 增速稳定 |
| 制造 | 0.8-1.5 | 周期性需考虑 |
| 新能源 | 0.5-1.0 | 增速快但竞争激烈 |

---

## 六、PEG的局限性

PEG有五个局限性：不适用于亏损公司（没有PE无法计算PEG，需要用PS等其他方法）；增长率估计困难（预测未来本身就很难，不同人估算差异大）；不适合周期股（周期顶部增长率很高，PEG看起来很低实际是陷阱）；不适合缓慢增长型（增速只有5%，PEG会很高，但这类公司应该看分红率）；忽略了公司质量（PEG低不代表公司好，需要结合护城河、ROE等判断）。

---

## 七、总结

**核心要点回顾：**

1. PEG公式：PE / 净利润增速，衡量成长股的性价比
2. 判断标准：PEG < 1低估，PEG = 1合理，PEG > 1高估
3. 增长率估算：用3-5年平均，保守估计打8折
4. 指标选择：成长股看PEG，稳定股看PE，重资产看PB
5. 局限性：不适用于亏损公司、周期股、缓慢增长型

**实践建议：**

1. PEG是成长股估值的首选工具
2. 结合PE和PB交叉验证
3. 保守估算增长率，宁可错过也不买贵
4. 不同行业用不同PEG标准
5. PEG只是工具之一，需要结合护城河、管理层等综合判断
