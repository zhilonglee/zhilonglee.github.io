## 一、周期行业投资框架

### 1.1 周期行业的本质

周期行业的底层逻辑是：供需错配导致价格波动，价格波动引发利润波动，进而影响股价。

供需错配的原因有三：

1. 产能建设需要时间（1至3年），供给滞后于需求
2. 需求受经济周期影响，繁荣时旺盛，衰退时萎缩
3. 企业投资决策是顺周期的，繁荣时扩产，衰退时减产

### 1.2 A股主要周期品分类

| 类别 | 代表品种 | 代表公司 | 驱动因素 |
|------|---------|---------|---------|
| 有色金属 | 铜、铝、锂 | 紫金矿业、中国铝业 | 全球经济+美元 |
| 钢铁 | 螺纹钢、热卷 | 宝钢股份、华菱钢铁 | 基建+地产 |
| 化工 | 乙烯、纯碱 | 万华化学、远兴能源 | 油价+需求 |
| 煤炭 | 动力煤、焦煤 | 中国神华、陕西煤业 | 能源需求 |
| 建材 | 水泥、玻璃 | 海螺水泥、旗滨集团 | 基建+地产 |
| 航运 | 集运、散货 | 中远海控 | 全球贸易 |

### 1.3 周期股 vs 成长股

| 维度 | 周期股 | 成长股 |
|------|--------|--------|
| 利润 | 大幅波动 | 持续增长 |
| 估值 | PE在底部最高、顶部最低 | PE相对稳定 |
| 买入时机 | 高PE时买入（利润底部） | 低PE时买入（业绩增长） |
| 卖出时机 | 低PE时卖出（利润顶部） | 增速放缓时 |
| 核心能力 | 择时能力 | 选股能力 |

## 二、周期判断方法论

### 2.1 周期四阶段模型

```
                价格顶部
               /        \
          繁荣期          衰退期
         /                  \
       /                      \
  复苏期                      萧条期
       \                      /
        \                    /
         \                  /
          价格底部
```

| 阶段 | 供需状态 | 价格 | 利润 | 投资策略 |
|------|---------|------|------|---------|
| 复苏 | 需求回暖，供给不足 | 上涨 | 改善 | 买入 |
| 繁荣 | 需求旺盛，供给跟上 | 高位 | 最高 | 持有/减仓 |
| 衰退 | 需求下降，供给过剩 | 下跌 | 下降 | 卖出 |
| 萧条 | 需求低迷，产能出清 | 底部 | 亏损 | 等待/建仓 |

### 2.2 周期判断指标

判断周期位置需要关注五个核心指标：

1. **产品价格**：价格处于历史什么分位？是否跌破成本线？
2. **库存水平**：社会库存是增加还是减少？处于历史什么分位？
3. **产能利用率**：高利用率意味着供给紧张，低利用率意味着供给过剩
4. **在建产能**：大量在建预示未来供给压力大，很少在建则未来供给紧张
5. **行业盈利面**：大部分企业盈利说明景气上行，大部分亏损说明接近底部

### 2.3 周期股的反直觉逻辑

周期股投资存在反直觉逻辑：

**高PE买入**：利润最差的时候PE最高，但这可能是周期底部，应该买入。

**低PE卖出**：利润最好的时候PE最低，但这可能是周期顶部，应该卖出。

**用PB估值更可靠**：PB不受利润波动影响，PB小于1可能是底部信号。

## 三、有色金属投资

### 3.1 铜：经济晴雨表

| 因素 | 影响方向 | 说明 |
|------|---------|------|
| 全球经济 | 正向 | 经济好 -> 需求增加 |
| 美元指数 | 反向 | 美元弱 -> 铜价涨 |
| 新能源需求 | 正向 | 电动车用铜量是传统车3倍 |
| 矿山供给 | 反向 | 矿山投产周期长 |

### 3.2 铝：产能天花板

铝行业投资逻辑围绕四点：

1. **产能天花板**：国内电解铝产能上限4500万吨
2. **需求增长**：光伏+新能源车+轻量化
3. **成本支撑**：电价是核心成本
4. **关注方向**：水电铝（成本优势）、再生铝（增量）

### 3.3 锂：新能源的金属

锂价与新能源车销量高度相关，参考新能源行业分析。

## 四、钢铁行业投资

### 4.1 钢铁行业特征

钢铁行业有五个特点：

1. 供给端受政策影响大（限产、去产能）
2. 需求端看基建和地产
3. 原材料（铁矿石）价格波动影响利润
4. 行业集中度在提升
5. 特钢比普钢更有成长性

### 4.2 投资选择

| 类型 | 代表 | 投资逻辑 |
|------|------|---------|
| 普钢龙头 | 宝钢股份 | 规模+成本优势 |
| 特钢 | 中信特钢 | 高附加值+弱周期 |
| 钢管 | 久立特材 | 高端产品+军工 |

## 五、化工行业投资

### 5.1 化工分类

| 类型 | 特征 | 投资方法 |
|------|------|---------|
| 大宗化工 | 强周期，看价格 | 周期底部买龙头 |
| 精细化工 | 弱周期，看产品 | 选高壁垒细分 |
| 新材料 | 成长性 | 选高增长赛道 |

### 5.2 化工龙头的投资价值

化工龙头（如万华化学）有五大投资逻辑：

1. **规模优势**：成本最低
2. **技术壁垒**：MDI全球寡头
3. **持续扩品**：从MDI到TDI到新材料
4. **周期弱化**：产品多元化降低周期性
5. **长期成长**：全球市占率持续提升

## 六、煤炭与能源

### 6.1 煤炭投资逻辑

煤炭行业已从高增长转向高分红：

**旧逻辑（已过）**：需求增长带动产能扩张。

**新逻辑（当前）**：需求稳定、供给受限、价格中枢上移、高分红。

投资煤炭的核心看点：

1. 股息率大于5%有吸引力
2. 长协价占比高则业绩稳定
3. 有无新增产能
4. 是否有新能源布局

### 6.2 能源价格联动

能源价格联动关系为：

- 原油价格影响煤炭、天然气价格
- 煤炭价格影响电力成本
- 电力成本影响高耗能行业（铝、硅）

跟踪指标：布伦特原油价格、秦皇岛动力煤价格、天然气价格（LNG）。

## 七、周期股选股与择时

### 7.1 选股原则

周期股选股有五个原则：

1. **选龙头**：周期底部最先活下来
2. **选低成本**：成本曲线左侧的公司
3. **选有分红**：证明盈利真实性
4. **选弱周期化**：产品多元化降低波动
5. **选有成长**：产能扩张带来量增

### 7.2 买入时机

| 信号 | 说明 |
|------|------|
| 产品价格跌破成本线 | 供给将收缩 |
| 大量企业亏损退出 | 接近底部 |
| 库存开始下降 | 供需改善 |
| PB < 1x | 市场悲观过度 |
| 行业没有新增产能 | 未来供给紧张 |

### 7.3 卖出时机

| 信号 | 说明 |
|------|------|
| 产品价格创历史新高 | 供给将增加 |
| 大量新增产能规划 | 未来供给过剩 |
| 库存大幅增加 | 供需恶化 |
| PE < 5x | 利润接近顶部 |
| 全行业都在扩产 | 周期即将反转 |

## 八、总结

### 核心要点回顾

1. 周期是供需错配：理解供需关系是投资周期股的基础
2. 反直觉操作：高PE买入、低PE卖出
3. 用PB估值：周期股用PB比PE更可靠
4. 选龙头：底部龙头最先复苏，顶部龙头最抗跌
5. 判断周期位置：价格、库存、产能利用率是核心指标
