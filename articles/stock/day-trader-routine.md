## 一、短线交易者的一天

### 1.1 完整日程表

| 时间 | 活动 | 内容 |
|------|------|------|
| 7:00 | 起床 | 查看隔夜外盘、重大新闻 |
| 8:30-9:15 | 盘前准备 | 制定当日交易计划 |
| 9:15-9:25 | 集合竞价 | 观察竞价异动 |
| 9:30-10:00 | 开盘30分钟 | 最重要的交易时段 |
| 10:00-11:30 | 上午盘 | 执行计划，不追涨 |
| 11:30-13:00 | 午休 | 复盘上午盘，调整计划 |
| 13:00-14:30 | 下午盘 | 观察，一般不操作 |
| 14:30-15:00 | 尾盘30分钟 | 第二个重要交易时段 |
| 15:00-17:00 | 盘后复盘 | 分析当日交易，更新数据 |
| 20:00-21:00 | 晚间研究 | 看公告、新闻、做功课 |

## 二、盘前准备（8:30-9:15）

### 2.1 信息收集（15分钟）

```
必看信息：
1. 隔夜美股表现（影响开盘情绪）
2. A50期货走势（预判开盘方向）
3. 重大新闻/政策（影响板块）
4. 自选股公告（利好/利空）
5. 板块资金流向（前一日的）
```

### 2.2 制定交易计划（30分钟）

```
今日交易计划（必须写下来）：

持仓处理：
-> A股票：如果涨到___，止盈1/3
-> B股票：如果跌破___，止损
-> C股票：继续持有，不操作

买入计划：
-> D股票：如果回调到___，买入___仓位
-> E股票：如果突破___，买入___仓位
-> 不买：___（明确不买的股票）

仓位控制：
-> 当前仓位：___%
-> 今日最大仓位：___%
-> 最大加仓：___%
```

### 2.3 心理准备

```
盘前自检：
[ ] 我情绪稳定吗？
[ ] 我有明确的计划吗？
[ ] 我能严格执行计划吗？
[ ] 如果今天亏损我能接受吗？

如果任何一项不满足 -> 今天不交易
```

## 三、盘中操作（9:15-15:00）

### 3.1 集合竞价（9:15-9:25）

```
观察要点：
-> 自选股竞价情况（高开/低开/平开）
-> 竞价量是否异常
-> 有没有大单异动

注意：
-> 9:15-9:20可以撤单（假单多）
-> 9:20-9:25不能撤单（真实意愿）
-> 重点看9:20之后的数据
```

### 3.2 开盘30分钟（9:30-10:00）

```
这是最重要的时段：
-> 开盘定方向（高开/低开/平开）
-> 资金流向最明显
-> 主力意图最清晰

操作原则：
-> 有计划的买入 -> 执行
-> 没有计划的 -> 不操作
-> 不要因为"涨了就追"
```

### 3.3 上午盘中（10:00-11:30）

```
操作原则：
-> 减少操作
-> 只在触发条件时操作
-> 多看少动

关键观察：
-> 大盘走势
-> 板块轮动
-> 自选股表现
```

### 3.4 午休复盘（11:30-13:00）

```
复盘要点：
-> 上午操作是否按计划执行？
-> 有没有情绪化操作？
-> 下午需要调整计划吗？

调整计划：
-> 如果上午已经买入 -> 设好下午止损
-> 如果上午没机会 -> 下午继续等
-> 如果上午亏损 -> 下午不加仓
```

### 3.5 下午盘（13:00-14:30）

```
操作原则：
-> 下午一般不操作
-> 除非触发明确条件
-> 下午交易成功率通常低于上午

注意：
-> 下午容易犯困
-> 判断力下降
-> 不建议做重大决策
```

### 3.6 尾盘30分钟（14:30-15:00）

```
第二个重要时段：
-> 主力资金尾盘定方向
-> 适合确认买入（日线级别）
-> 适合调整仓位

尾盘买入的优势：
-> 减少当日波动风险
-> 可以更准确地判断趋势
-> 次日开盘方向更明确
```

## 四、盘后复盘（15:00-17:00）

### 4.1 当日交易复盘

```
复盘清单：

1. 今日操作记录
   -> 买入了什么？为什么？
   -> 卖出了什么？为什么？
   -> 按计划执行了吗？

2. 盈亏分析
   -> 今日盈亏多少？
   -> 是计划内的盈亏还是意外的？
   -> 有没有情绪化操作？

3. 持仓分析
   -> 各持仓表现如何？
   -> 需要调整吗？
   -> 有没有需要止损的？
```

### 4.2 市场复盘

```
市场复盘：

1. 大盘表现
   -> 指数涨跌
   -> 成交量变化
   -> 市场情绪

2. 板块分析
   -> 哪些板块领涨？
   -> 哪些板块领跌？
   -> 资金流向哪里？

3. 个股观察
   -> 自选股表现
   -> 有没有新的机会？
   -> 观察池有没有变化？
```

### 4.3 更新计划

```
更新内容：
-> 观察池：新增/删除
-> 候选池：更新估值
-> 持仓：更新止损位
-> 明日计划：初步制定
```

## 五、看盘设置与工具

### 5.1 看盘界面设置

```
推荐布局（4窗口）：

窗口1：大盘指数
-> 上证指数 + 深证成指 + 创业板指
-> 判断大势

窗口2：自选股列表
-> 持仓股票
-> 观察池股票
-> 快速查看涨跌

窗口3：个股K线
-> 日线 + 60分钟
-> 详细分析

窗口4：分时图
-> 当日走势
-> 量价关系
```

### 5.2 自选股分组

```
建议分组：

持仓组：正在持有的股票
-> 重点关注
-> 设好止损止盈

观察组1：即将买入
-> 已经深度研究
-> 等待买入时机

观察组2：初步关注
-> 还需要研究
-> 放入候选池

观察组3：已卖出
-> 跟踪后续走势
-> 评估卖出决策
```

### 5.3 预警设置

```
设置预警：

1. 价格预警
-> 止损位到达
-> 目标位到达
-> 关键突破位

2. 涨幅预警
-> 单日涨幅 > 5%
-> 单日跌幅 > 5%

3. 量能预警
-> 成交量异常放大
-> 换手率异常
```

## 六、纪律与心态

### 6.1 盘中纪律

```
必须遵守的规则：

1. 按计划执行
   -> 计划内的操作 -> 执行
   -> 计划外的 -> 不操作

2. 单日亏损上限
   -> 当日亏损达3% -> 停止交易
   -> 连续止损2次 -> 停止交易

3. 不追涨
   -> 已经涨了很多 -> 不追
   -> 错过就错过了

4. 不冲动
   -> 感到冲动 -> 等15分钟
   -> 还冲动 -> 关掉软件

5. 不报复性交易
   -> 亏损后 -> 冷静
   -> 不想"赚回来"
```

### 6.2 心态管理

```
盘中心态调整：

亏损时：
-> 这是交易的成本
-> 下一笔可能会盈利
-> 不要因为一次亏损影响整体

盈利时：
-> 不要过度自信
-> 这是系统的功劳
-> 继续保持纪律

无聊时：
-> 没有机会就不操作
-> 等待是交易的一部分
-> 空仓也是一种仓位

焦虑时：
-> 深呼吸
-> 检查仓位是否过大
-> 减仓可以缓解焦虑
```

## 七、总结

### 核心要点回顾

(1) **盘前准备**：信息收集+制定计划+心理检查  
(2) **盘中操作**：按计划执行，不追涨，不冲动  
(3) **盘后复盘**：分析交易+分析市场+更新计划  
(4) **看盘设置**：合理布局，分组管理，设好预警  
(5) **纪律心态**：单日亏损上限，不报复性交易  

### 给短线交易者的建议

```
1. 交易不是越多越好
   -> 有把握再出手
   -> 一个月做5-10笔就够了

2. 计划比天赋更重要
   -> 没有计划就不交易
   -> 有计划就要执行

3. 复盘比交易更重要
   -> 交易只是执行
   -> 复盘才是提升

4. 保住本金是第一要务
   -> 活着才有机会
   -> 不要all in

5. 平衡交易与生活
   -> 交易不是生活的全部
   -> 保持健康的身心
```
