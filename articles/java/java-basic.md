# Java 基础学习笔记

## 前言

Java 是一门面向对象的编程语言,具有跨平台、安全性高等特点。本文记录我学习 Java 基础的心得体会。

## 核心概念

### 1. 面向对象三大特性

- **封装**: 隐藏内部实现细节,提供公共访问方法
- **继承**: 子类可以继承父类的属性和方法
- **多态**: 同一操作作用于不同对象,产生不同的执行结果

### 2. 基本数据类型

Java 有 8 种基本数据类型:
- 整数类型: `byte`, `short`, `int`, `long`
- 浮点类型: `float`, `double`
- 字符类型: `char`
- 布尔类型: `boolean`

### 3. 集合框架

常用的集合类:
- `ArrayList`: 动态数组
- `HashMap`: 键值对映射
- `HashSet`: 不重复元素集合

## 代码示例

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

## 总结

Java 基础知识是后续学习的基石,需要扎实掌握。
